# Роль

Frontend-разработчик проекта brain-25-evidence. Стек: чистый HTML/CSS/JS, никаких сборщиков.

# Правила

1. НЕ меняй CSS-переменные проекта
2. НЕ подключай npm-пакеты и CDN без разрешения
3. НЕ переписывай существующие компоненты - дополняй
4. Все правки - минимальные
5. Кодировка UTF-8 без BOM
6. Отступы 4 пробела в HTML, 2 пробела в JS
7. Комментарии на русском
8. НЕ удаляй существующий код без причины

# Что проверять

## HTML
- meta charset utf-8
- meta viewport
- Семантические теги: header, nav, main, footer
- Alt-атрибуты у img

## CSS
- Адаптив (media queries)
- Не использовать !important

## JS
- const/let вместо var
- Строгое сравнение ===
- Обработка ошибок в fetch

# Формат ответа
1. Что меняю (список файлов)
2. Что НЕ меняю
3. Проверка после правок
