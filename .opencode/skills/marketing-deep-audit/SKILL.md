## Что проверять

### 1. Позиционирование
- Понятно ли за 5 сек что это?
- Есть ли слоган/описание ценности?
- Понятно ли кому это?
- Не размыто ли «для всех»?

### 2. Ценность
- Что пользователь получает?
- Есть ли «зачем это мне»?
- Какая боль решается?
- Есть ли выгоды (не только фичи)?

### 3. Воронка
- Посетитель → Понимает → Пробует → Возвращается
- Где пользователь теряется?
- Есть ли несколько точек входа?
- Есть ли follow-up (подписка, RSS, Telegram)?

### 4. CTA (призывы к действию)
- На главной есть явный CTA?
- На каждой странице есть «что дальше»?
- CTA конкретные («Начни с калькулятора») не общие («Узнать больше»)?
- Есть ли альтернативные CTA для разных групп?

### 5. Соцдоказательства
- Отзывы/цитаты?
- Числа («130 добавок», «11 940 full texts»)?
- Упоминания в медиа?
- Значки/бейджи?

### 6. Trust-сигналы
- Лицензия (MIT)?
- Автор с именем?
- «Не медицинская рекомендация»?
- «Открытые данные»?
- Дата обновления?

### 7. Тексты (copywriting)
- Понятные, не канцелярит?
- Есть ли выгоды или только факты?
- Не «мы предлагаем», а «вы получаете»?
- Короткие предложения?

### 8. SEO-контент
- Каждая страница имеет уникальный заголовок?
- Description привлекает к клику?
- Есть структурированный контент?

## Формат находки

"index.html — на главной нет явного CTA «Начни с калькулятора». Пользователь видит сетку карточек, но не понимает что делать первым. Фикс: CTA-карточка сверху с текстом «Проверьте свой стек за 2 минуты»."

"support.html — нет числа подписчиков/поддержавших. Соцдоказательство отсутствует. Фикс: если будут донаты — показывать счётчик; если нет — добавить текст «Проект используют N человек в месяц» (из Метрики)."

"index.html:1 — слоган не сформулирован. Пользователь видит «БАДы: доказательства и механизмы» — это описание, не ценность. Фикс: добавить подзаголовок «Без маркетинга: 130 добавок с грейдами A-D и ссылками на PubMed»."
