# Product Audit

Триггер: "проведи product audit", "аудит UI/UX", "product-аудит".

## Жёсткие правила

1. НИЧЕГО НЕ УДАЛЯЙ И НЕ МЕНЯЙ в проекте
2. Единственный создаваемый файл — reports/PRODUCT_AUDIT.md
3. Работай в режиме read-only
4. Все находки: файл + строка + что не так + как исправить
5. Не додумывай: если не нашёл — так и пиши

## Что проверять

### 1. UI/UX (docs/*.html, docs/style.css)

Консистентность:
- Все страницы имеют одинаковый набор кнопок в .actions
- Футеры байт-идентичны (кроме активных ссылок)
- Заголовки одного размера и шрифта
- Кнопки одного размера и стиля
- Hover и focus состояния у всех кликабельных элементов

Читаемость:
- Контраст текста к фону (light и dark)
- Размер шрифта >=14px для основного текста
- Межстрочный интервал >=1.4
- Нет текста, уходящего за экран
- Alt-атрибуты у всех img

Доступность (a11y):
- Фокус виден (outline)
- aria-label на иконочных кнопках
- Семантические теги (header, nav, main, footer)
- Язык страницы (lang=ru)

Навигация:
- На каждой странице нет ссылки на себя
- Битых ссылок нет
- Внешние ссылки с rel=noopener

### 2. Маркетинг

Meta и SEO:
- title 40-60 символов, уникальный на каждой странице
- meta description 120-160 символов
- og:title, og:description, og:image
- twitter:card
- rel=canonical

CTAs:
- На главной есть призыв к действию
- Кнопки Начни, Узнай, Сравни — есть или нет
- Ведёт ли пользователь куда-то логично

Ценность:
- Понятно ли за 5 секунд что за сайт
- Есть ли чем это мне поможет
- Есть ли социальное доказательство

Sharing:
- При шаринге URL превью нормальное
- og:image существует и открывается

### 3. QA (tests/, docs/*.js)

Покрытие тестами:
- Какие функции и сценарии не покрыты
- Есть ли тесты на критичные пути (форма, сравнение, поиск)
- Нет тестов на analyze_coi.py, graph_interactions.py, build_api.py

Edge cases:
- Обработка ошибок в fetch() на фронте
- Обработка пустых массивов и null
- Валидация форм
- Что если data.json не загрузился

A11y testing:
- Клавиатурная навигация (Tab, Enter, Escape)
- Работа с screen reader

### 4. Mobile (docs/*.html, docs/style.css)

Viewport:
- meta name=viewport на всех страницах

Touch targets:
- Кнопки >=44x44px
- Ссылки в навигации >=40px высотой
- Достаточные отступы

Шрифты:
- Основной текст >=16px
- Заголовки адаптируются
- Нет fixed width

Layout:
- Нет горизонтального скролла
- .quick-links адаптируется
- Модалки помещаются в экран
- Таблицы скроллятся

Media queries:
- Есть на 320px, 375px, 600px, 900px, 1200px

## Формат отчёта reports/PRODUCT_AUDIT.md

Структура отчёта:

    # PRODUCT AUDIT — brain-25-evidence
    Дата: YYYY-MM-DD

    ## Сводка
    - UI/UX: X находок
    - Marketing: Y
    - QA: Z
    - Mobile: W
    - Всего: N

    ## КРИТИЧНОЕ (ломает UX)
    - [UI/UX] файл:строка — описание

    ## ВАЖНОЕ (снижает качество)
    - [Mobile] файл:строка — описание

    ## ЖЕЛАТЕЛЬНОЕ (можно отложить)
    - [Marketing] файл:строка — описание

    ## Рекомендации
    ### Сделать сейчас
    ### Сделать позже
    ### Игнорировать

## Что НЕ проверять

- Вкус (красиво или некрасиво)
- Дизайн-систему
- Маркетинговую стратегию
- Микроанимации
