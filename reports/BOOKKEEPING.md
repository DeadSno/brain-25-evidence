## Метод

Ручная сверка, **один файл — один агент, строго последовательно**
(правило наложено после параллельного прогона, см. techdebt #86).
Для каждой записи из `## Открыто`:

1. перепроверка факта на текущем HEAD (перемер счётчиков, чтение файла по указанной строке);
2. поиск закрывающего коммита через `git log -S"<литерал>" -- <путь>` / `git log --grep="<ID>"`;
3. хеш засчитан **только** если `git log --oneline` его реально напечатал;
   отдельно сверен ещё раз вызовом `git log --oneline -1 <hash>`.
4. если закрытие не доказано — запись остаётся открытой.

Правки: строка переносится из `## Открыто` в `## Закрыто` с хешем и датой,
в шапке обновляются счётчики `Открыто` / `Закрыто`.

`pytest` прогоняется pre-commit хуком при **каждом** коммите:
`1070 passed, 235 skipped, 6 deselected` = **1076 passed** (стоп-порог соблюдён,
6 деселектов = 2 live-docs теста на 6 кейсов; `docs/version.json` = 1311).
