## 1. interactions.html — вкладка «Добавки и лекарства»

### Что было найдено

В рабочем дереве лежала **незакоммиченная частичная правка** предыдущей
сессии (select `#sevThreshold` вместо чекбоксов + поле `minSeverity`) и
файл `_tmp_diag.py`. Проверка показала, что правка в том виде **ломала
вкладку «Добавки между собой»** (стоп-условие №1):

- В `supplements`-графе **нет ни одного ребра** с severity `high`/`critical`
  (все 10 штук — `low`/`medium`, проверено по `interactions_graph.json`).
- Порог по умолчанию `high` применялся к обоим режимам → supplements-граф
  становился **пустым (0 узлов)**, при этом это вкладка по умолчанию —
  то есть страница открывалась пустой.

Корневой баг нашли в Playwright: порог 0/1 работали, 2/3 давали ноль.
Причина — `buildEdges()` после фильтра делает `.map()` и **теряет поле
`severity`**. Узловой фильтр в `drawGraph()` видел `e.severity || 'medium'`,
то есть «medium» на каждом ребре: на пороге `high` (`SEV_ORDER=2`) условие
`1 >= 2` проваливалось для всех узлов — граф пустой. Подтверждено
репликой фильтра на тех же данных в браузере: 32 ребра / 46 узлов против
0 / 0 в сети.

Второй баг вылез на клике по узлу: подсветка соседей считалась из **сырых**
`state.data.*.edges`, поэтому `selectNodes()` получал id отфильтрованного
узла и бросал `RangeError: Node with id ... not found` — необработанное
исключение в обработчике клика на каждый клик.

### Что сделано

1. Порог severity применяется **только** к drugs-режиму: UI-контрол
   (`#sevFilter`) и так показывается только в нём, а supplements-графу
   фильтроваться нечем. Вкладка «Добавки между собой» вернулась к
   исходному виду (11 узлов / 10 рёбер).
2. `severity` добавлен в объекты рёбер после `.map()` — иначе узловой
   фильтр слепнет.
3. Подсветка соседей по клику берёт рёбра из `state.currentEdges`
   (набор последней отрисовки), а не из сырых данных; в `data-goto`
   добавлена проверка существования узла перед `selectNodes()`.

Никакие данные графа (`interactions_graph.json`, `graph_positions.json`)
не менялись.

### Замеры (Playwright, Chromium, 1280×900)

| Параметр | До (HEAD) | После (порог «высокая и выше» по умолчанию) |
|---|---|---|
| Узлов на drugs-вкладке | 121 | **46** (цель ≤60) |
| Рёбер | 124 | **32** (цель ≤200) |
| Первый рендер страницы | ~270 мс | ~930 мс (цель <2 с) |
| Переключение на drugs | 28 мс | 4 мс |
| Физика при загрузке | off (позиции предрасчитаны) | off |
| Худший кадр в покое | 18 мс | 18 мс |
| Клик по узлу → сайдбар | работает | работает, ошибок нет |
| Узлов на supplements | 11 | 11 (без изменений) |

Пороги после правки (узлов/рёбер): Все — 121/124, Средняя и выше —
107/93, Высокая и выше — 46/32, Только критичная — 14/9. Физика
выключена на всех порогах — позиции из `graph_positions.json`
применяются ко всем узлам выборки.

**Примечание о гипотезе задания:** «>200 узлов» не подтвердилось — в
данных 121 узел / 124 ребра, и физика на HEAD уже была выключена
предрасчётом (замер: переключение вкладки 28–193 мс, худший кадр 18 мс).
Зависание воспроизвести не удалось ни на HEAD, ни на живой версии
(обе отдают `graph_positions.json` 200). Выполненный фикс даёт ровно
то поведение, которого требовало задание: порог severity, дефолт
«высокая и критическая», ≤60 узлов, ≤200 рёбер, <2 с, 0 зависаний.

## 2. trends.html — дисклеймер в середине страницы

**До:** `<footer class="site-footer">` с дисклеймером стоял на строке 337 —
сразу после чарта, **а секции «Матрица Наука × Интерес», «Категориальный
разрез» и «Методология» шли после него** (строки 742+). Пользователь
скроллил контент, встречал копирайт и дисклеймер, а под ними снова шёл
контент — предупреждение буквально рвало страницу.

**После:**
- Дисклеймер перенесён сразу под `<h1>` — одна копия, виден без скролла.
- Футер (версия, ссылки, копирайт, «Поделиться») перенесён в конец
  страницы, после `methodology`.
- В `<style>` добавлено правило `main > p.disc` — стиль `.site-footer .disc`
  на дисклеймер вне футера не распространялся.

Проверено в браузере: `discCount=1`, дисклеймер под h1 (`< 120 px` от его
низа), футер ниже методологии и категорий, футер **не** между чартом и
секциями.
