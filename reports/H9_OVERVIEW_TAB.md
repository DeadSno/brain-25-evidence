# H-9 — вкладки «Калькулятор» и «Сравнение» слиты в «Обзор»

Ветка: `v5.6.5-dev` · дата: 2026-10-22

## Что сделано

В Hactar было три вкладки: «Связи», «Калькулятор», «Сравнение».
Когнитивная нагрузка от трёх переключений ради одного набора данных
высока: дозы и сравнение живут об одном и том же выборе галочек.
H-9 оставляет **две** вкладки — «Обзор» и «Связи» — а весь набор
данных собирает в «Обзоре» на одной прокручиваемой странице.

### Разметка (`docs/hactar.html`)

* Табы: `data-mode="overview"` («Обзор», активна по умолчанию) и
  `data-mode="links"` («Связи»). Табы «Калькулятор» и «Сравнение»
  удалены.
* Новая панель `data-panel="overview"` с четырьмя секциями,
  разделёнными `<hr>`:

  | # | Секция (h2) | Наполнение |
  |---|-------------|------------|
  | 1 | Сводка стека | плитки: добавок в стеке, средний грейд, с грейдом A |
  | 2 | Дозы и нормы | разметка калькулятора из H-7 (строки с полями ввода + «Итог») |
  | 3 | Сравнение | разметка сравнения из H-8 (таблица side-by-side / карточки) |
  | 4 | Где купить | чипы Ozon / Wildberries / Яндекс.Маркет для каждой выбранной добавки |

* Уровни заголовков выровнены под новую иерархию: h1 → h2 (секции) →
  h3 («Дозы выбранных добавок», «Сравнение добавок») → h4 («Итог»).
* Классы чипов магазинов переименованы `.hactar-compare-shop(per)` →
  `.hactar-shop-chip(s)`: их использует и таблица сравнения, и новая
  секция «Где купить», имя с «compare» вводило бы в заблуждение.
* Новые классы: `.hactar-overview`, `.hactar-ov-section`, `.hactar-ov-title`,
  `.hactar-ov-sep`, `.hactar-ov-summary`, `.hactar-ov-stat(-label/-value/-sub)`,
  `.hactar-ov-buy`, `.hactar-ov-buyrow`, `.hactar-ov-buyname`.

### Логика (`docs/hactar.js`)

* `TAB_PARAM = {overview: 'overview', links: 'graph'}`, `DEFAULT_MODE = 'overview'`.
* `modeFromUrl()`: `?tab=graph` → «Связи», `?tab=overview` → «Обзор»,
  **старые `?tab=calc` и `?tab=compare` → «Обзор»**. Адрес при этом
  переписывается на `?tab=overview` через `replaceState` (без новой
  записи в истории) — иначе ссылка осталась бы вести на несуществующую
  вкладку. Остальные параметры (`?ids=`) сохраняются.
* `renderCalc` и `renderCompare` не тронуты по логике: их контейнеры
  (`#hactarCalc`, `#hactarCompare`) переехали внутрь панели «Обзор».
  Перерисовка теперь привязана к режиму `overview` вместо `calc`/`compare`.
* Новая `renderOverview(ids)`: показывает/прячет блок обзора, рисует
  сводку (`renderOverviewSummary`) и «Где купить» (`renderBuy`).
* `renderBuy` строит чипы магазинов для каждой выбранной добавки;
  форма выпуска подтягивается из `data.json`, когда тот загрузится
  (`ensureCompareData` перерисовывает секцию).

### Побочная правка (баг H-7, найден при проверке)

`loadCalcData()` помечал себя загруженным **до** завершения `fetch` и
не кэшировал промис. Второй и третий вызовы (быстрые клики по
галочкам) получали `Promise.resolve(null)` — список доз строился по
пустым данным, а последняя перерисовка (по первому промису, который
резолвился последним) откатывала список к **одному** id вместо всех
выбранных. Исправлено: промис кэшируется (`calcDataPromise`), а список
строится по текущему выбору (`selectedIds()`), а не по ids из момента
вызова. Баг был и до H-9, но в «Обзоре» список виден сразу, поэтому
бросается в глаза.

### Редиректы

* `docs/calculator.html`: `?tab=calc` → `?tab=overview` (meta refresh +
  canonical).
* `docs/compare.html`: `?tab=compare` → `?tab=overview` (meta refresh +
  canonical).
* Кнопка «+ Сравнить» на карточках добавок (`docs/sup/*.html`,
  `docs/script.js`, `docs/map.html`) ведёт на `?tab=compare&ids=…` —
  эти 133 ссылки не переписывались: новый JS принимает старый параметр
  и сам открывает «Обзор», сохраняя `ids`.

### Service worker

`docs/sw.js`: `CACHE_VERSION` v116 → v117. `hactar.html` входит в
`STATIC_ASSETS` без `?v`, поэтому без бампа `activate` не почистит
`v116-static` и возвратные посетители получили бы старую страницу
с тремя вкладками.

### Тесты

* `tests/test_tabs_interaction.py`: для hactar теперь 2 вкладки,
  режимы `overview`/`links`, активна по умолчанию `overview`.
* `tests/test_mobile_375.py`: 3 таба → 2.
* Снапшоты `interactions` и `calculator` (обе страницы редиректят на
  `hactar.html`) пересняты: `UPDATE_SNAPSHOTS="interactions,calculator"`.
