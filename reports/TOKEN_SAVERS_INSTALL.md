## 4. mcp-triage: разведка, рекомендация

**НЕ установлен** — только разведка, как указано в задании.

### Что это

Плагин маршрутизации MCP: отключает **все** MCP-инструменты в главной сессии и
направляет их в субагентов по ключевым словам. Экономия ~50K токенов на 6 MCP
(по измерениям автора).

### Характеристики

| Параметр | Значение |
|---|---|
| npm versions | 0.7.0, 0.9.0 (latest) |
| Совместимость | OpenCode 1.14+ (v2.0.24 ✅) |
| Stars / Forks | 1 / 1 |
| Отключает MCP | ✅ все, в главной сессии |
| Маршрутизация | Ключевые слова → субагенты |
| Конфигурация | Автоматическая (tools: {"server_*": false}) |

### Рекомендация: **НЕ ставить**

**Причины:**

1. **Отключает все MCP в главной сессии.** Для аудитов (playwright, serena) это
   критично — они должны работать напрямую. triage маршрутизирует через субагентов,
   что добавляет задержку и сложность.
2. **1 star, 1 fork** — минимальное тестирование сообществом.
3. **Конфликт с существующими субагентами.** У нас уже есть `local-fast` с
   настроенными permissions. triage создаёт своих субагентов для каждого MCP,
   что может привести к конфликту.
4. **Для текущих задач не нужен.** Аудиты, замеры, работа с графом — всё требует
   прямого доступа к MCP.

### Если ставить — как

1. `npm install -g opencode-mcp-triage`
2. Проверить `/mcp-triage status`
3. Убедиться, что субагенты не конфликтуют с `local-fast`
4. Откат: `npx opencode-mcp-triage uninstall`
