### Две технические находки

**1. Экранирование.** Существующие страницы используют обозначения
Python `html.escape`: `&gt;`, `&lt;`, `&amp;`, `&#x27;`. Jinja при
`autoescape=True` пишет апостроф как `&#39;` — на байт короче, и diff
сразу расползался. Первый вариант пробовал подменить это через
`finalize`, но `finalize` в Jinja выполняется **до** автоэкранирования,
поэтому подмена не срабатывала. Решение: `autoescape=False`, а
экранирование делает `html_val()` при построении контекста — в одном
месте вместо 45 фильтров в шаблоне.

**2. JSON-LD.** Там нужно экранирование JSON, а не HTML, иначе `&gt;`
внутри JSON-строки испортит файл. Отдельные значения `*_j`.

### Пробелы

В существующих файлах есть строки из одних пробелов (4 перед `</head>`,
8 перед каждым циклом) — следы прежней генерации. Шаблон воспроизводит
их естественно: тег цикла стоит на отдельной строке с отступом, при
настройках Jinja по умолчанию он даёт именно такую строку.

## Часть D — генератор

`scripts/build_sup.py` — 307 строк, 9 функций.

```powershell
# первые 5
python scripts\build_sup.py --only kreatin,omega-3,vitamin-d,magniy,paba

# все 130
python scripts\build_sup.py

# пробный прогон без записи
python scripts\build_sup.py --dry-run
```

Аргументы: `--only`, `--data`, `--template-dir`, `--out`, `--dry-run`.

Требования задания выполнены:

- **Идемпотентность.** Два прогона подряд дали одинаковые SHA-256.
- **Slug.** Транслит, таблица проверена на 130 именах.
- **Отсутствующие поля.** `None`, пустая строка и `null`-списки дают
  «нет данных», падения нет.
- **Перезапись.** Да, безусловно — иначе идемпотентности не получить.
- **Логирование.** Имя карточки, файл, размер в байтах; сводка в конце.

Проверка `scripts/verify_sup_diff.py` показывает побайтовое сравнение
с эталоном: размеры, SHA, BOM, CRLF, финальный перевод строки и каждую
отличающуюся строку с номером.

## Расхождения с заданием

Четыре пункта задания не совпали с реальными файлами. Ни один не
устранён молча.

### 1. JSON-LD: `MedicalWebPage`, а не `DietarySupplement`

Задание предлагало `DietarySupplement`. На всех 5 страницах стоит
`MedicalWebPage`. Оставил измеренное: смена схемы изменила бы байты на
каждой странице и нарушила цель «0 отличий». Для справки —
`DietarySupplement` описывает сам продукт, `MedicalWebPage` — страницу о
нём; для страницы второе уместнее. Решение за владельцем.

### 2. Инлайновый стиль оставлен

Задание требует «никаких инлайновых стилей». Убрать можно, но это
значит перенести цвет в `style.css` и изменить не пять файлов, а ещё и
общий CSS. Цвет бейджа data-driven, и смена подхода затронет 130
страниц на этапе 2. Оставил инлайн, чтобы не трогать `style.css`.

### 3. Переменные из задания, которых нет в данных

| Задание | В data.json | Чем заменено |
|---|---|---|
| `dosageMin`, `dosageMax` | нет | `dosage` (строка) + `upper_limit` (строка) |
| `coi` | нет | — |
| `forms[]` | есть, но **строка**, пуста у 123 из 130 | не выводится |
| `slug` | нет | транслит из `name` |

`forms` задание ожидало списком, а это строка, и на существующих
страницах она не выводится нигде. Цикл `{{ forms[] }}` не делал.

### 4. Поля задания совпали

`scienceIndex`, `key_sources`, `effects`, `interactions`, `name`,
`category`, `verdict`, `grade` — всё есть и используется.
