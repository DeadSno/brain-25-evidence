## NMN (grade C, «не подтверждено»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Предшественник NAD+ — «молекула молодости»; метаболизм, силу и мышцы у людей не улучшает. | PMID 42514320 (метаболизм не меняется); PMID 40275690 (мышечная масса/сила без эффекта); mechs «не подтверждён». |
| who_needs | Не определена: у здоровых пользы для глюкозы/липидов/мышц нет; слабые сигналы — только у пожилых и с ранними метабол. рисками. | PMID 42514320 (сигналы ДАД/HOMA-IR у пожилых/с метабол. риском); PMID 39531138 (у здоровых нет пользы). |
| onset | С 14 дней до 24 недель (250–2000 мг/д) метаболизм не менялся; «омоложения» нет. | PMID 42514320 (дозировки/длительности); PMID 39531138 (курсы 14 дн–12 нед без влияния). |
| myths | «Молекула молодости» — у людей глюкоза/липиды/мышцы не улучшаются (МА 2024-2025). «Дорого — значит работает» — дозозависимого эффекта нет. | PMID 39531138, PMID 40275690 (нет пользы); PMID 42514320 (без дозозависимых метаболических сдвигов); dosage «дорого». |
| food_sources | NMN в еде не практично: следовые количества (брокколи, авокадо); добавки — единственный рабочий путь. | Нет данных в abstracts — «не практично» из-за отсутствия пищевых источников в рабочей дозе. |
| guidelines | SR 2026 (15 РКИ, GRADE): курсы переносимы; широких метаболических преимуществ нет; «омоложение» не подтверждено. | PMID 42514320 (15 РКИ, GRADE, переносимость, нет метаболической пользы); caution (долгосрочные эффекты не изучены). |
| how_to_choose | Если пробовать: 250–1000 мг/д (дозы РКИ) короткими курсами; метаболического эффекта ожидать не стоит. | dosage карточки (250–1000 мг/д); caution (эффективность не подтверждена). |

## Гиалуроновая кислота (grade C, «зависит от контекста»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Полисахарид суставов и кожи; работает в виде инъекций при артрозе, перорально данных нет. | PMID 26475434 (инъекции при OA голеностопа); caution (перорально РКИ с исходами нет). |
| who_needs | Артроз колена/голеностопа (инъекции); пероральная форма — только надежда на кожу, пользы в РКИ нет. | PMID 26475434 (анkle OA — инъекции); PMID 41629990/40069655 (knee OA); caution (кожа слабо). |
| onset | Инъекции: эффект на боль виден месяцы (6 мес, −12% AOS); БАД — эффект не показан. | PMID 26475434 (AOS −12% на 6 мес); caution (перорально нет данных). |
| myths | «Пьём — и суставы смазаны» — перорально пользы в РКИ не показано. «Лучше плазмы» — нет: PRP превосходит ГК по WOMAC (МА 2026). | PMID 41629990 (L-PRP/LP-PRP > ГК по WOMAC); caution (перорально нет исходящих РКИ). |
| food_sources | Из еды не набрать: рабочих доз ГК в продуктах нет; в курином бульоне и хрящах количества мизерные. | Данных в abstracts нет — «не набрать» по отсутствию пищевых источников рабочих доз. |
| guidelines | Cochrane 2015: инъекции ГК слабо помогают при артрозе голеностопа. МА 2026: PRP эффективнее ГК. Перорально данных нет. | PMID 26475434; PMID 41629990; caution. |
| how_to_choose | Пероральная форма смысла не имеет (данных нет); инъекции — обсуждать с врачом, PRP эффективнее по WOMAC. | PMID 40069655 (42 РКИ: PRP лучше VAS/WOMAC); caution. |

## SAMe (grade B, «работает»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Донор метильных групп; помогает при депрессии (адъювант), боли при остеоартрозе и поддержке печени. | PMID 16021987 (депрессия); PMID 19821403 (OA); PMID 39519500 (печень). |
| who_needs | Взрослые с депрессией (дополнение к терапии); при остеоартрозе — мягкое обезболивание; при патологии печени. | PMID 16021987 (adjuvant therapy); PMID 19821403 (knee/hip OA); PMID 39519500 (liver). |
| onset | Депрессия: улучшение в первые недели; боль при артрозе — малый сдвиг к 1–3 мес. | PMID 16021987 (short-term trials); PMID 19821403. |
| myths | «Мгновенно поднимает настроение» — при большой депрессии эффект отсрочен. «Безобиден при биполярке» — риск мании, только с врачом. | PMID 16021987 (короткие РКИ, отсроченно); caution (риск мании при биполярном). |
| food_sources | Из еды напрямую не набрать — синтезируется организмом из метионина (яйца, рыба, бобовые). | SAMe — эндогенная молекула; пищевых источников в рабочих дозах нет (из abstracts не следует иного). |
| guidelines | Cochrane 2009: боль при артрозе −0.4 см VAS, функция та же. Печень: 1000–1200 мг/д улучшает параметры (SR 2024). | PMID 19821403 (SMD −0.17, 0.4 см VAS); PMID 39519500 (1000–1200 мг/д, НЯ редкие). |
| how_to_choose | Кишечнорастворимые формы, 400–800 мг/д натощак; при депрессии/биполярке — только с врачом. Дорого. | dosage карточки (400–800 мг/д натощак, кишечнорастворимые); caution (биполярка, цена). |

## Глутамин (grade C, «зависит от контекста»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Условно-незаменимая аминокислота; в реанимации эффект спорен, для спорта/мышц данных с исходами нет. | PMID 25199493 (критические состояния — противоречиво); caution (спорт — без клинических исходов). |
| who_needs | Только в клинике как условно-незаменимый при критических состояниях (по назначению); здоровым — не показан, пользы нет. | PMID 25199493 (conditionally essential); caution. |
| onset | Мгновенного эффекта нет; в клинике дни-недели, польза не подтвердилась в крупных РКИ. | PMID 25199493 (2 крупных РКИ без пользы). |
| myths | «Строит мышцы» — у здоровых с полноценным питанием не работает. «Спасает кишечник и иммунитет» — только в клинике, и то спорно (Cochrane 2014). | mechs «слабо/маркетинг»; PMID 25199493. |
| food_sources | Красное мясо, птица, рыба, молоко, йогурт, бобовые — главные источники; при обычном питании дефицита нет. | PMID 25199493 (обильная в здоровом теле — не незаменимая при достатке). |
| guidelines | Cochrane 2014: в реанимации польза не подтверждена; недоношенные (2001) — без эффекта; для спорта рекомендаций нет. | PMID 25199493; PMID 11687112 (недоношенные: RR 0.73, без разницы). |
| how_to_choose | Не нужна здоровым людям при полноценном питании; в клинике используйте препараты по назначению врача, не БАД. | PMID 25199493; dosage (5–10 г/сут — только в клинике). |

## Глюкозамин + хондроитин (grade C, «зависит от контекста»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Субстраты хряща при остеоартрозе; эффект небольшой, близкий к плацебо; хондроитин чуть сильнее. | PMID 25629804 (хондроитин — сдвиг 10%); PMID 29713967 (глюкозамин — маргинально); mechs «маркетинг». |
| who_needs | Артроз колена: скромное облегчение боли в первые месяцы; при выраженном износе и ожирении — не замена лечению. | PMID 25629804 (боль <6 мес); PMID 29713967 (knee OA). |
| onset | Эффект курсовой: боль ниже в первые 6 месяцев, к году эффект стирается (43 РКИ). | PMID 25629804 (43 РКИ, <6 мес значимо; >6 мес — нет). |
| myths | «Восстанавливает хрящ» — регенерации в РКИ не доказано. «Действует как ибупрофен» — эффект мал и близок к плацебо, к году стирается. | PMID 25629804; PMID 29713967 (WOMAC незначим). |
| food_sources | Костные бульоны, хрящи, креветки; в рабочих дозах из еды не набрать — проще добавка. | Дозы 1500+1200 мг (dosage) из еды недостижимы; данных в abstracts нет. |
| guidelines | Cochrane 2015: хондроитин — боль ниже первые 6 мес. Глюкозамин ≈ плацебо, кроме Rotta (Cochrane 2005, LOW). | PMID 25629804 (10% сдвиг, NNT≈5); PMID 15846645 (Rotta-препарат лучше; качество LOW). |
| how_to_choose | Хондроитин 1200 мг или глюкозамин сульфат 1500 мг (не гидрохлорид); курс 3–6 мес; нет эффекта — бросить. | dosage карточки (1500+1200, 3–6 мес); caution (сульфат > гидрохлорид; Peto OR 0.40). |
