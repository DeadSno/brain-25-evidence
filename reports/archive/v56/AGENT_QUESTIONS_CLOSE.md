## 1. Конфиг сохранён в репозитории

Решение №2 применено. Три параметра записаны через `git config` (без
`--global`), то есть в `.git/config` этого клона:

```
$ git config --local --show-origin --list | Select-String "http\."
file:.git/config   http.version=HTTP/1.1
file:.git/config   http.lowspeedlimit=0
file:.git/config   http.lowspeedtime=999999
```

Проверено, что это **локальный** конфиг, а не глобальный:

```
$ git config --global --list | Select-String "http\."
(no http.* in global - good)
```

`http.version` и снятие low-speed аборта. Лишний параметр в конфиге только

Замечания к #95 на будущее: снятие маски вряд ли потребует пересъёмки всех 69
эталонов. Плашка теперь прячется сама за ~800 мс, до момента съёмки, то есть
в кадр она не попадает. Маску держали ради изменчивой ширины полоски
прогресса, а при выключенной стабилизации этой изменчивости больше нет.
Так что сначала стоит снять маску и прогнать снапшоты — возможно, они окажутся
зелёными без единой пересъёмки. Оценка «69 эталонов» в строке техдолга
взята из исходной постановки, а не из замера.

Одно рабочее наблюдение на будущее: и #94, и снятие маски меняют высоту
страницы, а значит снова сдвинут полностраничные снимки. Стоит планировать их
вместе, одной пересъёмкой.

`oxipng` не устанавливался (решение владельца), поэтому эталоны остались
несжатыми — 45,6 МБ на 73 файла. Пуши теперь проходят, но каждый следующий
тянет эти мегабайты; если это начнёт мешать, сжатие — самое дешёвое лечение.
