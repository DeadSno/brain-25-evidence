## 2. Что оставил и почему

**Числа не трогал.** 49 из 49 числовых утверждений README сходятся с
данными — это подтверждено в `README_FIX.md` §1 и задание прямо запрещает
их менять. Правки в `git diff` затрагивают пять строк, ни одна цифра в
них не менялась, кроме замены неверных 37 → 118.

**Описание парсеров не перенёс в `scripts/`.** В README теперь
перечислены реальные файлы `src/`. Куда именно делись парсеры PubMed /
OpenAlex / ClinicalTrials (по одному скрипту на источник в `scripts/`
плюс чтение данных в `app.py`) — это вопрос структуры документации, а
не фактическая ошибка. Записал в п. 3.1.

**Фразу про отсутствие git-тега сохранил.** В `CHANGELOG.md:7–8`
сказано прямо: «Тег не поставлен — это решение владельца». Это факт, а
не ошибка, и он объясняет, почему версия в README не совпадает с тегами.

**«Плюс внутренние хелперы» в п. 1.4 не трогал.** Это оговорка о том,
что помимо render-точек есть вспомогательные вызовы; она
по-прежнему верна. Менял только число.

**Гиалуронку из примечания не убрал.** Задание предлагало заменить
пример на омега-3. Оставил оба: омега-3 как лидера по индексу, гиалуронку
как иллюстрацию перекоса. Причина — в замене «инъекционные формы» было бы
единственным примером, и тезис о лекарственных формах потерял бы
конкретное подтверждение. Если владелец хочет ровно один пример, это
правка одной фразы.

## 3. Вопросы владельцу

1. **`src/parsers.py` — куда делись парсеры?** Я перечислил реальные
   файлы `src/` и не стал переносить описание PubMed / OpenAlex /
   ClinicalTrials в блок `scripts/`. Нужно ли там дописать
   `fetch_papers.py`, `fetch_metrics.py`, `enrich_trials.py` с
   фактическим разделением обязанностей, или оставить как есть?

2. **Формулировка про омега-3.** Я написал: «её индекс нельзя читать как
   объём доказательств именно перорального приёма». Это осторожная
   формулировка — она не утверждает, что литература по омега-3 включает
   непероральные формы, но и не отрицает этого. Если причина раздува
   известна (например, конкретные формы), стоит назвать её прямо.

3. **SCImago и лицензия CC BY-NC.** В `DATA_SOURCES.md:147` сказано, что
   CC BY-NC «ок для проекта», но строки 143–145 признают: артефактов
   SCImago в репозитории нет, число 32 045 журналов проверить нечем. То
   есть лицензия в README заявлена для данных, которых физически нет в
   поставке. Стоит ли смягчить формулировку или это приемлемо как
   отсылка к источнику?
