| who_needs | Лёгкая-умеренная депрессия, когда хочется избежать побочек СИОЗС; противопоказан при тяжёлой депрессии и суицидальности. | PMID 28064110 (эффективен при mild-to-moderate; при тяжёлой/суицидальности данных нет); caution. |

| about | Полифенол винограда: улучшает биомаркеры (липиды, глюкоза), клиническая ценность не доказана. | PMID 41987155 (umbrella: биомаркеры, не исходы); caution (клинические исходы незначимы). |
| who_needs | СД2 (АД, холестерин, инсулинорезистентность) и ожирение (талия); здоровым — без эффекта. | PMID 41987155 (СД2: АД/холестерин; талия); PMID 33480264. |

| myths | «Как бокал вина» — French paradox маркетинг, в вине дозы копеечные. «Антивозрастной» — у людей биодоступность ~0, БАД 50 мг далеки от доз РКИ. | caution (биодоступность низкая, French paradox — маркетинг); PMID 41987155 (дозы РКИ 500+ мг). |

| how_to_choose | Только при СД2/избыточном весе: 100–500 мг из РКИ; обычные БАД 50–100 мг смысла не имеют. | dosage (100-500 мг); caution (в БАДах 50-100 мг — мало). |

| about | Силимарин стабилизирует мембраны гепатоцитов; маркеры улучшает, клиническая значимость спорна. | PMID 17943794; PMID 40552569 (МАСЛД); caution. |
| who_needs | МАСЛД/НАЖБП (адъюнкт к образу жизни); при инсулинорезистентности у СД2 — есть данные. | PMID 40552569 (МАСЛД); PMID 39855603 (инсулин-резистентность СД2). |

| myths | «Восстанавливает печень после алкоголя» — общая смертность не снижает (RR 0.78). «Сахар всем» — HOMA-IR падает только у СД2, при НАЖБП нет. | PMID 17943794 (RR 0.78 NS на смертность); PMID 39855603 (только СД2, не NAFLD). |
| food_sources | Обычные семена годятся лишь для чая; клиническая доза — стандартизованный силимарин 420 мг. | dosage (420 мг силимарина/сут). |

| how_to_choose | Силимарин 420 мг/сут (не порошок), курсы месяцами; при жалобах — сначала диагностика печени. | dosage; caution (сначала диагностика). |
