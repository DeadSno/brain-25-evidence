# Архив отчётов brain-25-evidence

Отчёты сгруппированы по релизам. Файлы не удалены — перенесены из `reports/`
после закрытия релиза.

**Почему архив, а не удаление.** Попарный Jaccard по 8-граммным шинглам внутри
семейств (V560, ROADMAP, MIGRATION) даёт максимум **0.023** — файлы не являются
копиями друг друга. Это хронологические логи: каждый следующий документ
фиксирует новое состояние. Удаление «как дубль» уничтожило бы историю
релиза, а не почистило репозиторий.

## Структура

| Каталог | Релиз | Содержание |
|---|---|---|
| `v550/` | v5.5.0 и предшествующие (v5.4.x) | Отчёты V550\*, V541\*, V542\*, MIGRATION\*, V540\* |
| `v560/` | v5.6.0 | Отчёты V560\*, ROADMAP-логи правок, ROADMAP_NEW |
| `v561/` | v5.6.1 | Отчёты V561\*, DOCS_CLEANUP_AUDIT |

## Правила

- **Ничего не удалено.** Всё в `reports/` и в этом архиве — полная история.
- Актуальный план проекта — корневой `ROADMAP.md`. Файлы `ROADMAP_V*`,
  `ROADMAP_UPDATE*` в архиве — исторические логи, не канон.
- Ссылка на отчёт из `ROADMAP.md` может указывать на архивный путь
  (`reports/archive/v560/...`). Канонический `ROADMAP.md` не перемещается.
- Новые отчёты текущего релиза пишутся в `reports/`; в архив переносятся
  после закрытия релиза.

Инвентаризация и обоснование: `reports/DOCS_CLEANUP_AUDIT.md`.
