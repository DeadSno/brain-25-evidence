# H-6 — Project Hactar: вкладка «Связи» (эго-граф, MAN-03)

Ветка: `v5.6.5-dev` · база: `bfbf0d06` (H-5) · дата: 2026-10-22

## Задача

Заменить заглушку первой вкладки Hactar на интерактивный граф связей.
Главное правило — **никаких 130 узлов**: мастер-граф (`docs/graph_data.json`,
130 добавок и 1983 ребра) рисуется только как источник рёбер, а пользователь
видит эго-сеть выбранных добавок.

### `docs/hactar.js`

1. **Мини-шина событий**: `subscribe(kind, fn)` / `emit(kind, payload)` —
   `change` (смена выбора) и `mode` (переключение вкладки). Публично:
   `window.Hactar.onChange(fn)` / `window.Hactar.onMode(fn)` — обе возвращают
   функцию отписки.
2. **Загрузка данных графа** (`loadGraphSources`, параллельно со списком):
   `graph_data.json` (рёбра), `graph_positions.json` (стартовые координаты,
   опционально — при отсутствии vis посчитает сам), `effect_labels.json`
   (русские названия мишеней). `data.json` (758 КБ, полные тексты механизмов)
   грузится лениво — только когда граф уже понадобился.
3. **Фильтрация** (`buildEgo`): из выбранных добавок собираются
   - 🟢 сами добавки (зелёные, `shape: dot`, размер 26);
   - 🟣 мишени (`теги: …` → ромбы) и механизмы (`механизм: …` → кружки) —
     из рёбер мастер-графа выбранной добавки;
   - 🟠 лекарства (оранжевые, `shape: box`) — из `interactions` в
     `data_index.json`; значение `нет данных` отфильтровывается, цвет ребра
     зависит от тяжести взаимодействия (высокий/средний/низкий риск);
   - синее ребро между двумя выбранными, если у них общие мишени или
     механизм (`sharedBasis`).
4. **Раскладка** (`placeNodes`): координаты выбранных берутся из
   `graph_positions.json` (детерминированная круговая раскладка) и
   переносятся в центр холста (220 px между крайними); остальные узлы
   расставляются вокруг своей добавки по детерминированному хэшу от id —
   поэтому кнопка «Сброс» возвращает одну и ту же картину.
5. **Физика**: `barnesHut`, `springLength: 200`, `avoidOverlap: 1`,
   `centralGravity: 0.1`, `gravitationalConstant: -3000`,
   `springConstant: 0.05`, `damping: 0.6`; стабилизация 300 итераций.
   По событию `stabilizationIterationsDone` физика выключается и граф
   «замирает» (`freezePhysics`), плюс страховочный таймер 4 с.
6. **Подсказки**: у каждого узла свой `title` (название, грейд, эффекты,
   механизм, лекарство и тяжесть взаимодействия) — vis-network показывает
   его при наведении.
7. **Реактивность**: клик по чекбоксу / `setSelection` → `emit('change')` →
   `network.setData({nodes, edges})`; возврат на вкладку «Связи» →
   `redraw()` + `fit()`; изменение размера окна → `redraw()`.
8. **Отладочный API**: `window.Hactar.graphState()` →
   `{nodes, edges, physics, ready}`.

## Нюансы реализации (важно для правок)

- **Фигура узла `dot` задана обратными кавычками** (`` shape: `dot` ``).
  `scripts/audit_classes.py` считает любой строковый литерал в `'` или `"`
  именем CSS-класса; литерал `'dot'` оживлял мёртвое правило
  `.atlas-legend .dot` в `style.css` и ронял
  `tests/test_no_orphan_classes.py::test_known_dead_list_matches_measured`.
  Обратные кавычки аудит не видит.
- **Цвет узла задаётся ключом `background`**, а не `color`. `color` — это
  стиль *рёбер*; у узла он игнорируется (узлы оставались синими).
- **Фигура `circle` не подходит**: подпись рисуется внутри круга и раздувает
  его по ширине текста. Фигура по умолчанию в vis-network 9.1.9 — `ellipse`,
  поэтому форма задаётся явно.
- `network.options()` / `getOptions()` в vis-network 9.1.9 отсутствуют —
  состояние физики отдаётся через собственный флаг `physicsOn`.

## Известные нюансы данных

- `graph_data.json` не различает типы узлов — все 130 узлов это добавки;
  цвет ноды в файле кодирует первый тег, а не роль. Поэтому роли узлов
  (`добавка / мишень / механизм / лекарство`) выводятся в hactar.js из
  заголовков рёбер и `interactions`.
- Заголовки рёбер механизмов в мастер-графе обрезаны («гамк», «воспален»);
  полные тексты берутся из `data.json` по вхождению обрезанного ключа.
- `graph_positions.json` — круговая раскладка всего мастер-графа; для
  эго-сети из неё берётся только относительное положение выбранных.
