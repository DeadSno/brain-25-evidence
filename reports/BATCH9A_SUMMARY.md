### 2b. Омега-3 `citations: 0` → `null`

Не ошибка расчёта, а **пробел в индексе**. PMID **32114706 (Cochrane 2020,
флагманский обзор) отсутствует в OpenAlex** — проверено поштучно. Два
остальных (42070013, 41870913 — статьи 2026) имеют настоящий
`cited_by_count = 0`. Сумма честная, но показывает «0 цитирований»
вместо реальных тысяч.

никогда.

`null` обрабатывается всеми тремя местами использования явно:
`script.js:118-119` → «Цитирования не рассчитаны для этой добавки»,
`:817` → `s.citations != null ? ... : ''`, `:1070` → `a.citations ?? 'нет данных'`.
Стоп-условие «null ломает UI» не сработало.

## 3. DATA-P2-06 — битый символ (`6336f68`)

`data/papers/funders.json:137571`, один U+FFFD:

```
"name": "BioCARE\uFFFDa National Strategic Research Program"
```

Восстановлено в `BioCARE2a National Strategic Research Program` — программа
Биоцентра старения Университета Тарту.

Файл **отслеживается git** (`git ls-files -- data/papers/` = 10 файлов), в
отличие от DATA-P2-05. Правка **байтовая, не через JSON round-trip**: файл
5.0 МБ / 33 789 записей, пересериализация переписала бы всё.

U+FFFD занимает 3 байта на один потерянный байт выгрузки Crossref, поэтому
восстановлен только байт между `BioCARE` и `a` — assert'ы на
`raw[i-7:i] == b'BioCARE'` и `raw[i+3:i+4] == b'a'`. Размер
5 064 684 → 5 064 682, JSON парсится.

Читают файл только `analyze_crossref.py:10,28` и `analyze_funding*.py` — на
сборку сайта не влияет.
