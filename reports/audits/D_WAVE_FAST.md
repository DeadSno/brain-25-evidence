## D1 — #49 `write_text` без `newline=` → `30d5514`

`.gitignore` для артефактов писался `Path.write_text` без `newline=`.
На Windows это даёт CRLF, и каждое падение снапшота/a11y-теста добавляло
в индекс 2 файла дифа вместо нуля — ложные «изменения» в `git status`.

- `tests/test_visual_snapshots.py` (`_write_artifacts`) — `newline="\n"`
- `tests/test_a11y_axe.py` (`REPORT_DIR`) — `newline="\n"`

Проверено: Python 3.14.7, `Path.write_text` принимает `newline`
(inspect.signature). Оба файла проходят `py_compile`. Прямой прогон
обеих сборок даёт 115 skipped — гейты `RUN_SNAPSHOTS=1` / `RUN_A11Y=1`
отключены, поведение не изменилось.

## D4 — #52 ключи guard по содержимому → `2b26464`

Самый рискованный фикс из пяти, но уложился в «средний рефактор» —
стоп-условие «сложнее, чем кажется» не сработало.

`ACCEPTED_NON_ELEMENT_GUARDS` в `tests/test_silent_handlers.py` был
ключуется парой `(имя файла, номер строки)`. Вставка 7 строк в `openModal`
сдвигала 6 записей, и тест падал про «неизвестные guard'ы» — отводя
внимание от реальной причины.

Ключ стал `(имя файла, текст guard'а)`. Тонкость: `if (!s) return;`
встречается в `script.js` **дважды** (две разные причины), поэтому
значение переведено в список причин, а stale-проверка сверяет
**количество** вхождений с числом причин:

- `found < expected` → guard исчез
- `found > expected` → новый неописанный случай с тем же текстом

Итого 14 ключей / 15 причин: `script.js` 8, `tracker.js` 3,
`science2.js` 3. `used_listed` переехал со `set()` на счётчик `{}`.

Проверено: `pytest -q tests/test_silent_handlers.py` → 4 passed.
Синтетика подтвердила 5 сценариев: полное совпадение → 0 расхождений,
исчез → «нет», прибавился → «лиш», пропал ключ → «нет»,
дубль одно-причинного guard'а → «лиш».

## D5 — #43 `.cat` opacity → `ae740ac`

Проблема: `.card .cat{opacity:.55}` на `docs/sup/index.html`
(130 статических `span.cat`) смешивала цвет категории с фоном карточки.
В светлой теме `#15803d` падал до **2.26:1** при требуемых 4.5:1
(нормальный текст 14px).

### Вариант «поднять до .75» отклонён — он не закрывает долг

Считали контраст `#15803d` над белым при разном opacity:

| opacity | контраст | AA для 14px |
|---|---|---|
| .55 (было) | 2.26:1 | ✗ |
| .75 (вариант A) | 3.20:1 | ✗ |
| .90 | 4.18:1 | ✗ |
| **1.0** | **5.02:1** | **✓** |

Единственное значение, проходящее AA — `opacity:1`. Ровно оно уже
применено к карточкам главной через `.card .cat[data-cat-group]`.

### Что сделано

Убрана `opacity:.55` из базового правила `docs/style.css:399`
(строка на момент волны D_FAST; сверка 13.10.2026: базовое `.card .cat` —
`docs/style.css:449`, там `opacity:1`, а правило с цветом
`.card .cat[data-cat-group]` — `docs/style.css:1230`).
Правило `[data-cat-group]` (цвет `--ic` + `font-weight:600`) оставлено
без изменений. Обновлён комментарий, утверждавший обратное.

Зеркалить маппинг `catGroup()` из `script.js` в Python **не стали**:
второй источник истины — тот же класс долга, что закрыли для палитр
грейдов в #38.

### Почему пересъёмки не потребовалось

`class="cat"` встречается **только** в `docs/sup/index.html` (130 шт.) —
ни в `docs/*.html`, ни в одной sup-странице. При этом `sup/index`
**отсутствует** в `PAGES` (`tests/test_visual_snapshots.py:98-102`):
там только 5 отдельных страниц (`sup/kreatin`, `omega-3`, `vitamin-d`,
`magniy`, `paba`) плюс `offline`. Ни один эталон не затронут —
стоп-условие «#43 требует пересъёмки» не сработало.
