### 1. `test_no_data_loss_live_data` — обоснована

**Что сломалось.** После закрытия DATA-P1-01 в `SUPPLEMENTS` появился
запрос для всех 130 карточек. В живых `docs/data.json` карточек без
запроса не осталось → сравнение множеств стало пустым, и тест
выродился бы в «пустое множество всегда равно пустому».

**Что сделали.** Добавили фикстуру, а не ослабили проверку
(`tests/test_build_key_sources.py:141-178`):

```python
sentinel = {"id": "sentinel-no-q", "name": NO_QUERY_NAME,
            "ma_top3": [{"pmid": SENTINEL_PMID, "title": "Kept", "year": 2024}]}
original = original + [sentinel]
...
assert before_pmids, "в данных нет карточек без запроса — тест потерял смысл"
assert before_pmids == after_pmids
```

`SENTINEL_PMID = "88888888"`. Ключевое: часовой добавлен **в сам набор**,
который проверяется, поэтому на нём срабатывает та же сверка.
Логика `before_pmids == after_pmids` (точное равенство множеств) не
тронута, защитный `assert before_pmids` сохранён. Правка **усилила**
тест: раньше он молча проходил на пустом множестве, теперь требует
непустоты.
