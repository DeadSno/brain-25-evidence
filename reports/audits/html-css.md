### Hardcoded hex (222)

**Замер.** `docs/style.css`, тот же метод, что давал базовые 139 —
`#[0-9a-fA-F]{3,6}`, все вхождения, комментарии включены.

**Где выросли.** Рост 139 → 222 (+83) дали ровно три коммита, все — Oct 8–9:

| Коммит | hex | Прирост |
|---|---|---|
| `1a8bee8` (до `fab27a6`) | 139 | база 139 из HC-P1-03 |
| `fab27a6` — UI: interactions, map, trends, feedback, index colors | 172 | +33 |
| `c3a4dda` — Яндекс.Метрика + cookie-баннер + privacy | 179 | +7 |
| `b4bb595` — audit(E) accessibility-check | 222 | +43 |

**Распределение 222 (текущее состояние — после правки: 217):**

| Категория | Было | Стало | Комментарий |
|---|---|---|---|
| OK — объявление токена (`--x: #hex`) | 56 | 56 | 15 → 56 за Oct 8–9: палитры `--grade-*-tx`, `--icon-*`, `--info-fill` |
| OK — fallback в `var()` | 0 | 0 | таких мест в файле нет вообще |
| НЕ OK — литерал в правиле | 108 | **103** | ↓ |
| Нейтрально — внутри CSS-комментариев | 58 | 58 | 13 → 58: таблицы контраста, обоснования значений |
| **Итого (метод аудита)** | 222 | **217** | |

**Ключевой вывод: цифра 222 вводит в заблуждение.** Рост — это дизайн-система
и документация, а не хардкод: настоящие литералы в правилах за это время
**уменьшились** (111 → 108 на момент `b4bb595`, 103 после текущей правки).
Метрика считает токены и комментарии наравне с хардкодом.

**Список НЕ-OK — 103, сгруппирован по причине:**

| Группа | ≈ | Почему не трогал |
|---|---|---|
| Тёмная/светлая пара захардкожена как два правила (`.sev-*`, `.favBtn.on`, `.grade.gX`, `html:not(.light)`-версии) | ~70 | Замена на токен требует нового объявления в `:root`/`html.light` — запрещено стоп-условием. Подстановка существующего токена изменила бы вторую тему: `--grade-a-tx` = `#4ade80` (тёмная) / `#15803d` (светлая), а `.grade.gA` использует именно светлое значение. |
| Одиночные фирменные цвета без токена (`#175a86`, `#3498db`, `#c0392b`, `#f1c40f`, `#fafafa`, `#1a1d21`, палитра `#22c55e`/`#3b82f6`/`#8b5cf6` в atlas) | ~32 | Токена нет — создание = правка `:root` |
| `#fff` (17) | 17 | Белый на заливке; `--text` в тёмной = `#f5f5f7`, подстановка изменила бы оттенок |
| `.s-context` `#88888833` (1) | 1 | Альфа-вариант: `--border-hover` = `#888888` без альфы, значение не совпадает |

**Исправлено — 5 вхождений (4 строки), `docs/style.css`:**

| Стр. | Было | Стало |
|---|---|---|
| 217 | `linear-gradient(135deg, #1f6fa5, #175a86)` | `var(--info-fill)` |
| 1942 | `html.light #atl-sidebar .cta { background:#1f6fa5 }` | `var(--info-fill)` |
| 2025 | `#cookieBanner .cb-accept` — background + border-color | `var(--info-fill)` ×2 |
| 2026 | `#cookieBanner .cb-accept:hover` — border-color | `var(--info-fill)` |

Это незакрытый хвост токенизации из `b4bb595`: сам токен `--info-fill: #1f6fa5`
объявлен там же и в комментарии назван единственным синим, дающим ≥ 4.5:1
в обеих темах — то есть подстановка гарантированно не меняет картинку.
`:root` и `html.light` не тронуты. Итог: 222 → 217 по методу аудита,
108 → 103 по существу.
