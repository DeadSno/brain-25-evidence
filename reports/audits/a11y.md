## Примечания

- Контраст-находки (P0-01…P1-03) закрыты одним коммитом `b4bb595` (09.10) — правки в `scripts/build_sup.py` (GRADE_COLORS), 4 новых токена `--grade-*-tx`, `--accent-2`, `--info-fill/--info-tx`, `--danger-tx`.
- P0-04 закрыт на уровне 144 `docs/*.html`; для 130 `sup/*.html` `dir` проставляется при ближайшем `build_sup` (STAGE7 `8dc3863` проставил `dir="ltr"`).
- P2-01 (пропуск уровней) осознанно оставлен как WONTFIX — см. обоснование в `STAGE2_HTML.md §D`.
- **Сверка 13.10.2026 (батч 4):** из 8 «открытых» P2 одна оказалась закрытой —
  `A11Y-P2-02` (`855d7f3`, 131/131 `docs/sup/*.html` несут `<nav class="actions" aria-label="Главная навигация">` на строке 55).
  Две находки переведены в PARTIAL (`A11Y-P2-06`, `A11Y-P2-08`), для шести открытых
  добавлены факты, проверенные на HEAD. Число открытых P2: 8 → 7, закрытых: 8 → 9.
  Ни один из ID не встречается в тексте коммитов (`git log --grep="A11Y-P2-*"` пуст) —
  закрытия доказываются по состоянию файлов, а не по имени ID.
- **Дубль ID A11Y-P1-01 (предсуществующий, не наша волна) — разрешён 14.10.2026:**
  в таблице «Закрыто» выше два разных ID — «Ссылка cookie-баннера 3.82:1» (`b4bb595`) и
  «Тап-таргеты < 44 px» (`d0867d9`, помечен ⚠️). Консолидация 11.10.2026 переиспользовала
  номер. Переименована строка **cookie-баннера: `A11Y-P1-01` → `A11Y-P1-12`**
  (следующий свободный в семействе P1). Направление выбрано по канону §2 `AUDIT_MASTER`:
  `A11Y-P1-01` = тап-таргеты (таблица «Открыто» в `mobile.md`, `OPEN_TECHDEBT.md:98,134`,
  `WAVE_D_FAST.md:48`), `A11Y-P1-10` = cookie-ссылка (`OPEN_TECHDEBT.md:54,83,135`,
  `WAVE_D_FAST_2.md:18`). Обратное переименование (46 → `A11Y-P1-10`) создало бы новый
  дубль с уже занятой строкой 55 и разорвало ссылки из 5 файлов.
  Ссылки в `OPEN_TECHDEBT.md` не затронуты: `A11Y-P1-12` в нём не встречается,
  а `A11Y-P1-01`/`A11Y-P1-10` сохранили прежние значения.
