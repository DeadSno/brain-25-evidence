## 1. Что изменено

Одна строка в `docs/version.js` плюс комментарий, объясняющий, почему гейт был
мёртв:

```diff
-    if (typeof applyFilters === 'function' && window.supplements && supplements.length) {
+    if (typeof applyFilters === 'function' && supplements.length) {
```

`script.js` не тронут — как и было указано в задании.

### Почему голый `supplements` безопасен

`applyFilters` объявлен в `script.js:462`, `supplements` — в `script.js:7`. Это
**один classic script**, поэтому если `applyFilters` существует, то `supplements`
существует тоже. Короткое замыкание `&&` не даёт коснуться несуществующей
переменной на 16 страницах, где `version.js` подключён, а `script.js` — нет.

Проверено на 6 таких страницах (atlas, faq, trends, map, graph, sup/kreatin):
версия подставилась (`2026-09-25`), `typeof supplements === "undefined"`,
`ReferenceError` — **ни одного**. `offline.html` вообще не подключает
`version.js`, там `APP_VERSION` остаётся `null` — как и было.

Полностью снести условие было бы неверно: на 16 страницах без `script.js`
`typeof applyFilters` вернул бы `false` раньше, чем условие дойдёт до
`supplements`, но голое обращение к необъявленному имени — это `ReferenceError`,
который ушёл бы в `.catch()` и записал бы в консоль путающее
«version.js не загрузился».

## 2. Проверка в браузере

Метод тот же, что дал воспроизведение бага: снести service worker и его кэши.
Без этого precache (`v67-static`) отдаёт `version.js` быстрее, чем проигрывается
гонка, и баг не виден — 8 прогонов подряд показывали 130/130 и до фикса.

```
SW снесён: {"unregistered":1, "caches":["v68-static","v68-data"]}
run 1: cards=130 dates={"2026-09-25":130} win_supp=undefined bare=130 ver=2026-09-25
run 2: то же
run 3: то же
run 4: то же
run 5: то же
run 6: то же
```

Ключевое: `win_supp=undefined` **по-прежнему**. То есть перерисовка теперь
проходит не благодаря `window.supplements`, а вопреки его отсутствию — то
есть ровно тот случай, который раньше её блокировал.

До фикса на тех же прогонах было `{"2026-09-16":81, "2026-09-23":26,
"2026-09-25":10, "2026-09-22":13}` без восстановления на горизонте 12 секунд.

Консоль: 2 ошибки и 1 предупреждение, все посторонние — блокировка внешнего
Метрики (`mc.yandex.ru`, 499 и неверный MIME) и deprecated-мета
`apple-mobile-web-app-capable`. Ничего от `version.js`.

## 3. Побочная находка: диагноз флейка `modal_index` был неверным

`MIGRATION_STEP2` записал: единственный сбой `test_modal_index_snapshot` дал
текст, начинающийся с `ht`, и автор предположил `html.className`, то есть
гонку темы.

Предположение ошибочно. `_assert_version_consistent`
(`tests/test_visual_snapshots.py:342`) начинает сообщение с URL:

```python
pytest.fail(f"{url}: дата на карточках «{info['first']}» не совпадает с "
            f"APP_VERSION.data «{info['data']}» — гонка version.js/script.js …")
```

Для `index` это `http://localhost:8000/index.html: дата на карточках…` — и
`ht` там это начало `http`. Модалка вызывает и `_await_version`, и
`_assert_version_consistent` (строки 503-504), так что этот путь вполне мог
дать тот самый сбой.

То есть флейк `modal_index` и флейк `index@1280` — тот же корень, что и строка
1, а не отдельная проблема темы. Отсюда все четыре пункта техдолга закрываются
вместе.

Отдельно отмечу: сам тест был прав, что отказывался «чинить страницу за неё».
Пока гейт был мёртв, ожидание сходимости не могло наступить, и любая помощь
из теста замаскировала бы возврат бага.

## 6. Чего этот фикс не делает

- **Не трогает сами `updated` в `data.json`.** 120 карточек по-прежнему хранят
  2026-09-16/-22/-23. Теперь это перестало быть видно, потому что дата
  берётся из `version.json`, но если `version.json` не придёт — карточки
  покажут старое значение. Чистить поле в данных — отдельная задача.
- **Не добавляет ожидание на стороне `script.js`.** Если на какой-то странице
  `version.json` придёт раньше, чем определится `applyFilters`, перерисовки не
  будет. На `index.html` это невозможно: `version.js` подключён с `defer` в
  начале, `script.js` — без `defer` в конце, то есть выполняется при разборе и
  всегда раньше отложенного сценария.
- **Не чинит офлайн.** `offline.html` не подключает `version.js` — там дат нет.
