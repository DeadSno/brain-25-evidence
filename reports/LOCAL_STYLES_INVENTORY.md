### Как считались категории (чтобы можно было поспорить)

- **C** — селектор есть в `style.css` **и** все объявленные свойства уже
  совпадают по значению. Именно «удалить без последствий».
- **B** — класс или id из селектора встречается в локальных `<style>`
  **2+ страниц**, то есть это общий паттерн.
- **A** — селектор на одной странице и его нет в `style.css`.
- **?** — сомнительные вынесены в §5, из основной таблицы убраны.

независимый набор на 5 страниц). Таблица считает 33 правила × 5 = 165, но
переносить нужно **33**: остальное — вычитание дубликата.

**Реально переносится: 255 правил**, а не 387.

## 3. Что НЕ переносится

### 3.1 `sup/*` — 33 правила, но они общие

Формально на каждой из 5 страниц 32 правила помечены B, потому что один и тот
же класс встречается в локальных стилях всех пяти. Это **не** «уникальные
правила страницы» и не «общий паттерн сайта» — это **один набор, продублированный
5 раз**. Переносится один раз в `style.css`, остальные 4 копии удаляются.

Состав (33 правила): `.sup-wrap`, `.breadcrumbs`, `.sup-header`, `.grade-badge`,
`.verdict`, `.sup-section`, `.tag`, `.mech-card`, `.mech-body`, `.mech-effect`,
`.mech-strength`, `.s-strong/.s-medium/.s-weak/.s-context`, `.inter-card`,
`.inter-low/.inter-medium/.inter-high/.inter-critical/.inter-with/.inter-sev`,
`.inter-note`, `.src-card`.

### 3.2 Локальные `h2` / `h3` — по замыслу автора

```
faq.html          h2 { font-size: 1.125rem }   h3 { font-size: 1rem }
methodology.html  h2 { font-size: 1.125rem }
index.html        h2 { font-size: 1.125rem }
map.html          h2 { font-size: 1.125rem }
```

Комментарий в коде: «Правило локальное: на остальных страницах h2 остаётся
1.3rem». В `style.css` — `h2{font-size:1.3rem;font-weight:500;margin-bottom:1rem}`.

То есть эти правила **принципиально локальные**: перенос в `style.css` изменит
типографику всех страниц, где их нет. Не переносить.

⚠️ Тут есть настоящая проблема, но она не решается выносом: `h2` переопределён
на 4 страницах из 18, причём одинаково. Это «18 страниц, а типографика h2 в трёх
вариантах» — кандидат на унификацию в **Шаге 5** (шкала шрифтов), не в Шаге 0.

## 7. Что стоит решить до миграции

1. **`:root` и токены на 4 страницах** (§4) — по условиям миграции это Шаг 3.
   До него вынос трогать нельзя, иначе получится два места с одним токеном.
2. **Инлайны (179)** — крупнее самой миграции `<style>`. Отдельная задача,
   иначе её потеряем.
3. **Локальные `h2`** — 4 страницы из 18. Не вынос, а унификация типографики,
   то есть Шаг 5.
4. **`glossary`** — 0 правил, 39 инлайнов. В списке «простых страниц» она
   стоит зря: переносить из неё нечего.
