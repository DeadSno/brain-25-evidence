## T3 — модалка: роль, подпись, ловушка фокуса, возврат фокуса

`docs/index.html:433`, `docs/script.js`.

**Было.** `<div id="modal">` без роли. Клавиатурный пользователь открывал
карточку и мог уйти из диалога на элементы страницы под ним: модалка
выглядела открытой, а фокус уже управлял невидимым интерфейсом. Кроме
того карточка — это `div` с `onclick`: ни Enter, ни Пробел её не
открывали, а после закрытия фокус падал на `<body>`, и обход Tab
начинался сначала с шапки.

**Стало.**

- `#modal` получил `role="dialog" aria-modal="true"
  aria-labelledby="modalTitle"`. Заголовку присвоен `id="modalTitle"`
  в `innerHTML` модалки — до правки атрибута не существовало, и
  `aria-labelledby` ссылался бы в пустоту.
- `trapModalFocus(e)` удерживает Tab и Shift+Tab внутри. Список
  фокусируемых собирается на каждый вызов: содержимое `#modalBody`
  перерисовывается при открытии, статический список не годится.
- При открытии фокус переносится внутрь, при закрытии возвращается на
  карточку, из которой открыта (сохраняется в `modalPrevFocus`).
- Карточка получила `tabindex="-1"`: она становится фокусируемой, но
  **не входит** в порядок обхода Tab — перебирать 130 карточек стрелками
  не нужно. Открытие с клавиатуры добавлено через `onkeydown` (Enter и
  Пробел), с проверкой, что событие пришло не от вложенных ссылок и
  кнопок.

**Замер в браузере** (`http://localhost:8000`, кеш сброшен):

```
карточка .focus()        -> true
Enter на карточке        -> модалка открыта, заголовок «Витамин D»
фокус при открытии       -> BUTTON#modalClose
Tab с последнего (12-й)  -> BUTTON#modalClose (defaultPrevented: true)
Shift+Tab с первого      -> последняя ссылка «PubMed ↗»
Escape                   -> закрыта, фокус на DIV.card (та же карточка)
```

## T4 — поиск по PMID возвращал 0 результатов

`docs/script.js`.

**Причина.** Фильтр работал по `data_index.json`, где полей PMID нет.
Индекс отдаёт только `id, name, category, code, verdict, grade,
scienceIndex, metaCount, citations, wiki, ongoing, effects, updated,
interactions, upper_limit, hedges_g`. PMID лежит в `data.json`
(`key_sources[].pmid`, 0.73 МБ), который раньше грузился только при
открытии модалки. Условие поиска проверяло `s.name` и `s.effects`, поэтому
запрос «42027564» не совпадал ни с чем — 0 результатов при непустом поле.

**Стало.** Индекс PMID строится один раз лениво и только когда запрос
похож на PMID (`/^\d{4,}$/`). Пока индекс не готов, запрос не сужает
выборку, а после догрузки `applyFilters()` перезапускается сам — пользователю
не нужно жать Enter повторно. Отказ загрузки проглатывается: поиск по
PMID не сработает, остальное не сломается.

Попутно: одинаковый код загрузки `data.json` был продублирован в трёх
местах (prefetch, openModal, сравнение) и различался только текстом ошибки.
Вынесен в общую `ensureFullData()` с единым retry.

**Замер в браузере:**

```
запрос          карточек  бейдж
(пусто)         130       (130 из 130)
магний          1         (1 из 130)
42027564        1         (1 из 130)   <- было 0
99999999        0         (0 из 130)
(сброс)         130       (130 из 130)
```

PMID `42027564` находится карточку «Креатин» — совпадает с `data.json`.

## V1 — иерархия заголовков: 21.6px против 20.8px

`docs/style.css:131` и шесть страниц.

**Причина.** Правка P2-10 была сделана локально на шести страницах
(`h2 { font-size: 1.125rem }`). `glossary` оказался единственной
страницей без своего правила и остался единственной со сломанной
иерархией: зазор h1→h2 составлял 0.8px.

**Замер до правки** (`getComputedStyle`, 10 страниц):

| Страница | h1 | h2 |
|---|---|---|
| index | 21.6 | 16 |
| **glossary** | **21.6** | **20.8** |
| faq | 21.6 | 18 |
| methodology | 21.6 | 18 |
| feedback | 21.6 | 18 |
| support | 21.6 | 18 |
| map | 21.6 | 10 |
| trends | 21.6 | 18.4 |
| calculator | 21.6 | 16 |
| about | 20.8 | — |

**Стало.** Значение переехало в общий токен `style.css` — 1.125rem (18px).
Локальные копии удалены из `index`, `faq`, `methodology`, `map`
(правила целиком) и из `feedback`, `support` (только `font-size`;
`font-weight: 600` у них отличается от токена и сохранён). Источник истины
один. В `faq` и `methodology` комментарий был на латинице — при удалении
правила оставлен на кириллице.

**Замер после правки:** glossary 21.6 / 18, зазор 3.6px. На всех прочих
страницах значения не изменились — локальные копии были избыточны.

Снапшоты перезаписаны для `glossary` (4 файла). `index` и `methodology`
тоже изменились — в пределах допуска 0.05%, тест их не ронял.
