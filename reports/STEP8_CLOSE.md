## 1. Одно решение, которое я принял за вас — скажите, если не так

Ваш новый текст v5.1.6 **не содержит блока «Что:»** — то есть определения
работы. Без него релиз «Cross-browser» не описывает, что именно делать.

Я сохранил «Что:» и добавил в него пункт, которого не было, но который следует
из проверки кода:

```
- Перенести 37 существующих эталонов в tests/snapshots/chromium/
- Переписать путь эталона в коде: сейчас SNAP_DIR / f"{name}.png" лежит
  плоско, _actual/ — рядом; нужно SNAP_DIR / engine / ..., иначе новые
  движки не найдут свои базовые кадры
- Обновить scripts/compress_snapshots.py под новую раскладку
```

**Основание, измерено:**

```python
tests/test_visual_snapshots.py:81   SNAP_DIR = Path(__file__).resolve().parent / "snapshots"
tests/test_visual_snapshots.py:82   ART_DIR  = SNAP_DIR / "_actual"
tests/test_visual_snapshots.py:440  path     = SNAP_DIR / f"{name}.png"
```

Сейчас в `tests/snapshots/` лежат **37 PNG плоско** (+ `_actual/.gitignore` в
гите). Создать пустые `chromium/` и `webkit/` без правки этих строк —
значит получить прогон, который не находит базовый кадр и падает на всех 37
снимках.

Если «Что:» нужно убрать — скажите, уберу.
