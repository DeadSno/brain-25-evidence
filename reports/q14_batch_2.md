## BCAA (grade B, «зависит от контекста»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Лейцин/изолейцин/валин: спорт-эффекта при достатке белка нет; ниша — печёночная энцефалопатия. | PMID 28518283/26377410/41542879 (энцефалопатия); мехс «при достатке белка эффекта нет». |
| who_needs | Цирроз с печёночной энцефалопатией; спортсменам/веганам с нехваткой белка — но лучше просто белок. | PMID 28518283 (цирроз + энцефалопатия, 16 РКИ, 827 чел.); caution (спорт — без клинич. эффекта). |
| onset | Энцефалопатия: симптоматически, курсами; для мышц мгновенного эффекта не закреплено. | PMID 28518283 (улучшение проявлений энцефалопатии; длительность курсовой). |
| myths | «Качают мышцы без еды» — при достатке белка эффекта нет. «Лечат печень» — только при энцефалопатии на циррозе, на смертность не влияют. | мехс «маркетинг»; PMID 28518283/Cochrane 2026 (на смертность эффекта нет). |
| food_sources | Яйца, мясо, молоко, соя: весь белок содержит BCAA — проще есть белок, чем добавку. | Практический вывод из мехс «при достатке белка эффекта нет». |
| guidelines | Cochrane 2017: BCAA уменьшают симптомы энцефалопатии (16 РКИ), смертность не меняют; для спорта пользы нет. | PMID 28518283; caution (мета-анализы по спорту противоречивы). |
| how_to_choose | Брать добавку только под цирроз с энцефалопатией; для спорта бессмысленно — белок/протеин эффективнее. | derive: те же источники; «протеин эффективнее» — из caution/мехс. |

## ГАБА (grade D, «не подтверждено»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Главный тормозной нейромедиатор; оральный ГАБА плохо проходит ГЭБ — сон/стресс подтверждены слабо. | PMID 33041752 (SR, limited/very limited); caution (плохо проходит ГЭБ). |
| who_needs | Не определён: обзор 14 РКИ дал ограниченные данные для стресса и очень ограниченные для сна; здоровым нет. | PMID 33041752 (14 плацебо-РКИ; ограниченный/очень ограниченный эффект). |

| myths | «Успокаивает как аптечный препарат» — доказательства ограничены, часть РКИ без эффекта. «Попадает в мозг» — хуже всего проходит ГЭБ. | PMID 33041752 (смешанные результаты); caution (ГЭБ). |
| food_sources | Квашеные и ферментированные продукты содержат ГАБА; сколько всасывается в мозг — не установлено. | PMID 33041752 упоминает натуральный ГАБА в еде; эффект на мозг не доказан. |

| how_to_choose | Если пробовать — 100–300 мг (дозы исследований); ожидать эффекта не стоит — карточка D. | dosage карточки (100–300 мг — дозы исследований); вердикт D. |

## L-карнитин (grade C, «зависит от контекста»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Возит жирные кислоты в митохондрии; эффекты скромные: ~1 кг веса, малый сдвиг маркеров при СД2. | PMID 38594107 (СД2: ИМТ −0.37, HbA1c −0.16%, ЛПНП −0.11); effects карточки. |
| who_needs | Диабетическая нейропатия (>1500 мг/сут ALC), СД2 с метаболическими целями, хромота; для похудения здоровым — слабо. | PMID 31201734 (ALC нейропатия); PMID 38594107 (СД2); PMID 34954832 (хромота). |
| onset | Нейропатия — недели-месяцы; метаболика — на дистанции от 1 г/д; мгновенного нет. | PMID 38594107 (дозозависимость 1–4 г/д на дистанции); в abstracts явных недель нет — осторожно. |
| myths | «Растопит жир на митохондриях» — заявлено, но эффект ~1 кг и противоречив. «Терапия витаминная» — это лекарственные формы (ALC/PLC), не БАД. | PMID 38594107 (эффект мал, гетерогенность высокая); caution (2 из 4 РКИ спонсированы производителем). |
| food_sources | Красное мясо — главный источник; вегетарианцы/веганы обычно на нижней границе нормы, но дефицит редок. | Общеизвестный факт; обзоры его не оспаривают. |
| guidelines | ALC >1500 мг/д при нейропатии — certainty VERY LOW; СД2: на 1 г/д HbA1c −0.16% (Cochrane 2019/2024). | PMID 31201734 (Cochrane 2019, VERY LOW); PMID 38594107 (2024, дозозависимость 1 г/д). |
| how_to_choose | Обычный L-карнитин для метаболизма — 1–2 г/сут; при нейропатии — ацетил-L-карнитин, дозы под врача. | dosage карточки (1–2 г/сут); ALC — высокая доза (>1500 мг) только при назначении врача. |

## Глицин (grade D, «не подтверждено»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Тормозная аминокислота: улучшает засыпание (3 г) в отдельных РКИ; мета-анализов нет — база слабая. | PMID 37851316 (SR 2024: сон у здоровых лучше в малых выборках); caution (в базе нет МА). |
| who_needs | Недоказан: данные по сну и шизофрении в малых выборках; биохакеры-энтузиасты; пожилые — GlyNAC эксперимент (n=36). | PMID 37851316 (сон, психиатрия); PMID 35975308 (GlyNAC, n=36). |

| myths | «Доказанный снотворный» — SR 2024: улучшение сна в малых выборках с высоким риском смещения. «Продлевает жизнь» — эффект у животных, не у людей. | PMID 37851316 (малые выборки, высокий риск смещения); PMID 35975308 — эффекты на модели животных переносятся с осторожностью. |
| food_sources | Коллаген/желатин, мясо, бобовые — богаты глицином; из еды дозу 3 г набрать сложно. | Общеизвестный факт; dose 3 г из еды трудно. |
| guidelines | SR 2024: нервная система — самые положительные эффекты, но качество данных низкое; дозы 3 г перед сном, курсы до 4 мес. | PMID 37851316 (11 систем, нервная — наиболее позитивно; качество низкое). |
| how_to_choose | Если пробовать — обычный глицин 3 г перед сном; эффект субъективный, ожидать науки не стоит (карточка D). | dosage карточки (3 г); вердикт D. |
