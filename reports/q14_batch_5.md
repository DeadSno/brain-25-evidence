| who_needs | Веганы, пожилые (атрофический гастрит), приём ИПП, беременные с дефицитом; пернициозная анемия — только инъекции. | PMID 39373282 (веганы — функциональный дефицит выше); PMID 37060552 (ИПП OR 1.42); PMID 38189492 (беременные, дефицит 26–51%); caution. |

| myths | «Всем поднимает энергию» — у здоровых когниция и усталость не меняются (16 РКИ). «Только инъекции» — перорал 1000–2000 мкг так же эффективен. | PMID 33809274 (16 РКИ, 6276 — нет эффекта); PMID 38231320 (перорал = IM/SL, 13 РКИ, 4275). |

| guidelines | Перорал = инъекции по уровню B12 (НМА 2024, 4275); веганы — функциональный дефицит выше; ИПП — риск +42% (SR 2023). | PMID 38231320; PMID 39373282 (19 исследований, tHcy выше, MMA выше); PMID 37060552 (OR 1.42, 25 исследований). |
| how_to_choose | 500–1000 мкг перорально/сублингвально; при дефиците или веганам; перед приёмом — B12 + MMA + гомоцистеин. | dosage/course (500–1000 мкг; только при дефиците/веганам); PMID 39373282 (функциональный статус — панель биомаркеров). |

## Сывороточный протеин (grade A, «работает»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Золотой стандарт белка: лейцин + полный амино-профиль; работает при силовых нагрузках и саркопении. | PMID 38350303/37571361 (МА при саркопении); mechs «сильно». |
| who_needs | Спортсмены (1.6–2.2 г белка/кг/сут), пожилые с саркопенией, худеющие при дефиците калорий. | PMID 35871954 (композиция тела: BMI, жир, талия при дефиците калорий); dosage. |
| onset | Эффект копится тренировками, виден на 8–16 неделях; быстрого «пампа» масса не даёт. | PMID 37571361 (сила хвата +2.31 кг, масса — малые эффекты); длительность МА-РКИ. |
| myths | «Сам по себе строит мышцы» — без силовой нагрузки на саркопению нет (10 РКИ, 1154). «Чем больше, тем лучше» — свыше 2.2 г/кг выгоды нет. | PMID 38350303 (эффект массы/силы — вместе с RT); dosage (не более 2.2 г/кг). |
| food_sources | Молочная сыворотка: молоко, кефир, творог; добавками экономно доедают белок, когда еды мало. | Whey — молочный белок (из abstracts следует категорно); практическая рекомендация. |
| guidelines | МА 2023–2024: при саркопении мышцы SMD 0.47 и ходьба 1.13; композиция тела — только с нагрузкой и дефицитом калорий. | PMID 38350303 (ASMMI 0.47, gait 1.13, сила хвата 0.67 с RT); PMID 35871954. |
| how_to_choose | Изолят при лактозной непереносимости; 20–40 г после тренировки; ориентир — лейцин ≥2.5 г на порцию. | dosage карточки (20–40 г); caution (изолят > концентрат по белку); «лейцин ≥2.5 г» — практика из МА-данных. |

## Рибофлавин (grade B, «работает»)

| Поле | Текст | Обоснование |
|---|---|---|
| about | Витамин B2 — митохондриальный кофактор; работает как профилактика мигрени у взрослых (400 мг/день). | PMID 33779525 (МА: 400 мг/сут, 3 мес); mechs «умеренно». |
| who_needs | Взрослые с частой мигренью, кому нужна немедикаментозная профилактика; у детей эффект смешанный, здоровым не нужен. | PMID 28485121 (у взрослых стабильно, у детей смешанно); SR 2017. |
| onset | Эффект развивается через 2–3 месяца приёма 400 мг/день; быстро мигрень не купирует. | PMID 33779525 (400 мг/сут в течение трёх месяцев); caution. |
| myths | «Снимает приступ сразу» — профилактика: реже через 2–3 месяца. «Жёлтая моча — опасно» — норма; у детей эффект смешанный. | PMID 33779525 (профилактический эффект, не абортивный); PMID 28485121; caution (жёлтая моча — норма). |
| food_sources | Молоко, яйца, грибы, печень, миндаль, зелень; дефицит редок, при мигрени — дозы добавки, не еды. | Доза 400 мг (dosage) из еды недостижима — добавка. |
| guidelines | МА 2022 (9 статей, 673 чел.): дни/частота/длительность/боль ниже. SR 2017: у взрослых стабилен, комбинации не помогают. | PMID 33779525 (все четыре исхода значимы); PMID 28485121 (комбинации без пользы). |
| how_to_choose | Обычный рибофлавин 400 мг/сут (не «активные формы»), курс от 3 месяцев; дешёвый и безопасный. | dosage (400 мг/сут); PMID 28485121 (дёшев, безопасен). |

| who_needs | Люди с возрастной макулодистрофией (AREDS2) и семейным риском; при ядерной катаракте — наблюдательные данные. | PMID 31887124 (пациенты с ВМД); PMID 24451312 (ядерная катаракта — ассоциативная). |

| how_to_choose | Дозировка AREDS2 — 10 мг лютеина + 2 мг зеаксантина с жирной едой; покупать не «формулы», а состав. | dosage (10+2 мг с жирами); caution (AREDS2 — стандарт). |
