## Реализация (F)

Выбран вариант F: CTA «Найти свою добавку» → каталог 130 добавок с
плавной прокруткой и фокусом на первой кнопке фильтра. Обоснование
владельца: «Найти свою добавку» — семантика браузинга; каталог с
фильтрами и есть эта задача; «Топ по науке / Доказано / Изучают
сейчас» — готовые точки входа, «По эффекту» (Сон, Стресс, Иммунитет) —
то, что пользователь ищет.

### Правки

| Файл | Что |
|---|---|
| `docs/index.html:280` | `href="#search"` → `href="#cardsContainer"` (id в разметку **не добавлялся**) |
| `docs/index.html:197–214` | комментарий MKT-P1-02 дополнен абзацем INDEX_CTA_FIX |
| `docs/script.js:251–277` | обработчик на верхнем уровне (рядом с `initTheme()`) |
| `docs/index.html:464` | `script.js?v=286` → `?v=287` |
| `docs/sw.js` | `CACHE_VERSION` `v95` → `v96` + комментарий «Бамп v95 -> v96» |

Обработчик:

```js
document.querySelectorAll('a.btn.calc[href="#cardsContainer"]').forEach((cta) => {
  cta.addEventListener('click', (e) => {
    e.preventDefault();
    const target = $('cardsContainer');
    if (target) {
      const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
      target.scrollIntoView({ behavior: reduce ? 'auto' : 'smooth', block: 'start' });
    }
    const filterBtn = document.querySelector('#tagPresets .tagPreset[data-tag="all"]')
                   || document.querySelector('#presetRow .preset');
    if (filterBtn) filterBtn.focus({ preventScroll: true });
  });
});
```

Три решения, которые стоит зафиксировать:

1. **Селектор по href, а не по id.** Связка `href → обработчик` не
   разъезжается, если кнопку переставят, и не требует правки разметки.
2. **Обработчик на верхнем уровне, не в `initApp()`.** `initApp()`
   вызывается только после `Promise.allSettled` загрузки данных
   (`script.js:277–288`), а секция статична и должна работать с первого
   клика. Рядом с `initTheme()` — по той же причине, по которой
   переключатель темы вынесен из `initApp()` (v4.0).
3. **`focus({preventScroll: true})` обязателен.** Без `preventScroll`
   вызов `focus()` немедленно дёргает прокрутку и обрывает
   smooth-анимацию — каталог и фокус оказались бы в разных местах.

### Уточнение по «первому фильтру» (открыто перед правкой)

Классов `.filter-btn` / `.fx-btn` и атрибута `[data-effect]` в проекте
**нет** — предложенные в задании селекторы не сработали бы. Реальные

- «Все эффекты» — `#tagPresets .tagPreset[data-tag="all"]`, рендерится

- фолбэк «Топ по науке» — `#presetRow .preset` (`index.html:394`),

Взят первый, при отсутствии — второй.

### Ловушка, на которую наступили дважды

Сервер `http.server 8000` на этой машине запущен из
`C:\analytics\brain-25-evidence` — **основного репозитория**, а
сессия работает в worktree
`C:\Users\TshK\.local\share\opencode\worktree\8eba72\misty-mountain`.
`:8000` отдаёт старую копию `index.html`, из-за чего правка выглядела
неприменённой, а Playwright падал по таймауту `#ctaFind`.

Проверка `sha256` файла `style.css` **прошла**, хотя копии разные:
в этой правке `style.css` не менялся, а в main и worktree он
идентичен — сверка дала ложное подтверждение. Сработала только
сверка `index.html` (файл, который правка меняла).

Решение: поднят второй сервер **из worktree** на свободном порту

```
python -m http.server 8010 --directory docs   # из корня worktree
```

и все проверки сайта шли с `SNAPSHOT_BASE_URL=http://localhost:8010`.
Сервер владельца на `:8000` не трогали. **Вывод на будущее: сверять
хеш того файла, который правка меняет, а не того, который не менялся.**
