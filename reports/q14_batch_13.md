## Клюква (зависит от контекста, C; scienceIndex 258)
| Поле | Текст (обоснование PMID) |
|---|---|
| about | Клюква и ИМП: профилактика рецидивов у женщин — минус 26%; лечение — РКИ нет; в целом эффект ограничен. (29046404) |
| who_needs | Женщины с рецидивирующими ИМП (RR 0.74) — эффект скромный; не для лечения и не для пожилых/с катетером — данных мало. (29046404, 37947276) |

| myths | «Лечит цистит» — Cochrane 2023: подходящих РКИ нет. «Профилактика для всех» — в основном женщины с рецидивами. «Сок любой клюквы» — нужны PAC, разбавленный морс их почти не имеет. (37947276, 29046404) |
| food_sources | Ягоды и неподслащённые морсы — есть PAC; магазинный «сок» разбавлен — PAC мало. (37947276) |
| guidelines | Cochrane 2023 (50 РКИ, 8857): снижает ИМП в отдельных группах, уверенность низкая. МА 2017 (7, n=1498): RR 0.74. Лечение — нет. (37947276, 29046404) |
| how_to_choose | Концентрат с PAC ~36 мг/сут (сок без сахара); курсом при рецидивах; при симптомах — к врачу. (29046404) |
