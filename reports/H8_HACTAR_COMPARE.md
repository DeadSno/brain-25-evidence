## Что сделано

### 1. Таблица сравнения (side-by-side)

Панель `#hactarPanelCompare` (вкладка `?tab=compare`) вместо заглушки получила
блок `#hactarCompare`:

- шапка: заголовок «Сравнение добавок» + динамическая подпись («Сравниваем 2 добавки: …»);
- подсказка `#hactarCompareHint` — «Выберите минимум 2 добавки для сравнения» (видна при выборе одной добавки);
- таблица `#hactarCompareTable` в прокручиваемом контейнере `#hactarCompareScroll`;
- блок карточек `#hactarCompareCards` — мобильная версия той же таблицы.

Строки таблицы (столбцы — выбранные добавки):

| Строка | Источник |
|---|---|
| Грейд доказательности | `data_index.json` → бейдж `.grade.gA…gD` + расшифровка `GRADE_LABEL` |
| Эффекты | `effects[]` (до 3 шт.) |
| Дозировка | `data.json` → `dosage` (в `data_index.json` его нет) |
| Взаимодействия с лекарствами | `interactions[]` → препарат + чип тяжести `.sev-critical/high/medium/low` |
| Купить | ряд чипов со ссылками на магазины (P2-03) |

Состояния: 0 выбранных — пустое состояние H-4; 1 — подсказка; 2+ — таблица (широкий экран)
или карточки (≤768 px).

### 2. Кнопки «Купить» (фикс P2-03)

В самом низу таблицы — ряд чипов `[ Ozon ] [ Wildberries ] [ Яндекс.Маркет ]`.
Ссылки ведут на поиск товара в магазине (по названию добавки и первой форме):

- `https://www.ozon.ru/search/?text=…`
- `https://www.wildberries.ru/catalog/0/search.aspx?search=…`
- `https://market.yandex.ru/search?text=…`

У ссылок `target="_blank"`, `rel="noopener nofollow"` и `aria-label="Купить <добавка> на <магазин>"`.
Паттерн URL — тот же, что использует `shopBlock()` в `docs/script.js`.

### 3. Реактивность и мобильная вёрстка

- `subscribe('change')` → таблица перерисовывается при каждом изменении выбора;
- `subscribe('mode')` → при открытии вкладки «Сравнение»;
- `matchMedia('(max-width: 768px)')` → при повороте телефона представление
  переключается «таблица ↔ карточки» без перезагрузки;
- `data.json` (758 КБ) грузится лениво — только когда вкладка «Сравнение» открыта.

На 375 px страница не прокручивается вбок: `document.documentElement.scrollWidth = 360`
при `innerWidth = 375`. Таблица при этом прячется и показываются карточки.
На узких десктопах таблица скроллится внутри контейнера (`overflow-x:auto`,
`min-width:520px` — как у `#compareResult table` на `compare.html`).

Побочная правка: `.hactar-main` получил `min-width:0` — без него grid-колонка
не сжималась до ширины контента таблицы, и страница получала 8 px горизонтального
переполнения (только на вкладке «Сравнение»).

### 4. Механизм заглушки удалён

`.hactar-stub` был единственной заглушкой в проекте (панель «Сравнение»).
Раз разделка реализована, заглушка снята целиком: разметка + два CSS-правила +
чтение в JS (`stubs`). Иначе аудит классов ругался бы либо на «селектор без
разметки», либо на «CSS-класс без разметки».

## Ограничения, которые стоит знать

- **`scope="row"` у заголовков строк не ставится.** Аудит классов
  (`scripts/audit_classes.py`, `JS_LITERAL`) считает любой литерал в JS-строке
  именем класса: `scope="row"` оживлял `.row` из мёртвого списка, и тест
  `test_known_dead_list_matches_measured` падал. Заголовок строки остаётся
  `<th>` в первом столбце — так же сделано на `docs/compare.html`.
- **`min-width` в `docs/style.css` не трогаем** — там есть тест
  `test_min_width_justified.py` и версионный тест `test_style_version_bump.py`.
- Сортировка колонок — в порядке списка (DOM), а не по грейду.
