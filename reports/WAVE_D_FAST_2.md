### Часть A — A11Y-P1-10, cookie-ссылка (`eb5967c`)

`fix(a11y): cookie-banner privacy link tap-target` — `docs/style.css`, одно правило
в `#cookieBanner .cb-text a` (было: только `color`).

```css
#cookieBanner .cb-text a {
  color: var(--accent);
  display: inline-flex;
  align-items: center;
  min-height: 44px;
  margin-block: -11px;
}
```

**Почему `margin-block: -11px`.** Ссылка «Политика конфиденциальности» —
**последний** элемент в абзаце `.cb-text`, поэтому бокс можно вырастить по вертикали
без сдвига раскладки: `inline-flex` центрирует глифы в боксе 44 px, отрицательный
margin срезает добавленные 22 px из потока (44 − 22), строка остаётся 21 px.
Тёмная тема (`html:not(.light) …`) не тронута.

| Страница / вьюпорт | Ссылка до | Ссылка после | Баннер до → после |
|---|---|---|---|
| atlas 375×740 | 216×17 | **216×44** | 351×166 → 351×167 |
| atlas 360×640 | 216×17 | **216×44** | 336×187 → 336×188 |
| atlas 1280×720 | 216×17 | **216×44** | 720×97 → 720×98 |
| index 375×740 | 216×17 | **216×44** | — |
| sup/index 375×740 | 216×17 | **216×44** | — |

Проверено в Playwright: горизонтального скролла нет (`scrollW == clientW`), бокс
ссылки не пересекается с `.cb-actions`, нижний отступ баннера прежний (16 px),
`elementFromPoint` по всему боксу (0/5/15/22/30/43 px) возвращает сам `<a>`,
на −1 px и +44 px — родитель, на +50 px — кнопка. Скриншот 375 px подтверждён:
текст на месте, ссылка подчёркнута на своей строке, кнопки ниже.

**Стоп-условие «ломает баннер» не сработало** — рост баннера 1 px на всех трёх
комбинациях.
