## Метод

Три инструмента, потому что один не видит половину сайта:

1. **Статический скан** (bs4, 144 файла) — структура: `lang`, число `h1`,
   уровни заголовков, лендмарки, `alt`, формы, `aria-hidden` против
   фокусируемых, дубли `id`, положительные `tabindex`, `user-scalable`.
2. **Живой зонд** (Playwright, `getComputedStyle`) — то, чего нет в исходнике:
   итоговый цвет текста, фактический фон (с обходом родителей), фокусируемость
   и видимость индикатора фокуса, порядок табуляции. Прогонялся на 16
   страницах в тёмной и светлой темах: `/`, `methodology`, `faq`, `trends`,
   `calculator`, `interactions`, `feedback`, `map`, `atlas`, `graph`,
   `glossary`, `support`, `privacy`, `sup/ashvaganda`, `sup/index`,
   `sup/creatin` — 32 замера контекста.
3. **Калькулятор контраста** (отдельный скрипт, формула WCAG 2.x) — для
   подбора значений, которые потом клались в токены.

**Правило градации:** < 3.0:1 → P0 (текст нечитаем); 3.0-4.49:1 → P1
(ниже AA, но читаемо); соответствие best practice → P2.

**Ловушка, которая стоила времени:** браузер кэширует и HTML, и
`style.css`. Первый верификационный прогон показал «22 находки, ничего не
поменялось», потому что зонд получил старые файлы. Лечится добавлением
`?cb=<N>` к URL страницы в навигации и бампом `style.css?v=`. Отдельно:
`?v=` пришлось поднимать дважды — токены грейдов добавились в один заход,
`--info-*` в другой, а кэш браузера помнит URL.

**Ложные срабатывания (не находки):**

- `.bestBadge` на `index.html` — замер 1.07:1. Фон градиент
  `linear-gradient(135deg,#f1c40f,#f39c12)`, а зонд брал `background-color`
  (прозрачный) и уходил вверх к белому. Контраст `#222` на `#f1c40f` ≈ 10:1.
  Зонд переписан: элементы с `background-image != none` пропускаются.
- `<input name="botcheck">` на `feedback.html` — honeypot с
  `display:none; tabindex="-1"`. Не фокусируем и скринридеру не виден.
- `vColor` в `script.js` (`#2d8a4e` / `#d4a017` / `#c0392b`) — цвета вердиктов
  в `vis-network`, то есть заливка узлов графа, а не текст. Проверено по
  местам использования (`backgroundColor:`), правилу WCAG 1.4.3 не подчиняется.
- `.dot` в `atlas.html:219-221` — декоративные точки легенды рядом с текстом.

## P0 — контраст ниже 3:1 (закрыто, 3 шт.)

Корень всех трёх один: палитра грейдов v3.1 (`#22c55e` / `#84cc16` /
`#f59e0b` / `#ef4444`) была заточена под **заливку под белый текст**, и её
при этом использовали как **цвет текста**. Как заливка она и сейчас жива в
`.grade.gX`, но как текст не проходит ни в одной теме.

### P0-1. Бейдж грейда на 130 sup-страницах

`templates/sup.html.j2:83` кладёт цвет инлайном в `style=`, и блок v4.1 с
`!important` в `style.css:846-849` его не перебивает — у `.grade-badge` свой
класс. Белый текст на инлайн-заливке:

| Грейд | Цвет | Контраст | Страниц |
|---|---|---|---|
| B | `#84cc16` | **1.98:1** | 45 |
| A | `#22c55e` | **2.28:1** | 8 |
| D | `#ef4444` | 3.76:1 | 25 |
| C | `#b45309` | 5.02:1 | 52 — проходил |

**Фикс:** палитра sup и палитра `.grade.gX` больше не расходятся —
`GRADE_COLORS` в `scripts/build_sup.py` переведён на `#15803d` / `#4d7c0f` /
`#b45309` / `#b91c1c` (4.59-5.94:1). 78 уже закоммиченных страниц мигрированы
буквальной заменой подстроки (не regex), по одной строке на файл;
`GRADE_FALLBACK` `#888888` (3.54:1) → `#4b5563` (7.48:1).

Регенерация sup через `build_sup.py` **не запускалась**: шаблон
`templates/sup.html.j2` устарел относительно закоммиченных страниц и откатывает
cookie-баннер, ссылку на `../privacy.html` и версию `style.css?v=`. Подробности
в P2.

### P0-2. Чипы `.mech-strength` на 131 sup-странице

`style.css:1553-1555`: тонированная подложка `background:#…33` и цвет текста
того же тона.

| Класс | Светлая тема на `#f5f5f7` | Тёмная на `#2c2c2e` |
|---|---|---|
| `.s-medium` `#84cc16` | **1.81:1** | 1.98:1 |
| `.s-weak` `#f59e0b` | **1.97:1** | 2.15:1 |
| `.s-strong` `#22c55e` | **2.28:1** | 2.28:1 |

**Фикс:** четыре новых токена `--grade-a-tx … --grade-d-tx` — по одному на
грейд, тёмная и светлая ветки считались по худшей паре фонов:

```
тёмная:   #4ade80 -> 8.00:1   #a3e635 -> 9.24:1   #fbbf24 -> 8.35:1   #f87171 -> 5.04:1
светлая:  #15803d -> 4.61:1   #4d7c0f -> 4.59:1   #b45309 -> 4.61:1   #b91c1c -> 5.94:1
```

Светлые значения — ровно те, что v4.1 уже поставил на заливку `.grade.gX`,
поэтому плашка и текст теперь из одного набора. В светлой теме подложка чипа
сделана белой с рамкой в цвет текста: оттенок того же тона под тёмный текст
даёт максимум 3.85-4.38:1 при любой альфе 0.10-0.20 — hue слишком близок,
это не лечится прозрачностью.

## P2 — техдолг (5 шт., не делал)

1. **Нет `<nav>`-лендмарка на 13 главных страницах** — `atlas`,
   `calculator`, `faq`, `feedback`, `glossary`, `graph`, `index`,
   `interactions`, `map`, `methodology`, `privacy`, `support`, `trends`.
   На 131 sup-странице `<nav>` есть. Правило сквозной навигации в
   `style.css` есть, а разметки — нет; это правка 13 файлов.
2. **Пропуски уровней заголовков:** `index.html` h1 → h3, `trends.html` h2 → h4.
   WCAG-формально это не нарушение (читаемо), но навигация по заголовкам
   встаёт.
3. **`templates/sup.html.j2` устарел** относительно закоммиченных sup-страниц:
   регенерация откатывает блок cookie-баннера, ссылку `../privacy.html` и
   версию `style.css?v=`. Проверено на `build_sup.py --only ashvaganda`.
   Пока шаблон не синхронизирован, `build_sup.py` запускать нельзя — а
   значит, правки в данных не доедут до страниц. Это блокер для
   data-аудита, а не косметика.
4. **Один `<a>` без индикатора фокуса** на `trends.html` — элемент создаётся
   скриптом, у него нет `:focus-visible`-стиля. Нашёл живой зонд, не статика.
5. **Зонд пропускает элементы с градиентным фоном** — иначе даёт ложные
   срабатывания (см. `.bestBadge`). Значит, текст на градиенте не проверяется
   автоматически вообще. Сейчас таких элементов один, вручную проверен.

## Прошло (без замечаний)

- `lang="ru"` на 144/144.
- Ровно один `<h1>` на 144/144.
- `<main>`, `<header>`, `<footer>` на 144/144; skip-link «Перейти к
  содержимому» -> `#main` на 144/144 и видим при фокусе.
- Ни одного `<img>` без `alt`.
- Ни одного положительного `tabindex` (то есть нет искусственных
  переупорядочиваний в DOM-порядке).
- Нет `aria-hidden="true"` на видимых фокусируемых элементах.
- Нет дублирующихся `id`. Нет `<iframe>` без `title`. Нет неизвестных `role`.
- Нет `<video>`/`<audio>` без `<track>`.
- Нет `user-scalable=no` в `viewport`.
- Порядок табуляции логичный на всех 8 страницах, где считали: skip-link ->
  логотип -> навигация -> контент. Ловушек фокуса нет.
- Видимый индикатор фокуса есть у всех фокусируемых элементов, кроме одного
  случая из P2-4.
- **Контраст после фиксов: 0 замеров ниже порога** на 16 страницах × 2 темы
  (было 22 на тех же страницах до фиксов, 130 бейджей и 131 чип — статикой).
