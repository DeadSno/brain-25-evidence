## R1 — 199 тестов не выполняются

### Механизм в conftest.py

`pytest_collection_modifyitems` (tests/conftest.py:14) выключала четыре маркировки
**срезом списка**, а не skip:

```python
if not os.environ.get("RUN_SNAPSHOTS"):
    items[:] = [item for item in items if "snapshots" not in item.keywords]
```

Так же для `RUN_A11Y`, `RUN_TABS`, `RUN_GRAPH`. Маркер `e2e` уже был
правильно реализован через `item.add_marker(skip)` — то есть в одном файле
жили два несовместимых способа выключить одно и то же, и невидимый был
записан позже.

Почему opt-in, а не opt-out: гейты висят на переменных окружения намеренно.
Причина зафиксирована в docstring и в pytest.ini: `-m` из командной строки
**перекрывает** `addopts`, поэтому `pytest -q -m "not snapshots"` в addopts
разбудил бы 37 тяжёлых попиксельных тестов и превратил быстрый прогон в
100-секундный. Замерено на этой копии: `pytest --collect-only -q` → 754/791.
Этот довод в силе и после правки — переменные окружения не перекрываются ничем.

### Что не так было

Не сам opt-in, а способ его выражения. `items[:] = [...]` не выполняет тело
теста ровно так же, как `skip`, но **убирает тест из отчёта целиком**. Итог:

```
$ pytest -q
878 passed, 2 skipped          <- ни слова о 199 тестах, которые не выполнялись
```

1079 собрано, 880 выполнено, 199 исчезли молча. Ровно тот класс проблемы,
который проект уже записал в долг **#87** (AUDIT_MASTER.md:1348) и который
`scripts/check_snapshot_run.py` уже ловит по другой причине — «74 skipped
выглядит как успех».

Усугубляло два обстоятельства:

- числа «862 passed + 18 skipped» в постановке задачи не совпадали с реальностью
  (862 — это устаревшее число из отчётов v5.5, см. reports/archive/v550/);
- `--collect-only` показывает 1079 и при включённых гейтах, и при выключенных,
  поэтому расхождение не видно и при сборе.

### Выбор: вариант B (skip с явным сообщением)

Не A. A («оставить как есть, только предупредить в отчёте») оставляет ровно
ту конструкцию, на которой уже поймался #87: репорт читает человек, который
не открывал `conftest.py`. Отдельный документ не спасает — расходился не текст,
а сам вывод `pytest -q`.

Цена B — нулевая по скорости: и `skip`, и deselect не выполняют тело теста.
Замер до и после: 26.97 с → 32.93 с (разница в пределах шума на этой машине,
медленнее ровно от построения 201 сообщения о пропуске).

Что изменено — `tests/conftest.py`, четыре фильтра заменены на один цикл с
таблицей гейтов, каждый со своим текстом «как включить»:

```python
for marker, env_var, command in (
    ("snapshots", "RUN_SNAPSHOTS", "..."),
    ("a11y",      "RUN_A11Y",      "..."),
    ("tabs",      "RUN_TABS",      "..."),
    ("graph",     "RUN_GRAPH",     "..."),
):
    if not os.environ.get(env_var):
        skip_marker = pytest.mark.skip(reason=command)
        for item in items:
            if marker in item.keywords:
                item.add_marker(skip_marker)
```

Гейты остались независимыми — пересечения маркеров по-прежнему нет.

### Проверка

```
$ pytest -q
878 passed, 201 skipped, 1 warning in 32.93s
```

Разложение 201: a11y 39 + graph 42 + tabs 42 + snapshots 76 + e2e 2.
1079 − 201 = 878 — сходится.

Причины видны в отчёте (`-rs`), а не прячутся:

```
SKIPPED [72] tests\test_visual_snapshots.py:629: снапшоты выключены по умолчанию
         (попиксельные PNG, ~100 с против ~4 с). Запуск: $env:RUN_SNAPSHOTS="1"; ...
SKIPPED [42] tests\test_tabs_interaction.py: tabs выключены по умолчанию ...
SKIPPED [42] tests\test_graph_interaction.py: graph выключены по умолчанию ...
SKIPPED [36] tests\test_a11y_axe.py:268: a11y-тесты выключены по умолчанию ...
```

Независимость гейтов на месте — каждый открывается своей переменной, чужие
остаются выключенными:

```
$ $env:RUN_A11Y="1"; pytest -q --collect-only -m a11y

$ $env:RUN_TABS="1"; pytest -q --collect-only -m tabs
```

Отдельно проверено, что правка не ломает
`tests/test_version_json_counts_match_reality.py::test_version_json_tests_match_collected`:
тест сверяет `docs/version.json` (1079) с выводом `--collect-only`. Skip не
уменьшает число собранных, поэтому 1079 сошлись и после правки — тест зелёный.

**Закрывает долг #87.**

## R2 — aria-live

### git log -S результат

Задание требовало не править без истории. `git log -S` нашёл четыре коммита,
`role="alert"` — **ни одного**.

```
$ git log -S "aria-live" --oneline -- docs/
b8ad33c feat(v5.6.3): replace Web3Forms with Yandex Forms + 152-FZ privacy
98ec4dc feat(round2): health-check report, share.js 17/17, mobile carousel, microfixes
7aa6c8b fix(qa): close QA audit P0+P1 - api contract, test infra, sw/offline
57decfe fix(audit): close 20 important + followups + SW sup + contrast
```

Два из них **добавляли** aria-live, и оба добавления живы до сих пор:

- `57decfe` — `docs/feedback.html`: `<span class="f-status" id="fStatus"
  role="status" aria-live="polite">`;
- `7aa6c8b` — бейдж офлайна, сегодня `docs/pwa.js:39-40`;
- `98ec4dc` — кнопка «поделиться», сегодня `docs/share.js:28-30`.

### Что на самом деле пропало

Одно: `fStatus` на `docs/feedback.html`. Его снёс `b8ad33c` — коммит заменил
Web3Forms на iframe Яндекс Форм и удалил вместе с `<form>` весь блок `.f-*`
(411 строк → 247). На месте остался комментарий в разметке: «форма
обратной связи переехала на Яндекс Формы».

### Регрессия или осознанно

**Осознанно, и восстанавливать нечего.** Причина исчезновения — исчезновение
адресата: писать в `fStatus` было некому, потому что локальной формы больше
нет, отправка ушла в сторонний iframe. Возвращать атрибут на осиротевший span
значило бы объявить скринридеру «здесь появляются сообщения» там, где ничего
никогда не появится. Это ровно тот класс правки, что запрещён §0.1.

Отдельно проверено, что это не повод для тревоги по доступности: форма
переехала в iframe `forms.yandex.ru`, то есть её собственная доступность —
зона ответственности Яндекса, и локально мы на неё повлиять не можем.

### Шаг 5 — где динамика

| Страница | Динамика | aria-live |
|---|---|---|
| `calculator.html` | `renderResult()` пересчитывает `#cntResult` и списки | нет — заголовок `<h2>` с числом, экранный диктор молчит |
| `trends.html` | графики, обновление по кнопке | нет |
| `feedback.html` | формы больше нет | неприменимо |
| `share.js` / `pwa.js` (130+ страниц) | «скопировано», офлайн-бейдж | есть, `polite` |

`calculator.html` — реальная дыра, и она **не регрессия**: она была всегда,
правок в этом направлении в истории нет. Чинить её здесь нельзя: это новая
функциональность за пределами волны R (регрессии), и касается она
`calculator.html`, а правка с `aria-live` на пересчитываемом счётчике требует
проверки на реальном скринридере, а не только зелёного прогона. Записано в
качество отдельной задачи, не потеряно.

Итог R2: **правок в `docs/` не потребовалось**. Ни одна страница не тронута,
значит стоп-условие «R2 ломает существующие страницы» не могло сработать.
