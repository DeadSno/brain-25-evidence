# Glossary — глоссарий терминов

> Формальный словарь терминов проекта для разработчиков, аналитиков и внешних интеграторов.
> Отличается от [FAQ](faq.html) — это справочник понятий, а не ответы на вопросы.

## Биология и медицина

| Термин | Определение | Пример |
|--------|-------------|--------|
| **БАД** | Биологически активная добавка — не лекарство, дополняет питание | Омега-3, Магний |
| **MA** | Meta-analysis — мета-анализ, объединяет результаты нескольких исследований | Cochrane review |
| **РКИ** | Рандомизированное клиническое исследование (RCT) | 4007 RCT по Витамину D |
| **CI** | Confidence Interval — доверительный интервал | 95% CI [1.2, 2.8] |
| **p-value** | Вероятность случайного результата при нулевой гипотезе | p < 0.05 — значимо |
| **Effect size** | Величина эффекта (Hedges g, Cohen d) | g = 0.3 — слабый |
| **Preclinical** | Исследование на животных/клетках, не людях | in vitro, in vivo (мыши) |

## Методология и грейды

| Термин | Определение | Пример |
|--------|-------------|--------|
| **Grade A** | Эффект подтверждён у здоровых, много РКИ+MA | Витамин D |
| **Grade B** | Эффект с оговорками, контекстный | Омега-3 |
| **Grade C** | Эффект только при дефиците / в подгруппах | Селен, Серин |
| **Grade D** | Нет РКИ на людях или эффект отрицательный | PABA, Пролин |
| **verdict** | Текстовый вердикт: работает / зависит / не подтверждено | «работает» |
| **code** | Числовой вердикт: 1 / 0 / -1 | 1 = работает |
| **SI** | Science Index = RCT + 10×MA. Мера изученности | 1265 для Креатина |

## Данные и API

| Термин | Определение | Где |
|--------|-------------|-----|
| **PMID** | PubMed ID — уникальный номер статьи | 12345678 |
| **PMCID** | PubMed Central ID — для full text | PMC7871530 |
| **DOI** | Digital Object Identifier | 10.1016/j.example |
| **JATS** | Journal Article Tag Suite — XML-схема статей | Full texts |
| **COI** | Conflict of Interest — конфликт интересов | coi_report.json |
| **effect_tag** | Нормализованный тег эффекта (18 штук) | brain, sleep |
| **mech** | Механизм действия — [текст, эффект, сила] | [буфер, сила, сильно] |
