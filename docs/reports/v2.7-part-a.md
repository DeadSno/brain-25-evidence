## Замечания и нюансы

### 1. Внедрение кнопки: MutationObserver на overlay

Принято решение использовать `MutationObserver` на `#modalOverlay` вместо обёртки над
`openModal()` или кастомного события. script.js не диспатчит событий при открытии модалки.
`MutationObserver` реагирует на смену `style.display`, задержка 100ms для каскадного рендера.

### 2. Доступ к данным: fetch data.json вместо window.supplements

Проблема: `supplements` в script.js — это `let`-переменная уровня сценария (не на `window`).
Решение: tracker.js делает `fetch('data.json')` при инициализации и кэширует результат.
Это изолирует tracker от script.js, но даёт двойной запрос data.json.
Для 81 добавки (~180KB) пренебрежимо.

### 3. Инцидент: коммит на ветке v2.7-dev-b

При работе в общем рабочем дереве другой исполнитель переключил ветку между
`git checkout v2.7-dev-a` и `git commit`. Коммит `d51b121` попал на v2.7-dev-b.

Исправление: `git commit-tree` создан `b3ea808` (тот же tree, parent=8cd7c0d).
Указатель v2.7-dev-a установлен на `b3ea808`. v2.7-dev-b восстановлена на `8cd7c0d`.

### 4. e2e в общем дереве: конфликт с Part B

Рабочее дерево содержит мои additions и additions части B (офлайн-тест с
`octx.set_offline`). Комбинированный e2e_smoke.py падает на блоке Part B:
`net::ERR_INTERNET_DISCONNECTED`. Моя версия проходит чисто.

### 5. Карточки «Мои добавки»: дизайн

CSS inline (без правок style.css): цветная полоса слева (#3498db / #2ecc71),
прогресс-бар с transition 0.3s. Пустая секция скрывается (display:none).

### 6. Ключ localStorage: myCourse

Выбран по брифу A1. Схема совместима с гардом `getFavs()`: невалидный JSON →
сброс + console.warn. Отличие от favs: myCourse — объект (dict), не массив.
