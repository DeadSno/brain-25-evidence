## Что сделано (компактно)

- **Демонтаж Value Score**: карточка, модалка и сравнение больше не рендерят
  «ценность». В сравнении колонка → «₽ за единицу эффекта». Сортировки: убраны
  «по ценности» и «по отзывам», добавлена «🎖 по грейду доказанности»
  (A<B<C<D<нет, при равенстве грейда — по scienceIndex).
- **Блок «💰 ЭКОНОМИКА»** в модалке: цена с тултипом (дата сбора из
  price_history, статус reliability) и «₽ за единицу эффекта» =
  round(цена / Hedges' g) только при верифицированном g; при g=null — честная
  причина «Эффект ждёт верификации — ₽ за единицу эффекта не считаем».
- **Блок «📚 Ключевые мета-анализы (топ-3 поиска)»**: автотоп-3 PubMed по
  scienceIndex (esearch + esummary) → ma_top3 [{pmid,title,year}] со ссылками
  pubmed.ncbi.nlm.nih.gov/<pmid>; пометка «Проверено ТОП-1 НЕ ПОИСКОМ, А РУЧНОЙ
  ВЕРИФИКАЦИЕЙ (N)» до и после списка.
- **data.json**: ma_top3 у 80/81 карточек, price_date у всех 81.
- **CHANGELOG.md** [v2.6.1] сверху + docs/changelog_public.html (12 версий).
- **STATE.md**: строка-патч, main = v2.6.1, теги + v2.6.1, выпускной блок.

## Замечания и нюансы

1. **80/81 ma_top3; Ежовик = 0 честный пусто.** Запрос
   `(Hericium erinaceus OR lion's mane) AND meta-analysis[pt]` вернул 0 МА —
   список оставлен пустым, ничего не подставлено. Разработчик не досочинял данные.
2. **price_date = «дата неизвестна» у ВСЕХ 81 карточек.** price_history.csv
   пуст (только заголовок: date,id,wb,ozon,median,source, 0 строк) — поле добавлено,
   честно помечено, обновится при физпрогоне update_prices владельцем (WB/Ozon в этом
   окружении блокируют сеть).
3. **Кофеин-эталон экономики**: price=266 ₽/мес, hedges_g=0.21 (B-грейд) →
   price_per_effect = round(266/0.21) = 1267. e2e проверяет 1267±1 в модалке.
4. **Креатин g=null** — экономика не показывается «0» или «—»: рендерится причина
   «Эффект ждёт верификации — ₽ за единицу эффекта не считаем».
5. **Сортировка по грейду на данных релиза почти декоративна**: верифицированный
   грейд только у Кофеина (B), все остальные «нет» — бейджи «ЖДЁТ ВЕРИФИКАЦИИ».
   Логика A<B<C<D<нет заложена и покрыта e2e.
6. **Сеть**: PubMed работал на прогоне build (esearch 200, esummary OK), sleep 0.4 c
   между запросами, ретраи 2× на 429/5xx/таймаут. WB/Ozon недоступны → цена «дата
   неизвестна» (см. п.2).
7. **ui_verify переведён с networkidle на domcontentloaded** + явные ожидания —
   networkidle на этой машине зависает. Скриншоты v261_* (index, sort_grade,
   modal_economics) и остальные обновлены финальным прогоном.
8. **Гард-тест** (tests/test_economics_guard.py) проверяет отсутствие строковых
   литералов «Ценность», «Value Score», «valueScore» в script.js и в видимом тексте
   index.html; комментарии в JS допустимы и используются. Сортировки сверяются
   позитивно (science/price_asc/name/grade есть; value/reviews отсутствуют).
9. **Схема ma_top3** (tests/test_ma_top3.py): pmid — цифры (или null), year
   1990–2026 (или null), title непустой, в карточке не более 3 записей; price_date
   — у всех карточек. Пример: Кофеин pmid 42621780, 42588143, 42588052 (year 2026).
10. **Файлы с кириллицей** правились построчно (Edit/Write/python encoding=utf-8),
    PowerShell Set-Content/Out-File не использовался (ломал кодировку).
11. **Скриншоты ui_verify не детерминированы по байтам** — регенерятся каждый
    прогон; в релиз зафиксирован финальный прогон (коммит f20be42).
12. **Nodes**: Node в PATH отсутствует, за всё время не понадобился (Playwright —
    Python). Сборка обновлённых HTML вручную не требуется (JS подтягивает data.json).
