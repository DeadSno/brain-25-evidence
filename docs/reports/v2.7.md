## Нюансы и замечания
- Параллельность через ОБЩИЙ рабочий каталог дала сбой: агенты переключали
  ветки в одном рабочем дереве, коммиты «уезжали» (ed4c0a7 — PWA на ветке c).
  Восстановлено commit-tree/update-ref; PWA-файлы в B и C оказались идентичны,
  поэтому мёрдж чист. Вывод: для следующих параллелей оркестратору лучше
  выдавать части с независимыми worktrees (git worktree) — иначе риск.
- data.json ни одна часть не меняла (P11 соблюдено). index.html получил 3
  независимые строки подключения (science2.js/tracker.js/pwa.js) — конфликты
  разрешены сохранением всех трёх (O2).
- Трекер A: кнопка в модалке и секция «Мои добавки» внедряются из tracker.js
  (MutationObserver + console.warn-гард localStorage myCourse); двойной
  fetch(data.json) для получения dosage — 180KB×2 пренебрежимо.
- PWA B: e2e-офлайн-фолбэк стабилизирован — ждать controller на первой
  странице, контролируемый reload ?ts=, затем offline-прогон.
- Пульс C: ценовая история живёт вне docs-deploy (price_history.csv пуст) —
  агрегат выгружен в docs/data_price_history.json, спарклайн честно в фолбэке
  («история копится с v2.1, спарклайн появится после 90 замеров»).
  ma_top3/годы МА: 71/81 добавок (PubMed esearch retmax=100 + esummary),
  остальные — пустые по запросу либо обрывы сети (сон 0.4 c соблюдён).
