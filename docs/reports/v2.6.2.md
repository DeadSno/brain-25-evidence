## Замечания и нюансы

1. **Каша в F1.1 не найдена** — фикс-скрипт не применялся, в отчёте зафиксировано.
   «Показатель», «Способность» и другие строки из брифа F1.1 есть только в ТЕКСТЕ брифа,
   кода они не касаются (рендер этих слов — «Цена ₽/мес», «Сравнить», «Радар профиля» —
   идёт из script.js, файл чистый UTF-8).
2. **e2e-строка F1.3**: в брифе была задумана «Показатель», но такого рендер-слова в
   дереве нет (только в брифе). Вместо этого взята строка исключительно из JS —
   «цена не найдена» (noPrice, script.js) — она не присутствует в HTML и полностью
   закрывает «слепую зону» (прошлая e2e-строка была из HTML).
3. **Радар не был доступен через window.** Топ-левел объявление `radarInstance` (let) не
   попадало на `window`, в отличие от chart/quadrantChart (явные window.*). e2e ждал
   `window.radarInstance != null` → падал. Фикс: `window.radarInstance = radarInstance` в
   конце renderCompare (bf8f5a5). Это же подтверждает, что радар рендерится событийно, а
   не в моменте загрузки.
4. **Светлый акцент #007aff НЕ проходит 4.5:1** (4.02:1 на белом). Бриф требует «текущий
   синий» (F3.1) И контраст ≥4.5:1 (F3.2) — они конфликтуют. Решение: #0062cc (5.8:1),
   хроматически тот же синий, только чуть темнее. Отклонение от буквы F3.1 сознательное,
   чтобы выполнить жёсткий критерий F3.2; отмечено в CHANGELOG.
5. **Тёмная тема #8ecbff на тёмном фоне** — 8.05:1 (подтверждено); underline добавлен.
   Также поправлен юр. footer: opacity:.75 → color:var(--muted) (опакность резала контраст
   всем футерным ссылкам сразу); в changelog_public футер-ссылка избавилась от inline
   color:inherit (перекрывал тему).
6. **Переход .25s на body ломал замер контраста**: classList-toggle мерял фоновый цвет
   ПОСЕРЕДИНЕ CSS-перехода (bg≈rgb(194,194,196)). В e2e/ui-verify тема теперь задаётся
   через localStorage + релоад страницы, без classList-переворота.
7. **pctile цены учитывает null как 0** (совпадает с JS): ссылочная реализация в тесте
   приведена к коду — массив цен базовой 81 карточки без фильтрации null (в test:
   x.get("price") без if). Креатин (цена null) в радаре получает «Доступность»=0.
8. **ui_verify переведён с networkidle на domcontentloaded** (networkidle на этой машине
   зависает) — наносное наблюдение, уже в v2.6.1.
9. **Отчёт о затронутых тестах**: test_no_mojibake_in_js.py читает ВСЕ docs/*.js и *.html
   на биграммы каши; test_v262_radar.py воспроизводит pctile-алгоритм (все оси ∈[0,100],
   base=81, инверсия цены); test_v262_trust.py проверяет структуру (qaGrid 3 колонки,
   trustChips 5, media 375px) и наличие chartSummary в script.js.
10. **Файлы с кириллицей** правились построчно (Edit/Write/python encoding=utf-8),
    PowerShell Set-Content/Out-File не использовался (ломал кодировку).
11. **Скриншоты ui_verify не детерминированы по байтам** — зафиксирован финальный прогон
    (v262_* + обновлённые v26/v261).
12. **Сеть**: внешние API в этом прогоне не трогались (только локальный playwright),
    PubMed/цены не дёргались — данных не менялось.
13. **Worktree для baseline**: C:\Users\TshK\AppData\Local\Temp\opencode\main-base (main
    9acbd6a) — замер до. После сдачи отчёта удалить `git worktree remove`.
