## Нюансы (важно для мерджа)

1. **`data/processed/price_history.csv` вне docs-deploy.** Файл живёт в `data/`, а сайт и e2e сервятся из `docs/` (GitHub Pages, `http.server -d docs`). Прямая выборка CSV из браузера дала бы 404 в консоли и уронила бы общий `assert not errors` старых e2e-блоков. Решение: build-скрипт агрегирует CSV при сборке в сервируемый `docs/data_price_history.json` (`{id: [[дата, median] × ≤90]]}`); при пустом/отсутствующем CSV — честный `{}` и фолбэк-текст. Это отклонение от буквы «читаем CSV напрямую» — данные те же, поле `id` сохранено, CSV сейчас пустой (только заголовок), так что визуально ничего не меняется.
2. **Спарклайн не трогает модалку ветки A** — только `MutationObserver` на `#modalOverlay`; id берётся из глобальной `curModal`/`location.hash`/`#modalBody h2`. Встраивается после `.blockTitle` «ЭКОНОМИКА».
3. **Кэш закоммичен** (как требует C1): `data/processed/ma_years.json` (371 год-точка по 71 добавке). `data.json` не трогали (P11).
4. **`index.html` получил одну строку от Части C** (`science2.js` defer); строки `tracker.js` (Часть A) и `pwa.js` (Часть B) в рабочем дереве уже были наложены оркестратором — конфликтов по строкам подключения при мердже не жду, все три скрипта уживаются (Modal/трекер/SW глазу не мешают).
5. **Сеть**: eutils отвечал (верификационный запрос `caffeine AND meta-analysis[pt]` → 387), один прогон C1 прошёл без 429/5xx.
