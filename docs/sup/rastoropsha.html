Расторопша

Грейд B — зависит от контекста

О добавке

Силимарин стабилизирует мембраны гепатоцитов; маркеры улучшает, клиническая значимость спорна.

Кому нужно: МАСЛД/НАЖБП (адъюнкт к образу жизни); при инсулинорезистентности у СД2 — есть данные.

Когда эффект: Эффект курсовой: ферменты и HOMA-IR через 4–12 недель; быстрого «очищения печени» нет.

Осторожно

Расторопша (Silybum marianum, силимарин). Для метаболической дисфункции печени (МАСЛД): есть Cochrane-обзор. Для алкогольного/вирусного гепатита: Cochrane показывает ограниченную эффективность. Для инсулинорезистентности: есть данные. Клиническая значимость спорная — биохимические маркеры улучшаются, но клинические исходы часто незначимы. Безопасна.

Мифы

«Восстанавливает печень после алкоголя» — общая смертность не снижает (RR 0.78). «Сахар всем» — HOMA-IR падает только у СД2, при НАЖБП нет.

Как выбирать

Силимарин 420 мг/сут (не порошок), курсы месяцами; при жалобах — сначала диагностика печени.

Пищевые источники: Обычные семена годятся лишь для чая; клиническая доза — стандартизованный силимарин 420 мг.

Клинические рекомендации: Cochrane 2007 (18 РКИ, 1088): общая смертность NS, печёночная RR 0.50; SR 2025: HOMA-IR −2.29 у СД2, при НАЖБП нет.
