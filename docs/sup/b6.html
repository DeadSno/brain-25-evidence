B6

Грейд B — работает

О добавке

Пиридоксин (B6): снижает тошноту и рвоту при беременности (МА 2023); при нейропатии как монотерапия не изучен, а высокие дозы сами токсичны для нервов.

Кому нужно: Беременные с тошнотой/рвотой — пиридоксин отдельно или в комбинации; при нейропатии — только в составе лечения под контролем дозы; высокие дозы — риск сенсорной нейропатии.

Когда эффект: При тошноте беременности — улучшение в течение приёма (МА 2023); для других показаний сроки не установлены.

Дозировка

Стандартная доза: Для тошноты при беременности — по схемам РКИ из МА 2023 (в абстракте доза не приведена).

Курс: На период симптомов тошноты/рвоты при беременности.

Верхний предел: не установлен (в абстрактах не приводится; высокие дозы нейротоксичны)

Осторожно

Высокие дозы → сенсорная аксональная нейропатия, симптомы улучшаются после отмены (СР 2023); при беременности доза — по врачу.

Мифы

«B6 лечит нервы» — в СР 2023 данных о B6 как монотерапии нейропатии нет. «Больше B6 — лучше» — наоборот: высокие уровни дают сенсорную аксональную нейропатию. «Натуральный — значит безопасный» — доза решает.

Взаимодействия

Известных взаимодействий нет

Как выбирать

Пиридоксин в дозах для NVP под контролем врача; не принимать мегадозы; при нейропатии самостоятельно не назначать.

Пищевые источники: Курица, рыба, печень, картофель, бананы, нут, цельнозерновые; при термообработке потери значительны.

Клинические рекомендации: МА 2023 (18 исследований): пиридоксин один и в комбинации — Rhode's 0.78 [0.26-1.31], PUQE 0.75 [0.28-1.22]; СР 2023: высокие дозы B6 — риск нейротоксичности.
