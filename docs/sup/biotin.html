Биотин

Грейд D — не подтверждено

О добавке

Витамин B7: полезен только при дефиците; у здоровых на волосы/ногти не доказано; искажает анализы.

Кому нужно: Только подтверждённый дефицит (генетика, парентеральное питание, сырые яйца); здоровым для волос/ногтей — не доказано.

Когда эффект: При дефиците — неделями; у здоровых эффекта нет вовсе.

Метрики

Индекс науки: 48 · РКИ: 28 · Мета-анализов: 4

Категория: Кожа/Волосы

Эффекты

Волосы/ногти только при дефиците; мешает анализам

Механизмы действия

Кофермент карбоксилаз (кератин косвенно)
Волосы/ногти только при дефиците; мешает анализам
контекст
Кофермент четырёх карбоксилаз: метаболизм жирных кислот/глюконеогенез
У мальнутришных и беременных маркеры дефицита ниже; гликемический контроль при СД2 сомнителен
контекст
Заявленный контроль глюкозы и липидов при СД2
Общий холестерин ниже (−0.22); глюкоза/ТГ на грани значимости; инсулин без эффекта (5 РКИ, 445)
маркетинг

Дозировка

Стандартная доза: 30-100 мкг/сут

Курс: —

Верхний предел: Формального UL не установлен — данных о токсичности нет.

Осторожно

Биотин (витамин B7, витамин H). В базе НЕТ систематических обзоров или мета-анализов по клиническим эффектам у здоровых. Дефицит биотина редок (только при генетических заболеваниях, длительном парентеральном питании, употреблении сырых яичных белков). У здоровых людей с нормальным уровнем — добавки не имеют доказанного эффекта на волосы/ногти/кожу. Побочки: искажение лабораторных тестов (тропонин, гормоны щитовидки).

Мифы

«Для волос и ногтей всем» — только при дефиците. «Безвреден в любых дозах» — искажает иммуноанализы (щитовидка, тропонин).

Как выбирать

30-100 мкг/сут с едой; за 48 ч до анализов щитовидки/тропонина отменить; на волосы — только при дефиците.

Пищевые источники: Яйца, печень, орехи, бобовые, молоко; дефицит при обычном питании маловероятен.

Клинические рекомендации: МА 2022 (5 РКИ, 445): TC −0.22 значим, глюкоза/ТГ на грани, инсулин без эффекта. Риск: искажение иммуноанализов.
