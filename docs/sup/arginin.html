Аргинин

Грейд B — зависит от контекста

О добавке

Предшественник оксида азота: для пампинга слабее цитруллина; ниши — преэклампсия, НЭК у недоношенных.

Кому нужно: Беременные с риском преэклампсии, недоношенные (НЭК) — по назначению врача. Для спорта лучше L-цитруллин.

Когда эффект: АД-отклик за часы-дни; преэклампсия — курсы неделями; в спорте эффект непредсказуем.

Метрики

Индекс науки: 4412 · РКИ: 2557 · Мета-анализов: 371

Категория: Сосуды/Беременность

Эффекты

АД/пампинг: слабее цитруллина, контекст

слабо

Дозировка

Стандартная доза: 3-6 г/сут (часто ЖКТ-побочки)

Курс: —

Верхний предел: Формального UL не установлен — данных о токсичности нет.

Осторожно

L-аргинин — прекурсор оксида азота (NO). Для профилактики преэклампсии: данные есть. Для некротизирующего энтероколита (НЭК) у недоношенных: Cochrane подтверждает эффективность. Для оксид азота при стенокардии: Cochrane. Для давления: умеренное снижение. Для эректильной дисфункции: ограниченные данные (часто с пикногенолом). Для гликемического контроля: смешанные данные.

Мифы

«Мощный пампинг» — биодоступность низкая, цитруллин лучше. «Больше — лучше» — выше 6 г бьёт по ЖКТ. «Лечит преэклампсию» — лишь снижает риск.

Как выбирать

Если аргинин: L-форма, без «технологий». Доза — по цели приёма (преэклампсия / НЭК — по назначению врача).

Пищевые источники: Мясо, птица, рыба, орехи, семена тыквы; но биодоступность из еды спорна — проще цитруллин.

Клинические рекомендации: Преэклампсия: RR 0.52 (0.35–0.78, низкая уверенность). НЭК у недоношенных: Cochrane. Спорт: 3–6 г/сут — считаться с ЖКТ.
