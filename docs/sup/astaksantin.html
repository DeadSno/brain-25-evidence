Грейд C — зависит от контекста
🔬 3 в PubMed ✓ в сравнении

О добавке

Каротиноид: после нагрузки креатинкиназа ниже, кожа лучше; на VO2max и исходы ЭКО — нет.

Кому нужно: Восстановление после тренировок (мышечные ферменты вниз); фотостарение кожи; фертильность (созревание ооцитов) — контекст.

Когда эффект: Курсовой: кожа — 3-6 мг/сут за недели; маркеры восстановления — после нагрузок.

Осторожно

Астаксантин — каротиноид из водорослей Haematococcus pluvialis. Для кожи: систематический обзор (32202443) показывает улучшение параметров. Для фертильности: есть данные (39127677, 41714661). Для спорта/восстановления: данные ограниченные. Для печени: есть данные. Данных по клиническим исходам мало — в основном биомаркеры. Безопасен в дозах 4-12 мг/день.

Мифы

«Прокачает VO2max» — нет (24 РКИ), работает восстановление. «Лечит бесплодие» — созревание ооцитов лучше, ЭКО без изменений.

Как выбирать

3-6 мг/сут для кожи, 4-12 мг/сут с жирами для восстановления; стандартизация по Haematococcus pluvialis.

Пищевые источники: Исходно микроводоросль; в еде (лосось, криль) концентрации малы — рабочие 3-6 мг из добавки.

Клинические рекомендации: МА 2026 (24 РКИ): креатинкиназа SMD −0.45, ЛДГ −0.93, VO2max без сдвига. Кожа (SR 2021): 3-6 мг/сут на текстуру/морщины.
