NAC

Грейд B — работает

О добавке

Прекурсор глутатиона — главного антиоксиданта клетки: меньше обострений ХОБЛ, защита печени.

Кому нужно: При ХОБЛ с частыми обострениями; печёночная недостаточность (в т.ч. парацетамол); резистентный H. pylori.

Когда эффект: Мгновенного эффекта нет: при ХОБЛ обострения реже на дистанции, NAC пьют курсами.

Курс: курсы

Верхний предел: Формального UL не установлен — данных о токсичности нет.

Осторожно

N-ацетилцистеин — прекурсор глутатиона. 4 Cochrane-обзора в базе! Для ХОБЛ: снижает частоту обострений. Для острой печёночной недостаточности (не-парацетамол): Cochrane. Для H. pylori (адъювант): Cochrane. Для сепсиса: Cochrane. Для психиатрии (ОКР, трихотилломания, биполярное): есть РКИ с положительными данными. Доза: 600-1200 мг 2 раза/день. Безопасен, побочки: GI.

Мифы

«Антиоксидант = здоровье» — при сепсисе смертность не снизил (Cochrane). «Выше доза — лучше» — при ХОБЛ >600 мг без пользы; работает до 600 мг.

Как выбирать

Любая L-форма NAC, 600–1200 мг/сут. Дорогие «спортивные» версии не нужны — обзоры по классической форме.

Пищевые источники: Отдельного пищевого источника нет: NAC — производное цистеина; цистеин есть в мясе, яйцах, овсянке.

Клинические рекомендации: Cochrane: при ХОБЛ обострений меньше (RR 0.87) на дозах до 600 мг; для сепсиса пользы нет; при H. pylori — адъюнкт.
