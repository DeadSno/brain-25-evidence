О добавке

Лейцин/изолейцин/валин: спорт-эффекта при достатке белка нет; ниша — печёночная энцефалопатия.

Кому нужно: Цирроз с печёночной энцефалопатией; спортсменам/веганам с нехваткой белка — но лучше просто белок.

Когда эффект: Энцефалопатия: симптоматически, курсами; для мышц мгновенного эффекта не закреплено.

Осторожно

BCAA (лейцин/изолейцин/валин). Для печеночной энцефалопатии при циррозе: 4 Cochrane-обзора показывают эффективность. Для спорта: мета-анализы противоречивы — многие показывают отсутствие клинически значимого эффекта. Для саркопении при циррозе: есть данные. Для онкологии/операций: данные ограниченные.

Мифы

«Качают мышцы без еды» — при достатке белка эффекта нет. «Лечат печень» — только при энцефалопатии на циррозе, на смертность не влияют.

Формы выпуска

микронизированный, инстант (2:1:1)

Как выбирать

Брать добавку только под цирроз с энцефалопатией; для спорта бессмысленно — белок/протеин эффективнее.

Пищевые источники: Яйца, мясо, молоко, соя: весь белок содержит BCAA — проще есть белок, чем добавку.

Клинические рекомендации: Cochrane 2017: BCAA уменьшают симптомы энцефалопатии (16 РКИ), смертность не меняют; для спорта пользы нет.
