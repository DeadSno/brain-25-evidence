О добавке

Кофермент метильного цикла: критичен для нервной трубки плода, снижает гомоцистеин.

Кому нужно: Планирующие/беременные (нервная трубка), при повышенном гомоцистеине, веганы, пожилые с дефицитом по анализу.

Когда эффект: За 1–3 месяца до зачатия; гомоцистеин за недели; для когниции пожилых — без эффекта.

Метрики

Индекс науки: 2693 · РКИ: 1173 · Мета-анализов: 304

Категория: Беременность/Кровь

Эффекты

Когниция (при дефиците/MCI) (не подтверждено)

Механизмы действия

Метильный цикл, гомоцистеин

контекст
Метильный цикл в эмбриогенезе: закрытие нервной трубки

сильно

Мало подтверждений в PubMed (2 источников).

Осторожно

Фолиевая кислота (витамин B9). 12 Cochrane-обзоров в базе! Для профилактики дефектов нейральной трубки: Cochrane подтверждает эффективность (400 мкг/день за 1-3 месяца до зачатия и в первом триместре). Для беременности: Cochrane. Для снижения гомоцистеина: работает. Для когнитивных функций у пожилых: Cochrane не показывает пользы. Осторожно: маскирует дефицит B12 у пожилых. Метилфолат (5-MTHF) — активная форма для людей с полиморфизмом MTHFR.

Мифы

«Все витамины B одинаково» — именно фолат периконцептивно (RR 0.28) закрывает тему нервной трубки. «Память пожилым» — Cochrane пользы не показал.

Формы выпуска

метилфолат, фолиевая кислота

Как выбирать

Обычный фолат 400–800 мкг; при MTHFR — 5-MTHF (метилфолат). В комплексах ищи именно такие дозы.

Пищевые источники: Шпинат, печень, бобовые — но фолат лабилен и всасывается хуже; синтетический надёжнее.

Клинические рекомендации: 400 мкг/день периконцептивно (WHO); гомоцистеин — доза по анализу. На преждевременные роды не влиял (Cochrane).
