Шатавари

Грейд C — зависит от контекста

О добавке

Классика аюрведы для женского здоровья. Основное применение — стимуляция лактации у кормящих матерей.

Кому нужно: Кормящие матери с недостатком молока (есть РКИ). Женщины в менопаузе — данных мало, есть традиционное использование.

Когда эффект: 3-7 дней для эффекта на лактацию; для адаптогенного эффекта — 2-4 недели.

Метрики

Индекс науки: 8 · РКИ: 8 · Мета-анализов: 0

Категория: Общее

Эффекты

Лактация Женское здоровье Пищеварение

Механизмы действия

Сапонины (шатавари-сапонины): стимулируют синтез пролактина
Усиление лактации у кормящих матерей
умеренно
Адаптогенный эффект: модуляция ГАМК и серотонина
Снижение тревожности, улучшение настроения
слабо
Улучшение пищеварения: мягкий слабительный эффект
Пищеварение, ЖКТ-комфорт
контекст

Дозировка

Стандартная доза: 250-500 мг экстракта 2 раза/сут, стандартизация по сапонинам

Курс: 4-8 недель; для лактации — по назначению

Верхний предел: Формального UL нет. Дозы до 1 г/сут считаются безопасными короткими курсами.

Осторожно

Не рекомендуется при беременности без консультации врача. При лактации возможен эффект на гормоны. Проверить наличие исследований на людях — их мало.

Мифы

«Стимулирует женские гормоны у мужчин» — нет данных. «Работает для фертильности у всех» — только ограниченные данные для конкретных групп.

Взаимодействия

Как выбирать

Стандартизированный экстракт по сапонинам 20-40%; избегать порошков неизвестного происхождения.

Пищевые источники: В пищу не употребляется — корень принимается как экстракт или отвар.

Клинические рекомендации: Не входит в рекомендации EFSA, FDA. Аюрведические источники указывают широкое применение, современные РКИ ограничены.
