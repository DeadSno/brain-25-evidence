Метионин

Грейд D — не подтверждено

О добавке

Все три мета-анализа по метионину — про дойных коров, а не про людей; для человека как добавки данных в пуле нет.

Кому нужно: Ни для кого по данным пула: все три мета-анализа выполнены на коровах, ни один — на людях.

Когда эффект: Сроки ответа изучались только у коров: 68-72 дня для защищённого метионина. Для человека не изучалось.

Метрики

Индекс науки: 43 · РКИ: 18 · Мета-анализов: 5

Категория: Метаболизм

Эффекты

Нет подтверждённых эффектов у людей

Механизмы действия

Дозировка

Стандартная доза: Все цифры в пуле — для коров: 3.5-67.9 г/сут, оптимум 13.2-16.4 г/сут защищённого метионина

Курс: в абстрактах для человека не указан; у коров оптимальная длительность 68-72 дня

Верхний предел: в абстрактах не указан

Осторожно

Переносить дозы и эффекты с дойных коров на человека нельзя: эти животные используют метионин для синтеза белка молока.

Мифы

«Мета-анализ доказывает пользу» — все три проведены на метионине для дойных коров, переносить их на человека нельзя. «Улучшает силу» — в пуле нет ни одной работы на людях.

Взаимодействия

Известных взаимодействий нет

Как выбирать

Выбирать нечего: подтверждённых доз для человека нет, а указанные в мета-анализах граммы рассчитаны на коров с обратным перегоном.

Пищевые источники: В abstract'ах пула пищевые источники для человека не обсуждаются: все три мета-анализа про кормление дойных коров.

Клинические рекомендации: Рекомендаций по метионину для человека в пуле нет: доступны только мета-анализы по продуктивности дойных коров.
