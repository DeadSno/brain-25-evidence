Лаванда

Грейд C — зависит от контекста

О добавке

Один из немногих растительных анксиолитиков, проверенных в крупных РКИ (Silexan — стандартизированное масло). Сравним с лоразепамом в исследованиях по тревожности.

Кому нужно: Люди с тревожными расстройствами лёгкой и средней степени. Студенты в стрессовые периоды. Как вечерний ритуал для сна.

Когда эффект: 30-60 минут для острого успокаивающего эффекта; 2-6 недель для устойчивого.

Дозировка

Стандартная доза: 80-160 мг масла в капсулах (Silexan) или 1-2 капли эфирного масла на саше/диффузор

Курс: 6-10 недель для устойчивого анксиолитического эффекта

Верхний предел: Формального UL нет. Капсулы Silexan 80-160 мг/сут хорошо переносятся.

Осторожно

Перорально только стандартизированное масло в капсулах (Silexan). Обычное эфирное масло внутрь НЕ принимать — токсично. При беременности — избегать. Может усилить эффект седативных.

Мифы

«Все эфирные масла одинаковы» — нет, работает только стандартизированное с линалилацетатом. «Мгновенно вырубает» — мягкий эффект, не снотворное.

Как выбирать

Silexan (стандартизированный препарат) или эквивалент в капсулах. Для ароматерапии — 100% эфирное масло, не ароматические смеси.

Пищевые источники: Как пряность в кулинарии (очень мало). Основное — эфирное масло или экстракт.

Клинические рекомендации: Есть РКИ (Silexan vs лоразепам, vs плацебо) — один из немногих с приличной доказательной базой. EFSA health claims не одобряет.
