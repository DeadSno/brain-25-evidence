Аланин

Грейд C — зависит от контекста

О добавке

Мета-анализ в пуле — по β-аланину, а это другое вещество, не α-аланин; по самому α-аланину данных нет.

Кому нужно: Ни для кого по данным пула: исследований α-аланина как добавки нет. Данные по β-аланину относятся к другому веществу.

Когда эффект: Сроки для α-аланина не изучались; в мета-анализе по β-аланину протоколы были только хротическими.

Метрики

Индекс науки: 5 · РКИ: 0 · Мета-анализов: 1

Категория: Спорт

Эффекты

Выносливость при нагрузке 0.5-10 мин Общая работоспособность (β-аланин)

Механизмы действия

В мета-анализе β-аланина эффект на выносливость при нагрузках 0.5-10 минут был 0.50 против 0.11 для результата за нагрузку
Выносливость на нагрузках 0.5-10 мин
умеренно
Длительность нагрузки значимо модифицировала эффект (p = 0.004), а тренированность и режим нагрузки — нет
Эффект зависит от типа нагрузки
слабо
Мета-анализ выполнен для β-аланина; α-аланин в работах пула не применялся
Эффект α-аланина не исследован
маркетинг

Дозировка

Стандартная доза: В мета-анализе отмечено, что общее количество принятого β-аланина не модифицировало эффект; конкретные дозы в abstract'ах не приведены.

Курс: в abstract'ах указан только хронический приём; конкретная длительность не названа

Верхний предел: в абстрактах не указан

Осторожно

В пуле смешаны три темы: β-аланин для выносливости, антидепрессанты и питание женщин-спортсменок; сам аланин не изучался.

Мифы

«Бета-аланин — это аланин» — разные вещества: β-аланин идёт в мышечный карнозин, α-аланин не изучался ни в одной работе пула. «Данные есть» — они по β-аланину, общий эффект 0.18 при 1461 участнике.

Взаимодействия

Известных взаимодействий нет

Источники

β-alanine supplementation to improve exercise capacity and performance: a systematic review and meta-analysis
Br J Sports Med · 2017 · PMID 27797728

Как выбирать

Данных по α-аланину нет, покупать нечего. Если интересует выносливость, в пуле есть только препарат β-аланина.

Пищевые источники: В abstract'ах пула пищевые источники не обсуждаются: мета-анализ по β-аланину касался перорального приёма препарата.

Клинические рекомендации: Рекомендаций по аланину в пуле нет: единственный спортивный обзор — по женщинам-спортсменкам, конкретно про аланин там не сообщается.
