Марганец

Грейд D — не подтверждено

О добавке

Марганец — эссенциальный микроэлемент, но в SR по минералам для спорта прямо указано: релевантных работ по марганцу не найдено.

Кому нужно: Только при подтверждённом дефиците или при нутритивной поддержке. Ни в данных по спортивной работоспособности, ни по веганской диете дефицит марганца не выявлен.

Когда эффект: Не изучалось: РКИ с приёмом марганца в пуле нет.

Метрики

Индекс науки: 541 · РКИ: 161 · Мета-анализов: 76

Категория: Общее

Коррекция дефицита марганца

Механизмы действия

Минералы и микроэлементы участвуют в сотнях биологических процессов, и марганец относится к этому классу

Осторожно

ESPEN отмечает потенциальную токсичность микронутриентов при избытке; данных о безопасных дозах марганца в пуле нет.

Мифы

«Марганец нужен всем спортсменам» — в SR по 128 работам исследований по марганцу не нашли. «Улучшает рост волос» — в SR по алопеции марганец есть лишь в списке, в выводах его нет.

Взаимодействия

Известных взаимодействий нет

Как выбирать

Добавки марганца не поддержаны ни одной работой на людях из пула; при подозрении на дефицит — анализ, а не самостоятельный приём.

Пищевые источники: Крупы, орехи и чай; отдельных данных об источниках марганца в abstract'ах пула не приводится.

Клинические рекомендации: ESPEN 2022 даёт рекомендации по микронутриентам на основе консенсуса: интервенционных исследований мало, мета-анализ провести не удалось.
