Сывороточный протеин

Грейд A — работает

О добавке

Золотой стандарт белка: лейцин + полный амино-профиль; работает при силовых нагрузках и саркопении.

Кому нужно: Спортсмены (1.6–2.2 г белка/кг/сут), пожилые с саркопенией, худеющие при дефиците калорий.

Когда эффект: Эффект копится тренировками, виден на 8–16 неделях; быстрого «пампа» масса не даёт.

Метрики

Индекс науки: 792 · РКИ: 467 · Мета-анализов: 65

Категория: Спорт/Мышцы

Эффекты

Мышцы и профилактика саркопении: обширные МА

Механизмы действия

Лейцин → mTOR + полный амино-профиль → синтез мышцы

контекст

Дозировка

Стандартная доза: 20-40 г после тренировки; всего 1.6-2.2 г белка/кг/сут

Курс: —

Верхний предел: Формального UL не установлен — данных о токсичности нет.

Осторожно

Сывороточный протеин (whey) — золотой стандарт белка для спортсменов и пожилых. Для мышечной массы: множество мета-анализов подтверждают эффективность при сочетании с силовыми тренировками. Для саркопении у пожилых: работает. Для гликемического контроля: улучшение постпрандиальной глюкозы. Для потери веса: есть данные при сочетании с диетой. Изолят vs. концентрат: изолят содержит больше белка. Доза: 20-40 г/день.

Мифы

«Сам по себе строит мышцы» — без силовой нагрузки на саркопению нет (10 РКИ, 1154). «Чем больше, тем лучше» — свыше 2.2 г/кг выгоды нет.

Как выбирать

Изолят при лактозной непереносимости; 20–40 г после тренировки; ориентир — лейцин ≥2.5 г на порцию.

Пищевые источники: Молочная сыворотка: молоко, кефир, творог; добавками экономно доедают белок, когда еды мало.

Клинические рекомендации: МА 2023–2024: при саркопении мышцы SMD 0.47 и ходьба 1.13; композиция тела — только с нагрузкой и дефицитом калорий.
