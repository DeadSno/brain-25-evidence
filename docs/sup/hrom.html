Хром

Грейд C — зависит от контекста

О добавке

Усиливает сигналинг инсулинового рецептора; при СД2 — слабые сдвиги гликемии и липидов, вес — нет.

Кому нужно: СД2 с плохим гликемическим контролем (курсы 2–6 мес) и СПКЯ; для похудения — не работает.

Когда эффект: Эффект накопительный: глюкоза и инсулин меняются за 2–6 месяцев; быстрого нет.

Метрики

Индекс науки: 348 · РКИ: 153 · Мета-анализов: 39

Категория: Метаболизм/Диабет

Эффекты

Гликемия/вес: не подтверждён

контекст

Дозировка

Стандартная доза: 200-400 мкг/сут

Курс: —

Верхний предел: Формального UL не установлен — данных о токсичности нет.

Осторожно

Хром (чаще пиколинат). Для диабета 2 типа: мета-анализы показывают небольшое снижение глюкозы натощак и HbA1c. Для ожирения: Cochrane (24293292) показывает НЕЗНАЧИМЫЙ эффект на вес. Для СПКЯ: есть данные. Для давления: эффект малый. Данные смешанные, клиническая значимость спорная. Безопасен в стандартных дозах (200-1000 мкг/день).

Мифы

«Жиросжигатель» — Cochrane 2013 (9 РКИ, 622): вес незначим. «Как метформин» — 200 мкг при СПКЯ снижает HOMA-IR лучше, качество РКИ скромное.

Взаимодействия

Известных взаимодействий нет

Как выбирать

Пиколинат 200–400 мкг/сут под контролем глюкозы при СД2/СПКЯ; для похудения здоровым — не брать.

Пищевые источники: Брокколи, цельнозерновые, картофель, дрожжи; пищевого хрома на 200–400 мкг не набрать.

Клинические рекомендации: SR 2024: FPG/HbA1c/HOMA-IR ниже на курсах 2–6 мес; Cochrane 2013: вес без изменений; МА 2025 (СПКЯ): овуляций больше.
