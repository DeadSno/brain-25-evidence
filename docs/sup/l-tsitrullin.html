L-цитруллин

Грейд B — работает

О добавке

Прекурсор аргинина и NO: поднимает аргинин в плазме, даёт спортивный «пампинг»; давления не снижает.

Кому нужно: Спортсмены на интенсивных нагрузках (цитруллин-малат 6–8 г); при преэклампсии пользы не доказано.

Когда эффект: Острое действие при приёме за 60 мин до нагрузки; накопительного эффекта нет.

Осторожно

L-цитруллин — прекурсор аргинина и оксида азота (NO). Эффективнее самого аргинина (не метаболизируется в ЖКТ, поднимает уровень аргинина лучше). Для давления: мета-анализы показывают умеренное снижение. Для спорта: улучшение производительности и восстановления. Для эректильной функции: есть данные. Для преэклампсии: есть данные. Доза: 3-6 г/день. Безопасен.

Мифы

«Снижает давление» — МА 2018 без эффекта на АД. «Лечит преэклампсию» — данные есть у аргинина (RR 0.52), цитруллин — 1 РКИ без эффекта.

Как выбирать

Цитруллин-малат 6–8 г за 60 мин до нагрузки; биодоступнее аргинина, не метаболизируется в ЖКТ.

Пищевые источники: Вода из арбуза — богатый источник; для спортивной дозы проще добавка (6–8 г малата).

Клинические рекомендации: МА 2018: АД без изменений; SR 2025: аргинин при преэклампсии RR 0.52 (LOW), цитруллин — без данных.
