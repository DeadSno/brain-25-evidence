GLA

Грейд C — зависит от контекста

О добавке

GLA (масло вечерней примулы): при атопическом дерматите у детей есть указания на пользу при низком качестве работ; при акне и псориазе неэффективна.

Кому нужно: Дети с атопическим дерматитом без пищевой аллергии — есть данные об улучшении симптомов. Неэффективна при акне, псориазе, ПМС, сухих глазах и преэклампсии.

Когда эффект: В рамках приёма, недели-месяцы; при дерматите оценка идёт по шкале SCORAD, скорость в abstracts не уточнена.

Дозировка

Стандартная доза: Дозы в абстрактах не указаны: в исследованиях использовались разные схемы приёма масла вечерней примулы.

Курс: Курсом недель-месяцев по схемам из исследований; точные сроки в abstracts не приводятся.

Верхний предел: не установлен в абстрактах

Осторожно

Неэффективна при акне, псориазе, хроническом ручном дерматите, гепатите B, преэклампсии и синдроме Шёгрена.

Мифы

«Примула лечит кожу» — данные касаются атопического дерматита у детей. «Поможет при суставах» — при ревматоидном артрите результаты смешанные. «Доказано» — качество по Jadad низкое, обзор 2024 требует осторожности.

Как выбирать

Для кожи — масло Oenothera biennis; учитывать низкое качество исследований. При артрите и диабете данных для выбора недостаточно.

Пищевые источники: Лен, конопля и соя содержат следовые количества GLA; практический источник — масло семян вечерней примулы.

Клинические рекомендации: EAACI 2024: по вечерней примуле доказательств недостаточно. Обзор 2024: сильных рекомендаций по воспалительным состояниям нет из-за гетерогенности.
