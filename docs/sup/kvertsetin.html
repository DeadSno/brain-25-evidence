Кверцетин

Грейд B — работает

О добавке

Флавоноид: умеренно снижает систолическое АД; на выносливость эффект тривиальный.

Кому нужно: Повышенное САД как мягкое дополнение; гиперурикемия/подагра — есть данные; аллергия/ОРВИ — нет.

Когда эффект: Эффект на АД — курсовой, недели приёма; эргогенного «за раз» нет.

Осторожно

Кверцетин — флавоноид из лука/яблок. Для давления: мета-анализ (35948195) показывает умеренное снижение. Для кардиометаболических факторов: улучшение маркеров (umbrella review 37654199). Для выносливости: есть данные (22805526). Для гиперурикемии/подагры: есть данные (41514376). Биодоступность низкая — нужны формы с усилителями (пиперин, фосфолипиды). Доза: 500-1000 мг/день.

Мифы

«Лечит аллергию» — стабилизация тучных клеток только в пробирке. «Повышает выносливость» — ВО2max +1.9%, но «trivial» и для любителей (МА 2013).

Как выбирать

500–1000 мг/сут с пиперином (биодоступность); при давлении — не вместо, а вместе с лечением.

Пищевые источники: Лук, яблоки, чай, каперсы; биодоступность низкая — рабочая доза из добавки.

Клинические рекомендации: Umbrella 2023 (5 МА): САД −1.9 мм, инсулин −1.07; МА 2022: САД −2.4, в (пред)гипертониках ДАД −3.1.
