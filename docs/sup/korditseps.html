Кордицепс

Грейд B — работает

О добавке

Гриб ТКМ: при ХБП ниже креатинин/протеинурия; после трансплантации лучше метаболизм.

Кому нужно: ХБП без диализа (адъювант, с врачом); реципиенты почечного трансплантата (не вместо иммуносупрессии); спорт не обоснован.

Когда эффект: Курсовой: в ходе терапии ХБП маркеры лучше; после трансплантации эффект к 6-12 мес.

Метрики

Индекс науки: 94 · РКИ: 34 · Мета-анализов: 12

Категория: Почки/Выносливость

Эффекты

VO2: слабо у пожилых, у спортсменов нет

Механизмы действия

слабо

Отторжение = азатиоприн, но нефротоксичность и метаболизм лучше (2017)
контекст

Дозировка

Стандартная доза: 1-3 г/сут

Курс: —

Верхний предел: Формального UL не установлен — данных о токсичности нет.

Осторожно

Кордицепс (Cordyceps sinensis) — гриб из традиционной китайской медицины. Для ХБП: 2 Cochrane-обзора (25519252, 26457607) показывают улучшение функции почек как адъювант к стандартной терапии. Для реципиентов трансплантата почки: есть данные. Для выносливости: данные ограниченные (отдельные РКИ, не систематизированы). Для лёгочных заболеваний: данные ограниченные. Дорогой препарат, часто подделывают.

Мифы

«Спортивный эргогеник» — РКИ по выносливости единичные, не систематизированы. «Вылечит почки сам» — только адъювант, качество РКИ слабое.

Как выбирать

1-3 г/сут стандартизированного гриба, с проверкой качества; при ХБП/трансплантации — только с врачом.

Пищевые источники: Не еда: гриб, сырьё ТКМ; препарат дорогой и часто подделывают — источника из пищи нет.

Клинические рекомендации: 2024 МА (рак легких): адъювант — QoL лучше; 2024 МА (ХОБЛ, Bailing): функция легких выше. Стандартизация формы критична.
