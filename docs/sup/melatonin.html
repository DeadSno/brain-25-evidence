Мелатонин

Грейд A — работает

О добавке

Гормон циркадного сигнала «биологическая ночь», а не снотворное.

Кому нужно: Джетлаг, сменный график, поздний тип сна, возраст (свой синтез падает).

Когда эффект: Засыпание — 30-60 минут после приёма; сдвиг ритма — 3-5 дней приёма по схеме.

Метрики

Индекс науки: 390 · РКИ: 130 · Мета-анализов: 52

Категория: Сон/Циркадные ритмы

контекст

Дозировка

Стандартная доза: 0.5-3 мг за 30-60 мин до сна

Курс: по необходимости

Верхний предел: Формального UL нет; рабочие дозы 0.5-3 мг; 5-10 мг дают побочки, не эффект.

Осторожно

Оптимальная доза для пожилых: 1-3 мг (не мегадозы). Короткий период полураспада — лучше контролируемые формы. Не вызывает зависимости. Побочки: сонливость, головокружение. Осторожно: аутоиммунные заболевания, беременность.

Мифы

«Больше — быстрее уснёшь» — кривая доза-эффект плоская после 1-3 мг. «Можно месяцами» — данных мало, лучше курсами.

Как выбирать

Низкие дозы 0.5-1 мг; без связок «10 мг + травы».

Пищевые источники: Вишня, грецкие орехи, рис — следовые количества, без практической роли.

Клинические рекомендации: EFSA: 0.5 мг перед сном уменьшает джетлаг; NIH: коротким курсом для засыпания.
