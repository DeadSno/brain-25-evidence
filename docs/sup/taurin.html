Таурин

Грейд C — зависит от контекста

О добавке

Сульфоаминокислота-осмолит: улучшает кардиометаболические маркеры — глюкозу, липиды, АД, печень.

Кому нужно: Метаболический синдром, СД2, стеатоз, гипертония — кардиометаболические маркеры; для «ума» без доказательств.

Когда эффект: Кардиометаболический эффект курсовой: недели-месяцы; «успокоения» в РКИ нет.

Осторожно

Таурин — сульфокислота с множеством функций. Для кардиометаболизма: мета-анализы показывают умеренное улучшение давления/липидов у людей с метаболическими проблемами. Для когнитивных функций: данные ограниченные (40320621). Для роста у детей с низкой массой при рождении: есть данные (29368111). Безопасен в дозах 1-6 г/день.

Мифы

«Успокаивает и думать помогает» — когниция без эффекта (7 РКИ, 402); «энергетик» — доза в банке (~мг) копеечная против рабочих 1.5–3 г.

Как выбирать

Таурин 1.5–3 г/сут при СД2/гипертонии/стеатозе; для «энергии» или ума — не брать.

Пищевые источники: Мясо, морепродукты, рыба — главные источники; вегетарианцы в зоне низкого потребления, но дефицит редок.

Клинические рекомендации: МА 2026 (34 РКИ): глюкоза −5.9 мг/дл, ТГ −14.4, ЛПНП −5.1, САД −4.4, АСТ/АЛТ вниз; доза-эффект 1.5–3 г/сут.
