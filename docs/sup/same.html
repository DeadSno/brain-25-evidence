SAMe

Грейд B — работает

О добавке

Донор метильных групп; помогает при депрессии (адъювант), боли при остеоартрозе и поддержке печени.

Кому нужно: Взрослые с депрессией (дополнение к терапии); при остеоартрозе — мягкое обезболивание; при патологии печени.

Когда эффект: Депрессия: улучшение в первые недели; боль при артрозе — малый сдвиг к 1–3 мес.

Курс: —

Осторожно

SAMe (S-аденозилметионин) — универсальный донор метильных групп. Для депрессии: эффективность сравнима с СИОЗС в РКИ. Для остеоартрита: Cochrane-обзор (19821403) подтверждает обезболивающий эффект. Для печени: есть данные. Для биполярного расстройства: ОСТОРОЖНО (риск мании). Высокая цена, низкая стабильность — нужны кишечнорастворимые формы. Доза: 400-1600 мг/день.

Мифы

«Мгновенно поднимает настроение» — при большой депрессии эффект отсрочен. «Безобиден при биполярке» — риск мании, только с врачом.

Как выбирать

Кишечнорастворимые формы, 400–800 мг/д натощак; при депрессии/биполярке — только с врачом. Дорого.

Пищевые источники: Из еды напрямую не набрать — синтезируется организмом из метионина (яйца, рыба, бобовые).

Клинические рекомендации: Cochrane 2009: боль при артрозе −0.4 см VAS, функция та же. Печень: 1000–1200 мг/д улучшает параметры (SR 2024).
