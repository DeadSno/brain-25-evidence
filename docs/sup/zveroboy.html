Зверобой

Грейд B — работает

О добавке

Гиперфорин блокирует обратный захват серотонина: работает при лёгкой депрессии, сравним с СИОЗС.

Кому нужно: Лёгкая-умеренная депрессия, когда хочется избежать побочек СИОЗС; противопоказан при тяжёлой депрессии и суицидальности.

Когда эффект: Эффект к 4-12 неделям, заметен со 2-4 недели; данные только краткосрочные.

контекст

Дозировка

Стандартная доза: 300 мг 3 р/день (0.3% гиперицина)

Курс: 4-6 недель

Верхний предел: Формального UL не установлен — данных о токсичности нет.

Осторожно

Для лёгкой-умеренной депрессии: сравнимая эффективность с SSRI, НО меньше побочных. НЕ работает при тяжёлой депрессии/суицидальности. КРИТИЧНО: взаимодействие с лекарствами (индуктор CYP3A4) — снижает эффективность оральных контрацептивов, антикоагулянтов, антиретровирусных, иммуносупрессантов. Фотосенсибилизация.

Мифы

«Лечит тяжёлую депрессию» — только при лёгкой/умеренной. «Безопасная трава» — индуктор CYP3A4: режет контрацептивы и антикоагулянты.

Как выбирать

Экстракт 300 мг 3 р/д (0.3% гиперицина), курс 4-6 недель; проверить взаимодействия с лекарствами.

Пищевые источники: В аптеках — трава для чая, но рабочие дозы — стандартизованный экстракт, чаем их не набрать.

Клинические рекомендации: 2023 МА (vs СИОЗС): паритет по ответу и ремиссии; 2021 SR: индуктор CYP3A4, взаимодействие с варфарином. Только лёгкая-умеренная депрессия.
