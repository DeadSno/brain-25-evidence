NMN

Грейд C — не подтверждено

О добавке

Предшественник NAD+ — «молекула молодости»; метаболизм, силу и мышцы у людей не улучшает.

Кому нужно: Не определена: у здоровых пользы для глюкозы/липидов/мышц нет; слабые сигналы — только у пожилых и с ранними метабол. рисками.

Когда эффект: С 14 дней до 24 недель (250–2000 мг/д) метаболизм не менялся; «омоложения» нет.

Осторожно

NMN (никотинамидмононуклеотид) — предшественник NAD+. Для безопасности: есть данные (42514320) — хорошая переносимость. Для метаболизма глюкозы и липидов: данные смешанные (39531138). Для мышечной массы: данные ограниченные (40275690). Большинство данных — краткосрочные РКИ. Долгосрочные эффекты не изучены. НЕ подтверждена эффективность для 'омоложения' у людей.

Мифы

«Молекула молодости» — у людей глюкоза/липиды/мышцы не улучшаются (МА 2024-2025). «Дорого — значит работает» — дозозависимого эффекта нет.

Как выбирать

Если пробовать: 250–1000 мг/д (дозы РКИ) короткими курсами; метаболического эффекта ожидать не стоит.

Пищевые источники: NMN в еде не практично: следовые количества (брокколи, авокадо); добавки — единственный рабочий путь.

Клинические рекомендации: SR 2026 (15 РКИ, GRADE): курсы переносимы; широких метаболических преимуществ нет; «омоложение» не подтверждено.
