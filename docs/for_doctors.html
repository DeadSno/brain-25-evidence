🧠 БАДы: что работает, а что нет

Для врачей и нутрициологов

Этот проект — открытый справочник данных о биологически активных добавках, построенный на мета-анализах PubMed. Мы не даём медицинских рекомендаций — мы предоставляем данные для принятия решений.

Что мы предлагаем

Данные из мета-анализов

  • Прямые ссылки на PubMed (PMID) для каждого эффекта
  • Hedges' g и 95% доверительные интервалы
  • Верифицированные эффекты (ручная вычитка топ-2 МА)
  • Автоматический топ-3 МА по запросу (для быстрого обзора)

Мониторинг доступности

  • История цен с Wildberries и Ozon (с v2.1)
  • Спарклайны за 90 дней
  • Медиана двух площадок + флаг расхождения >40%

Взаимодействия

  • 400+ взаимодействий добавка↔лекарство
  • Уровни риска: критический / высокий / средний / низкий

Трекер приёма (доступен, v2.7)

  • Пациент отслеживает курс самостоятельно
  • Данные хранятся локально (localStorage), не на сервере

PWA

  • Сайт устанавливается на телефон и работает офлайн

Как использовать

Перед консультацией

Пациент открывает сайт, изучает данные по интересующей добавке, приходит на приём с конкретными вопросами.

Во время консультации

Врач сверяет данные сайта с собственными знаниями и клиническим опытом, принимает решение о назначении или отказе.

После консультации

Пациент использует трекер для мониторинга курса; длительность и доза фиксируются объективно.
