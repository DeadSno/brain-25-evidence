📐 Методология и ограничения данных

Источники

  • PubMed E-utilities — число публикаций по годам 2015–2025 для 130 добавок
  • Wikipedia REST API — просмотры ru.wikipedia помесячно (90 из 130 добавок)
  • OpenAlex — цитирования по годам (130 из 130 добавок, в scatter не используются)

Формула роста

growth_pub  = pubmed[id][2025] / pubmed[id][2015]
growth_wiki = avg(wiki[id][последние 6 мес]) / avg(wiki[id][первые 6 мес])

Допущения

  • Рост > ×1.5 — «значимый», > ×2.0 — «аномальный»
  • Z-score > 2σ — статистический выброс (аномалия)
  • Для wiki берём первые/последние 6 месяцев — сглаживает сезонность

Ограничения

  • PubMed индексирует препринты с 2019 — часть роста 2020–2022 может быть артефактом
  • Wiki-просмотры ≠ потребление БАД, а интерес (иногда — из-за новостных событий)
  • OpenAlex неполный до 2023 — сравнение цитат по годам некорректно
  • В каталоге 130 добавок; серии собраны для 130 (PubMed и цитирования) и 90 (Wiki). Категории «Спорт» (2) и «Сон» (3) — маленькие, выводы менее устойчивы чем для «Когниции» (26)

Покрытие серий

Серии публикаций PubMed и цитирований собраны для всех 130 добавок каталога — до сбора данных по DATA-P1-12 это были 94 из 130. Серия просмотров Wikipedia есть у 90 из 130: у остальных 40 нет статьи ru.wikipedia с историей просмотров, поэтому вторая метрика для них не считается. В разделе «Главное» и в расчёт z-score попадают 86 добавок — только те, у которых есть обе метрики. Ещё у 4 (Клюква, D-манноза, Йохимбин, Шатавари) в серии PubMed нет ненулевого значения за 2015 или 2025 год, а без обоих годовых значений рост не считается.
