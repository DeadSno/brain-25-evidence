Brain 25 Evidence is an open project about dietary supplements. No ads, no subscriptions, no monetization.

📊 What the project contains

  • 130 supplements — with an A–D evidence grade and an upper dose limit
  • 199 interaction pairs — conflicts and synergies; the same pairs drive the calculator
  • 37,618 PubMed papers — the corpus the data comes from
  • A PMID link on every card — every source can be opened and checked
The project is run by one person in their free time. A donation helps pay for hosting and motivates me to continue.

💚 What your support pays for

  • Server costs (still ₽0 — GitHub Pages)
  • A .ru or .org domain (planned)
  • Time to add new cards
  • Feature development: comparison, symptom search, export
