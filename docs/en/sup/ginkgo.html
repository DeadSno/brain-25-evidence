About this supplement

При патологии (деменция, постинсульт) EGb-761 может поддерживать когницию; у здоровых — эффекта нет.

Who needs it: Только при подтверждённой патологии: деменция лёгкой/средней тяжести (адъювант), ишемический инсульт. Здоровым — не нужен.

When it works: Когнитивные функции — 12-24 недели; только при патологии, у здоровых данных нет.

Caution

Cochrane-обзоры по деменции: эффект СТАТИСТИЧЕСКИ малый, клинически НЕ значимый. Для когнитивных функций у здоровых — НЕТ эффекта. Риск кровотечений (антиагрегантное действие) — осторожно с антикоагулянтами. НЕ предотвращает деменцию (крупное РКИ GEM, n=3069).

Myths

«Улучшает память всем» — эффект при возрастном снижении, не у здоровых. «Безопасен с аспирином» — риск кровотечений.
