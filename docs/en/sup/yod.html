About this supplement

Йод — микроэлемент для щитовидной железы; в подборке абстрактов положительных МА именно по йодовым добавкам нет, есть данные об ограничении йода при Хашимото.

Who needs it: Коррекция дефицита йода — по статусу питания (ESPEN подчёркивает значимость дефицитов); при Хашимото снижение йода эффекта не дало; здоровым без дефицита данных нет.

When it works: Данных нет: сроки эффекта йодовых БАД в абстрактах не описаны.

Caution

Избыток йода может ухудшить течение тиреоидита; при заболеваниях щитовидной железы — контроль врача; без дефицита добавка не обоснована.

Myths

«Больше йода — лучше щитовидка» — в обзоре 2023 диета с ограничением йода эффекта не показала. «Йод нужен всем» — добавка логична только при установленном дефиците. «Йод безвреден» — избыток йода влияет на железу.

How to choose

Принимать только при подтверждённом дефиците по назначению врача; доза и форма — по статусу; при заболеваниях щитовидной железы — особая схема.

Food sources: Морепродукты, рыба, водоросли, йодированная соль, молочные продукты; содержание зависит от региона и почвы.

Clinical guidelines: ESPEN 2022: оценка статуса и назначение микроэлементов при дефиците; SR 2023 (Hashimoto): ограничение йода эффекта не дало; положительных МА по йодовым добавкам в подборке нет.
