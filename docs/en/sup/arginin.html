About this supplement

Предшественник оксида азота: для пампинга слабее цитруллина; ниши — преэклампсия, НЭК у недоношенных.

Who needs it: Беременные с риском преэклампсии, недоношенные (НЭК) — по назначению врача. Для спорта лучше L-цитруллин.

When it works: АД-отклик за часы-дни; преэклампсия — курсы неделями; в спорте эффект непредсказуем.

Caution

L-аргинин — прекурсор оксида азота (NO). Для профилактики преэклампсии: данные есть. Для некротизирующего энтероколита (НЭК) у недоношенных: Cochrane подтверждает эффективность. Для оксид азота при стенокардии: Cochrane. Для давления: умеренное снижение. Для эректильной дисфункции: ограниченные данные (часто с пикногенолом). Для гликемического контроля: смешанные данные.

Myths

«Мощный пампинг» — биодоступность низкая, цитруллин лучше. «Больше — лучше» — выше 6 г бьёт по ЖКТ. «Лечит преэклампсию» — лишь снижает риск.

How to choose

Если аргинин: L-форма, без «технологий». Доза — по цели приёма (преэклампсия / НЭК — по назначению врача).

Food sources: Мясо, птица, рыба, орехи, семена тыквы; но биодоступность из еды спорна — проще цитруллин.

Clinical guidelines: Преэклампсия: RR 0.52 (0.35–0.78, низкая уверенность). НЭК у недоношенных: Cochrane. Спорт: 3–6 г/сут — считаться с ЖКТ.
