About this supplement

GLA (масло вечерней примулы): при атопическом дерматите у детей есть указания на пользу при низком качестве работ; при акне и псориазе неэффективна.

Who needs it: Дети с атопическим дерматитом без пищевой аллергии — есть данные об улучшении симптомов. Неэффективна при акне, псориазе, ПМС, сухих глазах и преэклампсии.

When it works: В рамках приёма, недели-месяцы; при дерматите оценка идёт по шкале SCORAD, скорость в abstracts не уточнена.

Caution

Неэффективна при акне, псориазе, хроническом ручном дерматите, гепатите B, преэклампсии и синдроме Шёгрена.

Myths

«Примула лечит кожу» — данные касаются атопического дерматита у детей. «Поможет при суставах» — при ревматоидном артрите результаты смешанные. «Доказано» — качество по Jadad низкое, обзор 2024 требует осторожности.

How to choose

Для кожи — масло Oenothera biennis; учитывать низкое качество исследований. При артрите и диабете данных для выбора недостаточно.

Food sources: Лен, конопля и соя содержат следовые количества GLA; практический источник — масло семян вечерней примулы.

Clinical guidelines: EAACI 2024: по вечерней примуле доказательств недостаточно. Обзор 2024: сильных рекомендаций по воспалительным состояниям нет из-за гетерогенности.
