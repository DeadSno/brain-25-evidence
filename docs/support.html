Поддержать проект

Brain 25 Evidence — открытый проект о биологически активных добавках. Без рекламы, без подписок, без монетизации.

📊 Что внутри проекта

  • 130 добавок — с оценкой доказательности A–D и верхним пределом дозы
  • 199 пар взаимодействий — конфликты и синергии; те же пары считает калькулятор
  • 37 618 статей из PubMed — корпус, из которого взяты данные
  • Ссылка на PMID в каждой карточке — любой источник открывается и проверяется
Проект делает один человек в свободное время. Донат помогает оплачивать хостинг и мотивирует продолжать.

💚 Что даёт ваша поддержка

  • Серверные расходы (пока 0 ₽ — GitHub Pages)
  • Домен .ru или .org (в планах)
  • Время на добавление новых карточек
  • Развитие функций: сравнение, поиск по симптому, экспорт
