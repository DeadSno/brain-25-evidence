Brain 25 Evidence — открытый проект о 130 биологически активных добавках на основе 37 618 статей из PubMed. Без рекламы, без подписок, без монетизации.

Проект делает один человек в свободное время. Донат помогает оплачивать хостинг и мотивирует продолжать.
