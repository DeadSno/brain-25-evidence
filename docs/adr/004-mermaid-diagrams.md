# ADR-004: Mermaid для диаграмм

- **Статус:** Accepted
- **Дата:** 2026-09-25

## Решение

Все UML/BPMN-диаграммы — в формате **Mermaid** (текст в Markdown).

## Альтернативы

| Инструмент | Плюсы | Минусы |
|------------|-------|--------|
| **Mermaid** | Текст в git, рендер на GitHub, редактируется в PR | Ограниченный набор нотаций |
| PlantUML | Полный UML | Нужен сервер рендера |
| draw.io | Красивые диаграммы | Бинарный формат XML |
| Visio | Индустриальный стандарт | Платный, бинарный |

## Обоснование

1. **Текстовый формат** → версионируется в git, диффится в PR.
2. **GitHub рендерит автоматически** — не нужен сервер.
3. **Редактирование в PR** — ревьюер видит changes.
4. **Экспорт в PNG/SVG** — через mermaid.live при необходимости.

## Последствия

- Диаграммы всегда актуальны (в коде)
- Ревью через git diff
- Не все нативные элементы UML
- Не рендерится в VS Code без плагина

## Соглашения

- Файлы: `docs/architecture_diagrams.md`, `docs/bpmn_pipeline.md`
- Стили: без emoji в узлах (проблемы с рендером)
- Без `classDef` в mermaid (иногда ломает preview)
