# ROADMAP_NEW.md

> Актуальный план развития. Обновлено: 2026-09-30.
> Отклонено: Telegram-канал, нативное мобильное приложение, платные фичи.

## Контекст

**Проект:** хобби. Не коммерция. Бесплатный. 
**Цель:** помочь людям выбирать БАДы. Не заработать.
**Ресурсы:** 2-5 часов в неделю, бюджет 0 руб.

## Принципы

- Каждая фича должна **помогать пользователю**, не украшать сайт
- Никаких платных API, хостингов, лицензий
- Не плодить сущности — используем что есть
- Только бесплатные решения (GitHub Pages, Streamlit Cloud, Web3Forms, CDN)

## Фаза 1 — SEO база (2-3 вечера, 8 часов)

**Цель:** чтобы Google/Яндекс находили сайт без ручных постов.

### 1.1 Sitemap.xml + robots.txt (1 ч)
- [ ] Генерировать `docs/sitemap.xml` из списка .html
- [ ] `docs/robots.txt` со ссылкой на sitemap
- [ ] Отправить в Google Search Console и Яндекс.Вебмастер

### 1.2 JSON-LD (Schema.org) (3 ч)
- [ ] Для каждой карточки — `MedicalWebPage` + `about: Drug`
- [ ] Для главной — `WebSite` + `SearchAction`
- [ ] Проверить через https://validator.schema.org

### 1.3 Отдельные страницы добавок (4 ч)
- [ ] Генерировать `docs/sup/{slug}.html` для каждой из 130
- [ ] Meta description + og-image + JSON-LD на каждой
- [ ] Обновить sitemap

**Результат:** ×130 проиндексированных страниц, rich snippets в Google.
**Проверка через 2-4 недели:** Метрика → Источники → Поисковые запросы.
