# SUBSTANCES_ROADMAP — карта расширения базы

> Обновлено: 2026-10-02. Это НЕ план, а справочник для будущего расширения.
> Текущее состояние: 130 карточек в `data.json`.
> Цель: постепенное расширение до 400+ через v6.1+.
> Принцип: глубина > широта. Итерациями по 20-30 карточек.

## Как использовать

- **Не делать всё сразу.** Итерации по тирам.
- **Не форсировать.** Каждая карточка — глубоко (грейд, дозировки, COI, источники).
- **Приоритет по ROI** — сначала популярное (что гуглят чаще).
- **Тиры — не догма.** Можно менять порядок по интересу/популярности.

## Тиры (приоритеты)

| Тир | Что | Кол-во | Время с агентом |
|-----|-----|:------:|:---------------:|
| **Тир 1** | Уже в проекте | 130 | ✅ сделано |
| **Тир 2** | B-грейд, популярные | 40-50 | 2-3 недели |
| **Тир 3** | Растительные экстракты | 100-140 | 6-8 недель |
| **Тир 4** | Пробиотики, ферменты, пептиды | 50-70 | 3-4 недели |

## Поля для новых карточек

К текущим полям `data.json` добавить:

- `evidence_grade` — A/B/C/D (уже есть)
- `pubmed_term` — точный запрос для PubMed
- `hedges_g` — размер эффекта (если есть РКИ)
- `safety_profile` — профиль безопасности
- `interactions` — взаимодействия (уже есть на `interactions.html`)
- `segment` — категория (витамины, минералы, и т.д.)
- `inchi_key` — уникальный идентификатор вещества (для маппинга)

## Источники данных

- **PubMed / MeSH** — для статей и мета-анализов
- **DrugBank** (drugbank.ca) — взаимодействия с лекарствами
- **Natural Medicines Database** — грейды (платный, использовать осторожно)
- **EFSA Health Claims Register** — официальные заявления о здоровье ЕС
- **NIH ODS** (Office of Dietary Supplements) — американский аналог
- **Examine.com** — грейдирования (использовать как reference, не копировать)
- **supp.ai** (Allen Institute) — взаимодействия добавок (открытый датасет)

## Приоритеты сбора данных (по ROI)

1. **Тир 2** — B-грейд, самое популярное (40-50)
2. **Тир 3** — растительные экстракты, адаптогены, ноотропы (~140)
3. **Тир 4** — пробиотики по штаммам, ферменты, пептиды (~70)

## Что НЕ добавлять в расширение

- **Рецептурные препараты** (рацетамы, Семакс, Кортексин, Метформин) — не БАДы
- **Фуфломицины** (Кагоцел, Арбидол — не показали эффективность)
- **Экзотика без доказательной базы** (Нони, Каму-каму) — только если есть мета-анализы
- **Продукты животного происхождения** с этическими вопросами (плацента, панты, желчь медведя)
