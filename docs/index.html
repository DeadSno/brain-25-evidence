Сначала ответим на 3 вопроса

1. Чем БАД отличается от лекарства?

БАД дополняет питание, а не заменяет лечение. У БАД нет регистрации лекарства, но есть мета-анализы — считаем именно их.

2. Зачем он мне?

Три честные причины: дефицит (витамин D зимой), цель (креатин при нагрузках), профилактика с доказательствами (омега-3).

3. Как выбирать?

Вердикт и грейд доказательности → дозировка из исследований → конфликты с лекарствами → и только потом цена.

Доказательность: индекс науки / объём исследований (пузырь = мета-анализы, ось Y — лог-шкала)

📐 Что такое «индекс науки»?

Индекс науки = РКИ + 5 × мета-анализы в PubMed по запросу «(добавка) AND (исход)».

Индекс меряет количество науки, не силу эффекта. Вердикты ставим вручную по топ-2 мета-анализам.

🎯 Что такое «сила эффекта» (Hedges' g)?

Hedges' g — это стандартная метрика того, насколько добавка реально помогает, по сравнению с плацебо.

Как читать:

  • 0 — эффекта нет (как плацебо)
  • ±0.2 — маленький эффект (заметен, но скромный)
  • ±0.5 — средний эффект (клинически значимый)
  • ±0.8+ — большой эффект (заметен всем)
  • Отрицательный — не значит «плохо». Зависит от того, что измеряли: например, у Магния g = −0.67 по шкале тревожности — это снижение тревоги, то есть хорошо

Мы берём g из первого релевантного мета-анализа по каждой добавке. У одной добавки может быть много g по разным исходам (сон, сила, память) — мы показываем один пример, а не «главный эффект».
