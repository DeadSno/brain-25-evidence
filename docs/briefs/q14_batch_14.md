# BRIEF: Q1.5 — полное заполнение 3 карточек (пилот)

## Контекст

Проект brain-25-evidence. Три добавки — B1, Холин, EPA — находятся в
`docs/_drafts.json` с пустыми полями (`_пусто_`). Нужно заполнить их
полностью на основе abstracts.

## Что дано

Для каждой из 3 добавок:
- `reports/evidence/<name>.md` — 3 abstracts из PubMed (топ-3 MA)
- `docs/_drafts.json` — текущая карточка со всеми `_пусто_`
- `docs/data.json` — образец заполненной карточки (например, "Креатин")

## Задача

Заполнить для каждой из 3 добавок:

### 1. adv-поля (7)
- `about` — 30-160 символов
- `who_needs` — 40-180
- `onset` — 30-150
- `myths` — 60-220
- `food_sources` — 25-180
- `guidelines` — 40-180
- `how_to_choose` — 35-180

### 2. Базовые поля (6)
- `verdict` — `"работает"` | `"зависит от контекста"` | `"не подтверждено"`
- `grade` — `"A"` | `"B"` | `"C"` | `"D"`
- `code` — `-1` | `0` | `1` (по verdict)
- `dosage` — дозировка из abstracts (например, "300-600 мг/сут")
- `course` — длительность приёма
- `caution` — противопоказания / предостережения
- `upper_limit` — верхний безопасный предел (или "не установлен")

### 3. Механизмы (mechs) — 2-4 штуки
Формат: `["механизм (20-250 симв)", "эффект (5-120)", "сила"]`

Сила — только из: `"сильно"`, `"умеренно"`, `"слабо"`, `"контекст"`, `"маркетинг"`

### 4. key_sources (3)
```json
[{"pmid": "...", "doi": "...", "title": "...", "year": "..."}, ...]
```

## Правила

- **Только из abstracts.** Если данных нет — писать честно: «данных нет», «не изучалось».
- **Не выдумывать.** Каждый факт — из `reports/evidence/<name>.md`.
- **Стиль** — как в Креатине: короткие ёмкие фразы.
- **Длины** — обязательно в диапазонах (иначе apply-скрипт отклонит).
