## Правила (полные)

### Не выдумывать
- Только из abstracts
- Если данных нет → `"данных нет"` / `"не изучалось"`
- **Не использовать MA на животных** как доказательство людям
- **Не смешивать вещества** (α-аланин ≠ β-alanine, метионин у коров ≠ у людей)

### Формат полей

**adv (7):** `about` 30-160, `who_needs` 40-180, `onset` 30-150, `myths` 60-220, `food_sources` 25-180, `guidelines` 40-180, `how_to_choose` 35-180.

**База (7):** `verdict`, `grade`, `code`, `dosage`, `course`, `caution`, `upper_limit`.

**effects (1-3):** 5-40 симв.
**mechs (2-4):** `[механизм 20-250, эффект 5-120, сила]`.

**key_sources (1-3 для D, 2-3 для C):**
```json

```

**interactions:** если нет реальных → `[{"with": "нет данных", "severity": "low", "note": "известных взаимодействий нет"}]`
