# BRIEF: Q1.4 — adv-поля 61 карточки (батч)

## Контекст

Проект brain-25-evidence: 81 карточка БАД в `docs/data.json`.
У 20 карточек заполнены 7 adv-полей, у 61 — пусто.

**Задача:** заполнить 7 adv-полей для 5 карточек батча.

## Эталон стиля — карточка «Креатин» (уже в data.json)

**about:** «Самая изученная спортивная добавка: помогает мышцам пересобирать АТФ — валюту коротких мощных усилий.»
**who_needs:** «Силовые и спринт-спортсмены; вегетарианцы и веганы (в мышцах без мяса креатина меньше); пожилые — против потери мышечной массы.»
**onset:** «2-4 недели регулярного приёма (с загрузкой 5-7 дней); мгновенного «прилива» не даёт.»
**myths:** «Бьёт по почкам у здоровых» — на стандартных дозах не подтверждено. «Без загрузки не работает» — работает, просто медленнее.»
**food_sources:** «Красное мясо и рыба: порядка 4-5 г на килограмм сырого продукта — наесть дозу сложно.»
**guidelines:** «Позиция ISSN: эффективен и безопасен; EFSA health claims для спорта не требует.»
**how_to_choose:** «Моногидрат (знак Creapure); без «транспортных систем» и переплаты за экзотические формы.»

## Правила

1. **Только из abstracts.** Источники: `reports/evidence/<id>.md` + `docs/data.json` (поля `mechs`, `effects`, `verdict`, `grade`, `dosage`, `course`, `caution`).
2. **Не выдумывать.** Если данных нет — писать честно: «данных нет», «не изучалось».
3. **Стиль эталона:** короткие ёмкие фразы, без воды, без «может помочь», без маркетинговых заявлений.
4. **Длины (из 20 существующих):**
   - about: 51-101 симв
   - who_needs: 57-127
   - onset: 40-89
   - myths: 85-145
   - food_sources: 35-106
   - guidelines: 58-121
   - how_to_choose: 49-109
5. **Формат myths:** «миф» — реальность. Как в Креатине.

## Что записать

Один файл: `reports/q14_batch_N_proposal.json` (N — номер батча).

Формат:
{
  "ID_карточки_1": {
    "about": "...",
    "who_needs": "...",
    "onset": "...",
    "myths": "...",
    "food_sources": "...",
    "guidelines": "...",
    "how_to_choose": "..."
  },
  ...
}

Ключи = `c["id"]` из data.json. Все 7 полей обязательны.

**Ничего не писать в `docs/data.json`.**
