# BRIEF v2.6.1 — ЭКОНОМИКА-СЛУГА + КНОПКА «ПРОВЕРИТЬ ИСТОЧНИК» (patch)

## СОХРАНИТЬ КАК docs/briefs/v2.6.1-economics.md

## КОНТЕКСТ
Миссия: польза выше денег. Цена — слуга доказательства, не хозяйка и не изгой.
Value Score (индекс/цена) математически обесценивал доказательность —
демонтируем его из витрины, оставляем честную экономику: «₽ за единицу
эффекта» там, где эффект верифицирован.

## ЗАДАЧИ

### 1. ДЕМОНТАЖ VALUE SCORE
1.1 Убрать из карточки, модалки и таблицы сравнения всё, что рендерит
    «Ценность / Value Score»; в сравнении колонку заменить на
    «₽ за единицу эффекта» (см. п.2)
1.2 Сортировки: опцию «по ценности» удалить; остаются: по доказательности
    (scienceIndex), по цене, по алфавиту, по грейду
1.3 Гард-тест: в docs/script.js и docs/index.html отсутствуют строки
    «Ценность», «Value Score», «valueScore» в рендере (комментарии допустимы)

### 2. БЛОК «ЭКОНОМИКА» В МОДАЛКЕ
2.1 Поле price_per_effect = round(price / hedges_g) при обоих ненулевых;
    подпись: «₽ за единицу эффекта (цена / Hedges' g)»
2.2 При g=null: «Эффект ждёт верификации — ₽ за единицу эффекта не считаем»
    (не ноль, не прочерк-обманка, а причина)
2.3 Честность цены: тултип у цены: «Цена на {price_date}; ночной сбор
    временно заблокирован TLS-фильтром маркетплейса, трек reliability
    в работе» (price_date = последняя строка price_history по id,
    иначе «дата неизвестна»)
2.4 Тест: Кофеин (price 266, g 0.21) → 1267 ±1; у добавки без g — текст причины

### 3. КНОПКА «🔍 ПРОВЕРИТЬ ИСТОЧНИК»
3.1 scripts/build_key_sources.py: для каждой добавки esearch top-3 MA
    (запрос из config, как в scienceIndex) → esummary → ma_top3:
    [{pmid, title, year}]; сон 0.4 c между запросами; один прогон, коммит
3.2 Модалка: блок «📚 Ключевые мета-анализы (топ-3 поиска)»:
    ссылки pubmed.ncbi.nlm.nih.gov/<pmid> с title+year
    + пометка ДО и ПОСЛЕ списка: «Автоматический топ-3 запроса PubMed.
    Ручная верификация эффекта — в грейде и key_sources; верифицированных
    добавок сейчас: N» (N считать по непустым key_sources)
3.3 Тесты: ma_top3-схема (pmid — цифры, year 1990-2026, title непустой);
    e2e: у Кофеина блок рендерит ≥1 ссылку и пометку
