## Задача

Для каждой из 30 карточек — проверить 7 adv-полей против:
- `reports/evidence/<id>.md` (abstracts)
- `key_sources` в `docs/data.json` (PMIDs)

## Что проверять (по каждому полю)

1. **Факт подтверждается?** — есть в abstract или это выдумка?
2. **Актуален?** — PMIDs свежие (≤5 лет) или есть более новые МА?
3. **Стиль научный?** — без «может помочь», без маркетинга
4. **Согласован?** — не противоречит verdict/grade/mechs
5. **Длина в норме?** — about 51-101, who_needs 57-127, onset 40-89,
   myths 85-145, food_sources 35-106, guidelines 58-121, how_to_choose 49-109
