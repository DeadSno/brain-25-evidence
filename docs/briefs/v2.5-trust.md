## ТЕКСТЫ FAQ (дословно, аккордеон)

### 1. Что такое мета-анализ?
Мета-анализ — когда учёные собрали 10-50 отдельных исследований и посчитали
средний эффект. Это надёжнее одного исследования: случайные ошибки гасятся,
систематические — видны. Мы считаем вердикты по мета-анализам, не по отдельным РКИ.

### 2. Что такое Hedges' g?
Размер эффекта в стандартных отклонениях: насколько экспериментальная группа
отличается от контрольной. g=0.2 = малый эффект, 0.5 = средний, 0.8+ = большой.
g<0 = работает наоборот (вред или обратный эффект). Мы берём g из абстрактов
мета-анализов, сверяем с приором, записываем только верифицированные.

### 3. Что такое грейд A-D?
A = крепко доказано (g≥0.4, объём≥100)
B = доказано умеренно (g 0.2-0.4, объём≥50)
C = изучено много, эффект мал (объём≥100, g<0.2)
D = данных мало (объём<50)
Грейд пересчитывается автоматически из g и scienceIndex.

### 4. Почему некоторые добавки "работает" при scienceIndex < 100?
Вердикт ставится вручную по методологии: качество исследований, согласованность
результатов, биологическая правдоподобность. scienceIndex = объём науки,
не качество. Имбирь работает при индексе <100, потому что МА согласованы
и механизм понятен.

### 5. Как читать квадрант доказательности?
X = Hedges' g (сила эффекта), Y = scienceIndex (объём науки, лог-шкала).
Размер пузыря = metaCount (число МА), цвет = вердикт.
Большой пузырь высоко справа = много науки + сильный эффект (креатин).
Большой пузырь высоко слева = много науки + слабый эффект (глюкозамин).
Добавки без g помечены «ждут верификации» — у нас нет данных, не выдумка.

### 6. Что делать если цена не найдена?
Нажми «предложить» — откроется GitHub issue с названием добавки. Мы добавим
цену вручную. Честный null лучше выдуманной цифры.

### 7. Можно ли принимать всё сразу?
Смотри вкладку «Взаимодействия» в карточке. Критичные пары (зверобой+SSRI,
5-HTP+трамадол) — опасно для жизни. Антагонисты (кальций+железо) — разнести
на 2-4 часа. Синергисты (магний+B6) — принимать вместе можно.

### 8. Когда ждать эффект?
Смотри блок «Когда почувствую» в карточке. Креатин = 2-4 недели, мелатонин =
30-60 минут, омега-3 = 8-12 недель. Если эффект не указан = данных нет или
эффект не ощущается субъективно (контролировать анализом).

## ГЛОССАРИЙ (таблица)

| Термин | Определение |
|---|---|
| Мета-анализ | Статистическое объединение 10-50 исследований для среднего эффекта |
| РКИ | Рандомизированное контролируемое исследование: золотой стандарт доказательств |
| Hedges' g | Размер эффекта в стандартных отклонениях (0.2=малый, 0.5=средний, 0.8+=большой) |
| CI (доверительный интервал) | Диапазон, в котором с 95% вероятностью лежит истинный эффект |
| Science Index | Сумма РКИ + 5×мета-анализы: объём науки по добавке |
| Грейд | A-D: крепко доказано / умеренно / много науки мало эффекта / данных мало |
| Вердикт | Работает / зависит от контекста / не подтверждено / данных недостаточно |
| Биодоступность | Процент вещества, доходящий до крови (зависит от формы) |
| Синергист | Добавка, усиливающая эффект другой (магний+B6) |
| Антагонист | Добавка, конкурирующая за всасывание (кальций+железо) |
| UL (upper limit) | Верхний безопасный предел суточной дозы |
| Onset | Время до начала эффекта (30 мин / 2-4 недели / не ощущается) |

## ЖУРНАЛ ПРАВОК (таблица из CHANGELOG.md)

```python
# scripts/build_changelog_public.py
import re
from pathlib import Path

CHANGELOG = Path(__file__).resolve().parents[1] / "CHANGELOG.md"
OUT = Path(__file__).resolve().parents[1] / "docs" / "changelog_public.html"

entries = []
current_version = None
current_date = None
current_changes = []

for line in CHANGELOG.read_text(encoding="utf-8").splitlines():
    if line.startswith("## ["):
        if current_version:
            entries.append((current_version, current_date, current_changes))
        m = re.match(r"## \[(.*?)\] — (.*)", line)
        if m:
            current_version, current_date = m.groups()
            current_changes = []
    elif line.startswith("- "):
        current_changes.append(line[2:])

if current_version:
    entries.append((current_version, current_date, current_changes))

html = """<!DOCTYPE html>
<html lang="ru">
<head>
<meta charset="utf-8">
<title>Журнал правок</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<h1>Журнал правок</h1>
<table class="changelog">
<thead><tr><th>Дата</th><th>Версия</th><th>Что изменилось</th></tr></thead>
<tbody>
"""

for version, date, changes in reversed(entries):
    html += f"<tr><td>{date}</td><td>{version}</td><td><ul>"
    for change in changes:
        html += f"<li>{change}</li>"
    html += "</ul></td></tr>\n"

html += """</tbody>
</table>
</body>
</html>
"""

OUT.write_text(html, encoding="utf-8")
print(f"changelog_public.html: {len(entries)} versions")
```

## КОНТЕНТ-ПАК №2 (дословно, 10 добавок)

### Ашваганда
about: Адаптоген: снижает кортизол, тревогу, улучшает сон.
who_needs: Хронический стресс, тревожность, бессонница, спортсмены (восстановление).
onset: Тревога и сон — 4-8 недель; кортизол — 2-4 недели.
upper_limit: 600-1200 мг экстракта/сут; выше — дискомфорт ЖКТ.
food_sources: Не употребляется в пищу (корень в добавках).
guidelines: EFSA: claims не одобрены; ряд МА — умеренный эффект на тревогу и сон.
how_to_choose: Стандартизация 5% withanolides (KSM-66, Sensoril); корень, не листья.
myths: «Работает сразу как транквилизатор» — эффект накопительный. «Любой экстракт одинаков» — withanolides решают.

### Родиола розовая
about: Адаптоген: снижает усталость, улучшает концентрацию при стрессе.
who_needs: Выгорание, умственная усталость, сменный график, студенты в сессию.
onset: Усталость — 1-2 недели; концентрация — 30-60 минут (острый эффект).
upper_limit: 600 мг экстракта/сут; выше — раздражительность.
food_sources: Не употребляется в пищу (корень в добавках).
guidelines: EFSA: claims не одобрены; МА — умеренный эффект на усталость.
how_to_choose: Стандартизация 3% розавинов + 1% салидрозида; SHR-5 (шведский экстракт).
myths: «Заменит кофе» — механизм другой, не стимулятор. «Работает всем» — эффект зависит от baseline усталости.

### Бакопа
about: Ноотроп: улучшает память и обучение (адаптоген для мозга).
who_needs: Возрастное снижение памяти, студенты, СДВГ (умеренные данные).
onset: Память — 8-12 недель (накопительный эффект).
upper_limit: 300-450 мг экстракта/сут; выше — дискомфорт ЖКТ, усталость.
food_sources: Не употребляется в пищу (трава в добавках).
guidelines: EFSA: claims не одобрены; МА — умеренный эффект на память.
how_to_choose: Стандартизация 50% бакозидов; с едой (жирорастворимые).
myths: «Работает как пирацетам» — механизм другой, медленнее. «Мгновенный эффект» — 8-12 недель минимум.

### Гинкго билоба
about: Улучшает микроциркуляцию, когнитивные функции (умеренные данные).
who_needs: Возрастное снижение памяти, деменция (адъювант), шум в ушах.
onset: Когнитивные функции — 12-24 недели; шум в ушах — 4-8 недель.
upper_limit: 240 мг экстракта/сут; выше — кровотечения.
food_sources: Не употребляется в пищу (листья в добавках).
guidelines: EFSA: claims не одобрены; Cochrane — скромный эффект при деменции.
how_to_choose: Стандартизация 24% флавоноидов + 6% терпенов (EGb-761).
myths: «Улучшает память всем» — эффект при возрастном снижении, не у здоровых. «Безопасен с аспирином» — риск кровотечений.

### Коллаген
about: Структурный белок: кожа, суставы, кости. Пептиды всасываются.
who_needs: Остеоартрит, морщины (25+), спортсмены (суставы), постменопауза (кости).
onset: Кожа — 8-12 недель; суставы — 12-24 недели.
upper_limit: 15 г/сут безопасно; выше — дискомфорт ЖКТ.
food_sources: Костный бульон, кожа животных, желатин; добавки = гидролизат (пептиды).
guidelines: EFSA: claims не одобрены; ряд МА — умеренный эффект на кожу и суставы.
how_to_choose: Гидролизат (пептиды), не желатин; типы I+III (кожа), II (суставы); с витамином C.
myths: «Желатин равноценен» — пептиды всасываются лучше. «Работает сразу» — 8-12 недель минимум.

### Псиллиум
about: Растворимая клетчатка: холестерин, сахар, регулярность стула.
who_needs: Повышенный холестерин, запоры, преддиабет, контроль веса.
onset: Холестерин — 4-8 недель; стул — 1-3 дня.
upper_limit: 30 г/сут; выше — вздутие; пить много воды.
food_sources: Семена подорожника блошиного; добавки = шелуха (98% клетчатки).
guidelines: EFSA: 10 г/сут снижает холестерин; FDA: health claim для сердца.
how_to_choose: Шелуха (husk), не цельные семена; порошок или капсулы.
myths: «Заменит овощи» — клетчатка есть, но нет витаминов. «Работает без воды» — без воды запор.

### Берберин
about: Алкалоид: снижает сахар, улучшает чувствительность к инсулину.
who_needs: Преддиабет, метаболический синдром, СПКЯ (умеренные данные).
onset: Сахар — 4-8 недель; инсулин — 8-12 недель.
upper_limit: 1500 мг/сут; выше — дискомфорт ЖКТ.
food_sources: Барбарис, куркума (следовые количества); добавки = экстракт.
guidelines: EFSA: claims не одобрены; ряд МА — эффект сопоставим с метформином.
how_to_choose: Berberine HCl или phytosome; 500 мг 3 раза/сут с едой.
myths: «Заменит метформин» — эффект схож, но данных меньше. «Безопасен со статинами» — взаимодействие.

### Имбирь
about: Противовоспалительное, противорвотное, умеренный эффект на боль.
who_needs: Остеоартрит, тошнота (беременность, химиотерапия), мышечная боль.
onset: Тошнота — 30-60 минут; боль — 4-8 недель.
upper_limit: 4 г/сут; выше — дискомфорт ЖКТ, кровотечения.
food_sources: Корень имбиря (свежий, сушёный); добавки = экстракт.
guidelines: EFSA: claims не одобрены; МА — умеренный эффект на боль при остеоартрите.
how_to_choose: Стандартизация 5% гингеролов; капсулы или свежий корень.
myths: «Лечит простуду» — облегчает симптомы, не лечит. «Безопасен с антикоагулянтами» — риск кровотечений.

### Эхинацея
about: Иммуномодулятор: умеренный эффект на длительность простуды.
who_needs: Частые простуды (профилактика), начало простуды (сокращение).
onset: Профилактика — 4-8 недель; лечение — 1-2 дня сокращения.
upper_limit: 900 мг экстракта/сут; выше — дискомфорт ЖКТ.
food_sources: Не употребляется в пищу (корень/трава в добавках).
guidelines: EFSA: claims не одобрены; Cochrane — modest effect на длительность.
how_to_choose: E. purpurea (не angustifolia); спиртовой экстракт или сок.
myths: «Предотвращает простуду» — слегка сокращает длительность. «Работает всем» — эффект скромный.

### Чеснок
about: Серосодержащие соединения: умеренный эффект на АД и холестерин.
who_needs: Повышенное АД (адъювант), повышенный холестерин, профилактика.
onset: АД — 8-12 недель; холестерин — 12-24 недели.
upper_limit: 1200 мг экстракта/сут; выше — дискомфорт ЖКТ, запах.
food_sources: Свежий чеснок (2-4 зубчика/сут); добавки = экстракт аллицина.
guidelines: EFSA: claims не одобрены; МА — modest effect на АД и холестерин.
how_to_choose: Стандартизация 1.3% аллицина; aged garlic extract (AGE) лучше переносится.
myths: «Заменит статины» — эффект скромный. «Свежий чеснок равноценен» — добавки стабильнее.
