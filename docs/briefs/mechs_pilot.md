# BRIEF: Расширение mechs — пилот на Креатине

## Контекст

Проект brain-25-evidence: сайт про БАДы, 81 карточка в `docs/data.json`.
Каждая карточка содержит поле `mechs` — список механизмов действия.

**Сейчас у всех 81 карточки ровно 1 механизм.** Формат элемента:
["детальный механизм", "краткий эффект", "сила"]

Пример (Креатин):

["Фосфокреатиновый буфер: ресинтез АТФ в нейронах и мышцах", "Рабочая память под нагрузкой, сила", "сильно"]


**Цель:** расширить до 2-4 механизмов на карточку, не выдумывая — только из abstracts МА.

## Задача (пилот)

Расширить **только карточку «Креатин»** — с 1 до 3-4 механизмов.

### Источники данных (читать оба)

1. `reports/evidence/Креатин.md` — abstracts 3 PMIDs (PubMed)
2. Текущая карточка Креатина в `docs/data.json` — поля `mechs`, `effects`, `about`, `key_sources`

### Правила

- **Не выдумывать.** Каждый новый механизм должен подтверждаться абстрактом из evidence-файла или очевидной физиологией, упомянутой там.
- **Формат элемента:** `["механизм (20-250 симв)", "эффект (5-120 симв)", "сила"]`
- **Сила — только из:** `"сильно"`, `"умеренно"`, `"слабо"`, `"контекст"`, `"маркетинг"`
- **Механизм** — молекулярный/физиологический уровень (что происходит в клетке/органе)
- **Эффект** — что чувствует/получает человек (кратко, через запятую)
- **Стиль** — как в существующем mech Креатина: короткие ёмкие формулировки, без воды
- **Первый механизм оставить как есть** (уже утверждён), новые добавлять после него
- **2-4 механизма всего.** Не больше 4.

### Что известно про механизмы Креатина (подсказка, но проверь по abstracts)

- Фосфокреатиновый буфер (ресинтез АТФ) ← уже есть

- Митохондриальная поддержка (эффективность дыхательной цепи)
