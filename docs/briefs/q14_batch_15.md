## Задача

Заполнить для каждой из 6 добавок:

### 1. adv-поля (7)
- `about` — 30-160 симв
- `who_needs` — 40-180
- `onset` — 30-150
- `myths` — 60-220
- `food_sources` — 25-180
- `guidelines` — 40-180
- `how_to_choose` — 35-180

### 2. Базовые поля (7)
- `verdict` — `"работает"` | `"зависит от контекста"` | `"не подтверждено"`
- `grade` — `"A"` | `"B"` | `"C"` | `"D"`
- `code` — `-1` | `0` | `1`
- `dosage`, `course`, `caution`, `upper_limit`

### 3. effects — 1-3 коротких названия (5-40 симв)
Пример: `["Нейропатия", "Алкогольная нейропатия"]`

### 4. mechs — 2-4 штуки
Формат: `["механизм (20-250)", "эффект (5-120)", "сила"]`
Сила: `"сильно"`, `"умеренно"`, `"слабо"`, `"контекст"`, `"маркетинг"`

### 5. key_sources — 2-3 штуки с ОБЯЗАТЕЛЬНЫМИ полями
```json
[{
  "pmid": "12345678",
  "doi": "10.xxxx/yyyy",
  "title": "...",
  "year": 2024,              ← int, не строка
  "journal": "..."           ← обязательно!
}]
```

### 6. interactions — если нет реальных:
```json
[{"with": "нет данных", "severity": "low", "note": "известных взаимодействий нет"}]
```
