## Задача

## Список 20 карточек

## Что проверять

Для каждого из 7 полей карточки:

1. **Подтверждается ли факт** abstracts? Если нет — «не подтверждено».
2. **Не устарел ли факт?** PMIDs в key_sources свежие (≤5 лет)?
3. **Не маркетинговая ли** формулировка? Стиль эталона — научный, сдержанный.
4. **Не противоречит ли** другим полям (`verdict`, `grade`, `mechs`, `effects`)?
