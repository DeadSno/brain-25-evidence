Проект **brain-25-evidence** — открытая база данных о БАДах на основе PubMed.

## ⚠️ ГЛАВНЫЙ ПРИНЦИП: НЕ ВЫДУМЫВАТЬ

**Это критично.** Проект существует, потому что пользователи доверяют данным.
Ошибка = доверие потеряно.

### Жёсткие правила

1. **Только из abstracts.** Каждый факт (доза, эффект, механизм) должен быть подтверждён текстом из `reports/evidence/<id>.md`.
2. **Если данных нет — писать честно.** Не «может помочь», не «предположительно» — а:
   - `"данных нет"` / `"не изучалось"`
   - `verdict: "не подтверждено"`, `grade: "D"`
3. **Не смешивать вещества.** Например, α-аланин ≠ β-аланин. Если MA про другое вещество — не используй.
4. **Не использовать MA на животных** как доказательство для людей. Помечать: `"только preclinical"`.
5. **Не выдумывать дозы.** Если в abstract нет дозы — в `dosage` писать `"в абстрактах доза не указана"`.
6. **Не выдумывать механизмы.** Если механизм не упомянут — не добавлять «общеизвестную физиологию».

## ⚠️ Особые случаи

### Карнозин
Abstracts найдены про **β-alanine**, а не про карнозин напрямую. Это связано (β-alanine — предшественник карнозина), но **это разные вещества**.

**Что делать:**
- В `about` честно написать: «Карнозин — дипептид из β-аланина и гистидина. Прямых MA по добавке мало, но β-alanine изучен как предшественник.»
- В `verdict` — на твоё усмотрение: либо `C` (зависит от контекста), либо `D` (не подтверждено)
- НЕ писать «карнозин работает» на основе β-alanine MA

### Кремний
Только **1 релевантный MA** (Silicon Supplementation for Bone Health). Остальные — не про БАД.

**Что делать:**
- `verdict: "зависит от контекста"` или `D`
- `grade: "C"`
- В `myths` честно: «Данных мало — только 1 umbrella review»

### Цистеин
Прямых MA про цистеин почти нет. Есть **NAC** (N-ацетилцистеин — производное). Они связаны, но **разные молекулы**.

**Что делать:**
- `about` — честно: «Аминокислота, предшественник глутатиона. Прямых MA по свободному цистеину мало.»
- Использовать abstract про COPD mucolytics (релевантно)

## Задача — заполнить для каждой карточки

### 1. adv-поля (7)

| Поле | Длина | Что писать |
|------|-------|-----------|
| `about` | 30-160 симв | 1 предложение — суть |
| `who_needs` | 40-180 | кому показан |
| `onset` | 30-150 | когда эффект |
| `myths` | 60-220 | «миф» — реальность |
| `food_sources` | 25-180 | где в еде |
| `guidelines` | 40-180 | EFSA/WHO/RDA |
| `how_to_choose` | 35-180 | какую форму покупать |

**Обязательно в диапазонах** — иначе apply-скрипт отклонит.

### 2. Базовые поля (7)

- `verdict` — `"работает"` / `"зависит от контекста"` / `"не подтверждено"`
- `grade` — `"A"` / `"B"` / `"C"` / `"D"`
- `code` — `-1` / `0` / `1`
- `dosage` — доза из abstracts или `"в абстрактах не указана"`
- `course` — длительность приёма
- `caution` — предостережения
- `upper_limit` — верхний безопасный предел

**Правило grade:**
- `A` — эффект стабильный у здоровых, MA показывают значимость
- `B` — эффект есть, но с оговорками
- `C` — зависит от контекста (дефицит, популяция)
- `D` — нет MA на людях или MA отрицательные

### 3. effects — 1-3 коротких названия (5-40 симв)

Примеры:
- `["Hashimoto", "Щитовидка"]`
- `["Кожа", "Акне"]`
- `["Мышцы", "Восстановление"]`

### 4. mechs — 2-4 штуки

Формат: `["механизм (20-250)", "эффект (5-120)", "сила"]`

Сила — только из списка: `"сильно"`, `"умеренно"`, `"слабо"`, `"контекст"`, `"маркетинг"`

**Пример:**
```json
[
  ["Участие в синтезе селенопротеинов и глутатионпероксидазы", "Антиоксидантная защита", "умеренно"],
  ["Регуляция T-клеточного иммунитета", "Иммунный ответ", "контекст"]
]
```

### 5. key_sources — 2-3 штуки

**Строгие требования:**

```json
[{
  "pmid": "38243784",
  "doi": "10.1089/thy.2023.0476",
  "title": "Selenium Supplementation in Patients with Hashimoto Thyroiditis...",
  "year": 2024,
  "journal": "Thyroid"
}]
```

⚠️ **Критично:**
- `year` — **int** (2024, не "2024")
- `journal` — обязательно (если нет в abstract — используй esummary из PubMed)
- `doi` — если нет, оставить пустой строкой (но постарайся найти)

### 6. interactions — если нет реальных

```json
[{"with": "нет данных", "severity": "low", "note": "известных взаимодействий нет"}]
```

⚠️ **Обязательно поле `with`** — иначе тесты упадут.
