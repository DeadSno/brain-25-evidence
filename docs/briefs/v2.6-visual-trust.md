### БЛОК B. 5-точечный бейдж доверия (главная визуальная фича)
B1. В карточке и модалке: 5-точечный индикатор на основе ГРЕЙДА (не смешивать
    силу и контекст):
    ⬤⬤⬤⬤◯  A — крепко доказано (g≥0.4, объём≥100) — #2ecc71
    ⬤⬤⬤◯◯  B — доказано умеренно — #7dcea0
    ⬤⬤◯◯◯  C — много науки, эффект мал — #f4d03f
    ⬤◯◯◯◯  D — данных мало — #eb984e
    ◯◯◯◯◯  нет grade — #bdc3c7 + подпись «ждёт верификации»
B2. Рядом с точками — текст вердикта (как было) + тултип:
    «Грейд считает силу эффекта (Hedges' g) и объём науки (scienceIndex).
     Вердикт — ручная оценка по методологии.»
B3. Тест: у Кофеина (грейд B, g=0.21) рендерится 3 точки; у добавок без g —
    0 точек + текст «ждёт верификации».

### БЛОК C. тумблер оси X графика
C1. Переключатель над графиком: [Цена ₽/мес] [Число МА] [Число РКИ] [Год
    последнего МА]. По умолчанию = Число МА (не Цена — цена стала слугой).
C2. Поле «Год последнего МА» — добавить в data.json через scripts/build_edu.py
    (извлечь из metaCount-источников или записать null, если нет данных).
C3. График перерисовывается без перезагрузки страницы.
C4. Тест: все 4 оси работают, bubbles не пропадают при переключении.

### БЛОК D. бейджи актуальности
D1. Под названием в карточке: «Обновлено: 2026-09-XX» (дата последнего
    коммита в data.json через snapshot).
D2. Для карточек с вердиктом = бейдж «✋ ручная вычитка» + тултип
    «Вердикт выставлен вручную по топ-2 МА методологией проекта».
D3. Тест: обе метки в DOM, тултип показывается на hover.

### БЛОК E. поделиться + сравнение
E1. Кнопка «📤 Поделиться» в модалке: TG/VK/копировать ссылку.

    открытые данные · {url}».
E2. В модалке блок «🔀 Сравнить с:» с автоподстановкой 3 добавок
    той же категории (не случайных). Клик → переход в сравнение.
