## 1. Введение

### 1.1 Цель

Настоящий документ определяет **функциональные и нефункциональные требования** к открытой базе знаний о БАД. Система служит справочным инструментом для:

- Конечных пользователей (потребителей БАД)
- Внешних разработчиков (потребителей REST API)
- LLM-агентов (RAG-источник)
- Владельца (Maintainer)

### 1.2 Область применения

**Входит в скоуп:**
- Публичная статическая витрина (GitHub Pages)
- REST API v1 (публичный, без аутентификации)
- Batch-пайплайн обновления данных (Python)
- Аналитическая БД (DuckDB)
- BI-дашборд (Streamlit)

**Не входит:**
- Аутентификация пользователей
- Хранение PII
- Интерактивная запись через UI
- Мобильные приложения
- Оплата / подписки

### 1.3 Термины и сокращения

| Термин | Значение |
|--------|----------|
| БАД | Биологически активная добавка |
| COI | Conflict of Interest |
| MA | Мета-анализ |
| РКИ | Рандомизированное клиническое исследование |
| SI | Science Index |
| PMID | PubMed ID |
| PMCID | PubMed Central ID |
| ETL | Extract-Transform-Load |

### 1.4 Источники данных

| Источник | Назначение | Формат |
|----------|-----------|--------|
| PubMed | Метаданные статей, RCT, MA | XML (API) |
| Europe PMC | Full texts (JATS XML) | XML (REST) |
| NCBI efetch | Fallback для full texts | XML (REST) |
| OpenAlex | Цитирования | JSON (API) |
| Wikipedia | Популярные названия | JSON (API) |

## 2. Общее описание

### 2.1 Перспектива продукта

**Brain 25 Evidence** — самостоятельное решение, не интегрированное с другими системами. Публикуется через GitHub Pages (статика) и Streamlit Cloud (BI).

### 2.2 Функции верхнего уровня

| # | Функция | Приоритет |
|---|---------|-----------|
| F1 | Просмотр карточек 130 добавок | Must |
| F2 | Поиск и фильтрация | Must |
| F3 | REST API для внешних потребителей | Must |
| F4 | Визуализация связей (граф) | Should |
| F5 | Сравнение добавок (радар) | Should |
| F6 | Калькулятор доз | Could |
| F7 | Аналитический отчёт COI | Should |
| F8 | BI-дашборд (Streamlit) | Should |

### 2.3 Классы пользователей

| Класс | Описание | Задачи |
|-------|----------|--------|
| Конечный пользователь | Потребитель БАД | Найти, изучить, сравнить |
| Внешний разработчик | Интегратор API | Забрать датасет |
| LLM-агент | RAG-система | Читать метаданные |
| Maintainer | Владелец | Добавлять добавки |
| Аналитик | Исследователь | SQL-запросы |

### 2.4 Ограничения

- Хостинг: GitHub Pages (статика)
- Размер репо: лимит 1 GB
- Full texts: 11 940 XML (~1 GB)
- Лицензия: CC BY 4.0
- Бюджет: 0 руб/мес

### 2.5 Допущения

- API PubMed/EuropePMC доступны
- GitHub Pages работает (SLA 99.9%)
- Пользователи имеют современный браузер
- Данные научно-обоснованы
