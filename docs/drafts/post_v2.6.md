# Доверие — это не красивая картинка, это видимые детали

В v2.6 мы прошлись по каждой детали карточек и сделали так, чтобы
доверие было видно глазами, а не только словами.

Что нового в v2.6:
• 5-точечный бейдж грейда: A = 4 точки, B = 3, C = 2, D = 1. У добавок
без проверенного эффекта — 0 точек и честная подпись «ждёт верификации»
(пока так у всех, кроме Кофеина с грейдом B). Тултип поясняет, откуда
грейд: сила эффекта (Hedges' g) и объём науки
• тумблер оси графика: Цена ₽/мес, Число МА, Число РКИ (считаем по
формуле scienceIndex − 5×МА), Год последнего МА. Переключение мгновенное,
без перезагрузки. Дефолт — Число МА, самый информативный для 81 карточки
• «Обновлено: дата» на каждой карточке — дата последнего коммита данных,
и бейдж «✋ ручная вычитка»: вердикт выставляется человеком по топ-2
мета-анализам, а не автоматом
• «📤 Поделиться» в карточке: Telegram, VK и копия ссылки с текстом
поста «{добавка}: индекс {n}, {m} МА · открытые данные»; «🔀 Сравнить с:» —
три ближайших конкурента по доказательности из той же категории
• иконки источников: [PubMed ↗] у индекса науки, [Wiki ↗] у страницы
википедии, [WB/Ozon ↗] у цены. Цену пока не показываем ни у кого —
бота цен блокирует сеть, поэтому price_source пуст — честный null,
а не выдуманный источник
• «🔬 Топ-3 по доказательности» вместо «Лучший выбор»: топ считается
по индексу науки, а не по цене за единицу эффекта

Доверие = проверяемость: 72 теста, снапшот данных, e2e на живой вёрстке.
