❓ Часто задаваемые вопросы

1. Что такое мета-анализ?

Мета-анализ — когда учёные собрали 10-50 отдельных исследований и посчитали средний эффект. Это надёжнее одного исследования: случайные ошибки гасятся, систематические — видны. Мы считаем вердикты по мета-анализам, не по отдельным РКИ.

2. Что такое Hedges' g?

Размер эффекта в стандартных отклонениях: насколько экспериментальная группа отличается от контрольной. g=0.2 = малый эффект, 0.5 = средний, 0.8+ = большой. g<0 = работает наоборот (вред или обратный эффект). Мы берём g из абстрактов мета-анализов, сверяем с приором, записываем только верифицированные.

3. Что такое грейд A-D?

A = крепко доказано (g≥0.4, объём≥100)
B = доказано умеренно (g 0.2-0.4, объём≥50)
C = изучено много, эффект мал (объём≥100, g<0.2)
D = данных мало (объём<50)
Грейд пересчитывается автоматически из g и scienceIndex.

4. Почему некоторые добавки "работает" при scienceIndex < 100?

Вердикт ставится вручную по методологии: качество исследований, согласованность результатов, биологическая правдоподобность. scienceIndex = объём науки, не качество. Имбирь работает при индексе <100, потому что МА согласованы и механизм понятен.

5. Как читать квадрант доказательности?

X = Hedges' g (сила эффекта), Y = scienceIndex (объём науки, лог-шкала). Размер пузыря = metaCount (число МА), цвет = вердикт.
Большой пузырь высоко справа = много науки + сильный эффект (креатин).
Большой пузырь высоко слева = много науки + слабый эффект (глюкозамин).
Добавки без g помечены «ждут верификации» — у нас нет данных, не выдумка.

6. Что делать если цена не найдена?

Нажми «предложить» — откроется GitHub issue с названием добавки. Мы добавим цену вручную. Честный null лучше выдуманной цифры.

7. Можно ли принимать всё сразу?

Смотри вкладку «Взаимодействия» в карточке. Критичные пары (зверобой+SSRI, 5-HTP+трамадол) — опасно для жизни. Антагонисты (кальций+железо) — разнести на 2-4 часа. Синергисты (магний+B6) — принимать вместе можно.

8. Когда ждать эффект?

Смотри блок «Когда почувствую» в карточке. Креатин = 2-4 недели, мелатонин = 30-60 минут, омега-3 = 8-12 недель. Если эффект не указан = данных нет или эффект не ощущается субъективно (контролировать анализом).

Аудит v: частые вопросы

Что означают грейды A / B / C / D?

A — работает отлично: множественные Cochrane-обзоры и крупные РКИ (Креатин, Витамин D, Железо). B — работает: эффект подтверждён систематическими обзорами (Омега-3, Цинк, Мелатонин). C — зависит от контекста: эффект есть только при определённых условиях (доза, популяция) — Ресвератрол, NMN. D — не подтверждено: систематических данных нет или эффект не найден — Биотин, Йохимбин, Трибулус.

Как именно вы проверяли добавки?

По адаптированной методологии PRISMA (5 из 27 пунктов): поиск систематических обзоров и мета-анализов в PubMed → скрининг по релевантности → дедупликация → ручное чтение топ-15 абстрактов → выставление грейда и вердикта. Все 81 карточка аудита лежат в открытом виде в data/processed/audit/ с PMID ключевых источников.

Почему у популярной добавки грейд D?

Популярность ≠ доказательность. Биотин «для волос и ногтей» не имеет ни одного систематического обзора с положительным исходом у здоровых людей. Йохимбин изучался в 1980-90-х, после появления виагры исследования прекратились. Грейд D — это не «добавка плохая», а «доказательств нет».

Можно ли полностью полагаться на вердикты?

Вердикты — ручная оценка на основе абстрактов систематических обзоров, а не клиническая рекомендация. Ограничения: мы читаем абстракты, а не полные тексты; часть обзоров сама имеет низкое качество. Для решений о приёме консультируйтесь с врачом. Проект не даёт медицинских рекомендаций — только данные.
