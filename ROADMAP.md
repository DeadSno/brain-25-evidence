## Фаза 5 — решения приняты (2026-09-18)

1. Карта механизмов: гибрид. Старый атлас-список остаётся как
   навигация, справа — мини-граф выбранной добавки (вещество → мишень →
   эффект) с визуальными связями. Прототип — сначала на 1 карточке,
   замер производительности, потом внедрение.

2. Группировка категорий: гибрид. Верхний уровень — старые группы
   (Антиоксиданты, Нейро, Сердце и т.д.), внутри — фильтр по тегам
   `effect_tags` (Сон, Мозг, Энергия и т.д.). Пользователь видит
   и структуру, и цели.

3. URL карточек: `?s=ginkgo` (query-параметр). Работает на GitHub
   Pages из коробки, индексируется, шарится. Переход на `/ginkgo/`
   через SSG — отдельная задача при масштабировании.

4. citations + DOI: обогащаем `key_sources` DOI автоматически
   через PubMed esummary (ArticleId IdType="doi"). Скрипт
   `scripts/enrich_dois.py`, один прогон, 234 запроса. Затем
   `fetch_citations` использует DOI как fallback.

5. L (расширение базы) vs N (карта взаимодействий): сначала L.
   Расширение базы даст больше, потому что новые карточки сразу
   попадают в карту взаимодействий. N — после L, на готовой базе.
