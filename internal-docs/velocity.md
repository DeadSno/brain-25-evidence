## Ретроспектива

**Что сработало:**
- Разбивка на спринты по 4-6 задач
- Эстимация по сложности (Fibonacci: 1, 2, 3, 5, 8)
- Чёткое DoR (см. [definition_of_ready.md](definition_of_ready.md))

**Что улучшить:**
- S1-S2 недооценили масштаб (11-12 SP vs 22-30 в S4)
- Часть артефактов (Impact Analysis, DoR) появилась вне плана
- Velocity росла — признак оптимизации процесса

**Вывод:** velocity растёт линейно (11 → 30), что говорит о накоплении экспертизы.
