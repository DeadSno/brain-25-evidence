# ADR-002: GitHub Pages вместо VPS

- **Статус:** Accepted
- **Дата:** 2026-09-25

## Решение

Хостинг статики — **GitHub Pages**, BI — **Streamlit Cloud**.

## Альтернативы

| Вариант | Цена/мес | Плюсы | Минусы |
|---------|----------|-------|--------|
| **GitHub Pages** | 0 руб | Free, CDN, HTTPS, custom domain | Только статика |
| VPS (Hetzner) | 400 руб | Любой backend | Нужен админ, тьюнинг |
| Netlify / Vercel | 0 руб | Serverless функции | Лимиты bandwidth |
| AWS S3 + CloudFront | ~200 руб | Масштаб | Сложнее настройка |

## Обоснование

1. **Нулевая стоимость** на старте.
2. **Автодеплой** при push в main.
3. **HTTPS** и **CDN** из коробки.
4. **Streamlit Cloud** покрывает BI потребности бесплатно.

## Последствия

- 0 руб инфраструктура
- Deploy = git push
- Нет server-side логики (всё клиентское)
- Лимит 1 GB репо

## Когда пересмотреть

При необходимости аутентификации, персональных данных или интеграции с БД.
