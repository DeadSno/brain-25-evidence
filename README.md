## Что это и зачем

**Зачем этот проект:** рынок БАДов в России — это миллиарды рублей в год. Большинство покупок делается по рекламе и советам блогеров, но наука часто говорит противоположное: часть добавок работает только при дефиците, часть — только у пациентов, а часть — маркетинг без единого доказательства на людях.

**Что мы показываем для каждой из 130 добавок:**

| Что показываем | Зачем это знать | Источник |
|----------------|-----------------|----------|
| Индекс доказательности | Сколько науки стоит за добавкой | PubMed E-utilities |
| Вердикт (+1 / 0 / -1) | Работает / зависит / не подтверждено | Ручная вычитка топ-2 мета-анализов |
| Hedges' g | Сила эффекта в стандартных отклонениях | Из мета-анализов (86/130) |
| Активных испытаний | Тестирует ли кто-то сейчас | ClinicalTrials.gov |
| Дозировка и предостережения | Как принимать безопасно | Протоколы из исследований |
| Конфликты с лекарствами | Что нельзя совмещать | Interaction-база |

## Анализ конфликтов интересов (COI)

Проанализировано **6310 полных текстов** из PubMed Central. Всего XML
получено 7918, разобран текст с объёмом от 20 000 байт (порог
`threshold_bytes` в отчёте). Из 11 176 PMCID в наборе полных текстов
**56.5 %**.

> Прежняя формулировка «87 % покрытие PMCID» была неверной: 87.0 % — это
> доля полных текстов, в которых конфликт интересов **заявлен**, а не
> покрытие PMCID. Само покрытие PMCID равно 56.5 %.

| Метрика | Значение | % |
|---------|----------|---|
| Указали COI | 5490 | **87.0%** |
| — нет конфликта | 4349 | 68.9% |
| — **реальный конфликт** | **467** | **7.4%** |
| — неясно | 674 | 10.7% |
| Не указали COI | 820 | 13.0% |
| Указали funding | 3500 | 55.5% |
| Упомянули фарм-компанию | 282 | 4.5% |

Все проценты считаются от 6310, а не от 7918: сумма строк COI
(5490 + 820) даёт те же 6310, а строка «реальный конфликт» (467)
восстанавливается вычитанием 5490 − 4349 − 674.

**ТОП-10 funders** — государственные фонды: NSFC (Китай), NIH/NCI/NIDDK/NIA (США),
NCCAM, NIAAA, NICHD, NIGMS. **Ни одной фарм-компании в ТОП-10.**

## Методология

**Зачем эта секция:** чтобы любой мог воспроизвести наши выводы или поспорить с ними. Всё прозрачно.

### Индекс науки

**Индекс = РКИ + 5 × мета-анализы**

Проверяемо: формула сходится **в 130 из 130** карточек `docs/data.json`
(`scienceIndex == rct + 5 × metaCount`), то есть это описание реального
кода расчёта, а не только формулировка.

**Как считаем:** PubMed-запрос (вещество) AND (конкретный исход) с отсечкой ветеринарии и промышленных работ. Мета-анализ весит в 5 раз больше РКИ, потому что объединяет множество исследований.

**Почему так, а не иначе:** индекс меряет *количество* науки, а не *силу* эффекта. Поэтому параллельно ставим ручной вердикт по топ-2 мета-анализам.

**Примечание:** индекс отражает объём всей литературы по веществу, включая инъекционные и лекарственные формы. Лидер по индексу — омега-3 (10 666 из 130), то есть её индекс нельзя читать как объём доказательств именно перорального приёма. Тот же перекос виден на гиалуроновой кислоте (4 100): её литература раздута исследованиями инъекций в колено при остеоартрите. Вердикт и дозировка на карточке учитывают именно пероральный приём как БАД.

### Вердикты (вручную, по топ-2 мета-анализам)

| Код | Значение | Когда ставим |
|-----|----------|--------------|
| +1 | работает | стабильный эффект у здоровых — мета-анализы показывают значимый эффект в общей популяции |
| 0 | зависит от контекста | работает при дефиците / у пациентов / в экстриме — эффект только в подгруппах (дефицит, спортсмены, пожилые) |
| -1 | не подтверждено | маркетинг без человеческих доказательств — нет мета-анализов, или они отрицательные, или только in vitro / на животных |

### Активные испытания

Источник: ClinicalTrials.gov API v2. Статусы RECRUITING, ACTIVE_NOT_RECRUITING, NOT_YET_RECRUITING. Ноль испытаний = «маркетинг без будущего»: наука либо всё сказала, либо не верит в эффект.

## Локальный запуск

### Статический сайт (docs/)

```bash
# 1. Клонируй
git clone https://github.com/DeadSno/brain-25-evidence.git
cd brain-25-evidence

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Прогони тесты (должно быть 790 passed, 2 skipped)
python -m pytest tests/ -q

# 4. Подними сайт локально
python serve.py
# → http://localhost:8000/
```

**Важно для headless-проверок:**

- Используй `http://localhost:8000`, **НЕ** `file://` — `fetch()` не работает в файловом протоколе (CORS)
- После старта сервера: `Ctrl+Shift+R` в браузере для обхода кэша `data.json`
- На GitHub Pages (https) `fetch` работает без проблем
- `serve.py` лежит в **корне** репозитория (не в `docs/`) и автоматически добавляет заголовки `Content-Type: text/html; charset=utf-8` (и для JS/CSS/JSON) — лечит локальные кракозябры
- Прогон `pytest -q` без живого сервера **проводит не все тесты**: 197 из 989 требуют браузера и сняты по умолчанию. Считать «зелёный прогон» доказательством того, что браузерные сценарии живы, нельзя

## Как помочь проекту

### Нашли ошибку в данных?

Создайте [issue](https://github.com/DeadSno/brain-25-evidence/issues) по шаблону — исправим и отметим в CHANGELOG.

### Хотите добавить добавку?

1. Форкните репозиторий
2. Дополните `src/config.py` (запросы, нормы) и `src/content.py` (категории, эффекты, протоколы)
3. Прогоните `python scripts/update_all.py --apply` для регенерации `data.json`
4. Прогоните `python scripts/build_index.py` для синхронизации `data_index.json`
5. Откройте PR в `main`

Полные правила — в [CONTRIBUTING.md](CONTRIBUTING.md).

Звёздочка на GitHub и ссылка друзьям — уже помощь.
